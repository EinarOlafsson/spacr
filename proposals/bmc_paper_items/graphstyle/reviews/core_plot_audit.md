## Authority and interpretation

The copied `authority/SKILL.md` SHA256 is `a2a199443c6a4bb0dafaf75fc503c908735a4d6b3646fa945d9a92d5813790c1`; `authority/spacr_figstyle.py` is `6979fe7e9ed6aa31a41fc66b19447be50b9b901c861dd60f0982382a6913dca3`.

Use the later rules where the skill explicitly revises itself. In particular, the early geometry paragraph says 0.25 inch per condition, whereas the revised 2026-11-20 rule and the actual helper use 0.22 inch. The helper's `apply_style` docstring still says 7 pt while its constants are 8 pt. Neither stale prose should become a new implementation default. For thousands of observations per categorical group the authority explicitly requires a violin with no individual points; density/hexbin is the separate dense continuous-scatter decision. Round 5 forbids ordinary in-panel values/notes, later rounds permit specific missing-value/status labels and clarify varied chart forms; this is not a blanket ban on every label in an image, schematic, legend or missing-value slot. An image is not a continuous-coordinate statistical plot and should not be forced to a square crop or 60% image opacity. Explicit reference controls/units/legend contents require domain metadata; they cannot safely be guessed from arbitrary artist colors or column names. A nonsquare canvas alone is not proof of nonsquare axes; only explicit axes geometry, source arithmetic or rendered dimensions establishes that failure.

The copied helper is a reference, not a safe application import: `spacr_figstyle.py:39` calls `matplotlib.use("Agg")` globally, `:100` updates global rcParams, its ink/background assumptions are light-page oriented, and `_FONT_DIRS:90` points to a workstation-local installation. Importing it into the GUI would create a second style owner and can replace the live backend. Existing `spacr.figures.style.figure_style:720` already scopes rcParams, `spacr.figure_font` registers bundled faces, and `figure_style.saved_figure_appearance:882` separates print/screen/transparent modes.

## One owner and a concrete migration API

Extend **`spacr.figures.style`**, not the copied helper. Keep `figure_style.py` as the preference resolver/export-color adapter, `figure_font.py` as bundled font registration, `graph_types.py` as graph-choice policy, and `plot.save_figure`/`figure_sink` as the existing persistence/publishing path. The existing `.figures.style` owner should expose one resolved immutable style specification consumed by Matplotlib and the Qt renderer; do not copy constants into each backend.

Proposed additions within that owner: `resolve_style(target, kind, *, control, identities, comparison, policy_version)`; `axes_geometry(kind, *, conditions, cells, panel_height)`; and `finalize_figure(figure, specification, *, diagnostics)` using the existing primitives (`figure_style`, `condition_plot`, `size_condition_axes`, `square_axes`, `figure_problems`). Names are a proposal, not implemented APIs. A figure can retain a style/semantic specification next to its existing `_spacr_spec`; saved recipes must include its version. `finalize_figure` should report unmet semantic requirements instead of inventing a control or relabeling scientific units. It must not rescale data, alter tests, move acceptance thresholds, normalize images silently or replace stored user preferences.

Use a specific paper/export profile, with print-light/dark-screen/transparent adapters all sharing geometry and identity colors. A light-only global Agg module is unsuitable. Export-time chrome conversion must remain reversible. Preserve analytical normalization and scientific arrays/results; explicitly recorded display ranges, gamma and color normalization remain legitimate presentation operations. Numerical data colors and comparison ranges must not be silently changed. Image comparison policy should carry source, display range/gamma, method identity, scale and provenance; existing `_tag_panel`/integrity machinery is the seam.

## Ratchet strategy (proposed; nothing run)

1. Retain exact baseline inventory and exceptions. Require every new plotting creator/writer to use or explicitly justify the shared path; test function-level route membership rather than raw name matches in strings/docstrings. Do not require numerical/statistical/formatting helpers to draw.
2. Extend the existing `tests/test_figure_rules_spacr_graphs.py`: groups of 1, 20, 21 and 1001 observations; 2/3/6 conditions; fixed physical slot and bar width; exact control identity grey; effective artist RGBA alpha; >20 form selection and, for thousands per categorical group, violin with no individual points. Test dense continuous scatter's separate density/hexbin policy. Check all four spines/outward ticks, ≥8 pt, font Light/Regular/SemiBold resolution and scoped restoration even on failure. Test single-point bars explicitly. Report metadata must explain permitted deviations.
3. Preserve figure source arrays/statistics byte-for-byte while comparing geometry and artist metadata. Test manual overrides and pipeline preference isolation separately. Existing old opaque tests (`test_the_plot_figures_are_house_style.py:404`, `test_the_well_distributions_are_house_style.py:121`) conflict with the supplied authority and require deliberate expectation changes, not blanket weakening.
4. Add renderer parity cases for a boxed line+markers alpha.6, scatter with effective alpha.6, a square continuous axes, categorical physical widths, and a heatmap including missing values. Check scene pens/brushes and dimensions, then inspect small PNGs. Never claim pixel equality between Matplotlib and Qt antialiasing.
5. Add ordinary-save and bundle-recreation integration cases through the existing writer/sink. Verify status-led legend, both PDF/PNG and source-data metadata for declared paper deliverables; allow operational previews to retain their narrower contract. Preserve old recipe reproduction via explicit policy versions.
6. Layout findings require rendered extents and visual review. Existing `figure_problems` can support this, but passing it alone cannot prove no hidden labels, clipped artists, legend/data overlap or correct scientific narrative. A small number of bounded synthetic plots is sufficient to establish representative failures before any broad rendering.
