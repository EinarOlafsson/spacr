# Graph-style audit: remaining plot families

Source tree: `299179d9530ac618d82f11cc823f3ad8abd1c001` in `/mnt/wd4tb/worktrees/codex-graphstyle-spec`. This is a static specification audit. No application files were changed, and no Python, tests, rendering, training or scheduler jobs were run by this worker.

The scope is all 100 assigned entries in the frozen `.codex-audit/root_candidates.json` after excluding timelapse, lineage and division files owned by another worker. It also includes 18 supplementary chart, export and style-support functions found from the complete lexical inventory. Every assigned ID has one disposition. The canonical machine-readable output is `remaining_rows.json`: 118 unique entries comprising 18 plot owners, 12 writers, 20 support functions, 33 wrappers and 35 explicit exclusions.

Authority is the copied `proposals/bmc_paper_items/graphstyle/authority/SKILL.md` (SHA-256 `a2a199443c6a4bb0dafaf75fc503c908735a4d6b3646fa945d9a92d5813790c1`) and `spacr_figstyle.py` (SHA-256 `6979fe7e9ed6aa31a41fc66b19447be50b9b901c861dd60f0982382a6913dca3`). Later rules supersede older advice: condition slots are 0.22 in, data opacity is 0.6, every text element is at least 8 pt, and floating numerical/statistical text belongs in legends except explicit missing/status exceptions. Heatmaps need square cells; continuous plot areas need square geometry. Chart form must follow the question; the latest rules do not authorize converting every result to a bar chart.

The report distinguishes shared-helper adoption from full compliance. Many owners already enter `spacr.figures.style.figure_style`, register source data, and use `spacr.plot.save_figure`. Local mark opacity, labels, palettes and physical geometry can still violate the contract inside those contexts. These routes should be strengthened through the existing common owner. The external reference helper's light-only backend setup should not be copied into a competing production style subsystem.

## Findings that should affect the implementation plan

- **Frequently exposed scorecards and volcano results:** `scorecard.scorecard_figure:1080` draws opaque, dodged bars and inline values despite shared style/export adoption. `volcano_style.render_volcano:372` has 0.85 default point alpha, orange significant marks, optional point labels and no enforced square area. Its helpers already preserve actual legend identities and repaint theme ink consistently; retain those behaviors.
- **Explicit brown and undersized labels:** `sp_stats._map_figure:5450` uses `#b5471b`, opaque points and a 7 pt legend. `_similarity_figure:5484` has 6 pt labels, although its signed color scale and default square cells are appropriate. The compound galleries use `tab10`, whose sixth entry is brown; raster captions are 7 pt and the separate SVG writer hard-codes a white page.
- **Geometry and chart choice:** gene-function and gene-graph owners duplicate geometry and palette policy. They correctly preserve 0.6 mark alpha and grey controls in several paths, but retain horizontal comparison bars, opaque references, 6/7 pt labels and 200 dpi PNG export. Bootstrap groups can exceed 20 observations while remaining bars. Compare Images uses shared condition primitives but supplies arbitrary canvas sizing, forced chart kind and inline significance text. Its effect plot uses the explicitly rejected named horizontal dot-row form.
- **Heatmap semantics:** `seg_qc._robustness_figure:2630` uses `aspect='auto'`, opaque `magma_r` and 7 pt cell text. Nonfinite cells are colored at the maximum via `2*tolerance`; labels distinguish infinity as `all` and missing values as `-`, but the color does not. Missing and unbounded values need distinct, documented treatment; undefined cells require the prescribed cross.
- **Reports preserve upstream style:** HTML and PDF composition embed existing raster plots. A Matplotlib PDF container does not recover vector chart elements, and downscaling can reduce effective font size. `report.Figure` is a data container, not a Matplotlib figure constructor. Report prose and monospace document transcription must not be misreported as chart-font defects.
- **Workflow schematics require an explicit boundary:** FlowView already shares tokens between live Qt items and SVG export. Those tokens are dark-only Arial with a tan/brown process accent. Exported schematic rules apply, while condition-slot and replicate rules are inapplicable to node cards. An operational UI need not lose useful status information merely to meet a paper schematic's text budget; the implementation specification must decide how its export conforms.
- **Image and chemical galleries:** compare actual display ranges, scale/channel keys and final text size where applicable. Do not apply condition-slot or replicate rules to image pixels or chemical bonds. Counterfactual sequences already reuse the initial image range within each row, but text is 7 pt and ranges are not shared across rows.

Source confirms the literals, artist calls and routing described below. Clipping, overlap, exact final axes dimensions, appearance after raster resizing and dark/light contrast remain render-dependent. Absence of a geometry checker is not evidence that a particular rendered axis is nonsquare. The parent audit owns representative rendering and the consolidated API/ratchet proposal.

Exposure is an estimate from call paths, not usage telemetry: **1** = common results/export or reusable style route; **2** = a feature workflow or conditional pipeline path; **3** = a specialized research/validation path. Exclusions are not ranked. Wrappers inherit the downstream owner's findings and should not receive duplicate style implementations.
