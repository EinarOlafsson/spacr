# Function route checkpoint

This is an OPEN G1 checkpoint for Home G2, not a completed graph-style migration.
The original 1,607 reviewed function IDs are retained in inventory.csv. Exact
per-function staging entries have a scientific purpose and source location;
there are no file-wide runtime exceptions. Home removes individual entries
from deferred_g2.json as it converts its functions. The other group files
are separate so parallel removal does not edit the same lines.

G1 FINAL requires deferred_g1.json to be empty. It currently includes both
remaining independent creators and helpers whose styled calling context
still needs an explicit source route. An entry is not a compliance verdict.
The initial plan bounds the allowed IDs and reasons; current lists may only
shrink. New plotting primitives cannot be admitted through a module wildcard.
Original non-plot exclusions retain their primitive signatures so adding a
drawing operation requires review. Three retired private create_plot helper
identities are recorded explicitly.

Static lexical routing is paired with runtime physical geometry, count/form,
control identity, real RGBA/opacity, typography, missing-cell, manual-choice,
replay and numerical-neutrality tests. Reachability alone does not certify
every conditional execution path or every actual rendered figure.


Reviewed metadata and preference helpers have individual exact-source
contracts in support_contracts_g1.json. They create no charts or artists.
The guard checks every source variant, file and AST hash before accepting
the helper, including calls outside the primitive vocabulary. A changed
body fails review even if it still contains no recognized drawing call.
This is a source-bound support classification, not a style certificate or
a new deferred chart allowance. Independent chart creators remain in G1.


Support contracts also freeze each source-resolved call target. Rebinding a
module import to an unrelated painter fails even when the getter AST and
the recognized primitive list are unchanged. This supplements the exact
body, file, variant and original-G1-ID checks.


Caller-owned scene adapters have separate context_contracts_g1.json records.
Every known caller has an exact source witness to its real declared or
finalized host. Scene entry points reach the shared finalizer; builder entry
points declare and apply their shared specification before returning the
figure to ordinary saving and display. Helper and witness bodies, all variants,
resolved calls and recognized primitives are frozen. New callers fail review,
including wrappers whose own body contains no recognized drawing primitive.
Adapters are never added as style roots, so calling a low-level adapter from
a new unstyled chart cannot establish a route. These contracts describe
source ownership; actual paint, arrays, geometry and fallback remain covered
by the named runtime tests. Unsupported cases retain explicit diagnostics.
