# Function route checkpoint

This is an OPEN G1 checkpoint for Home G2, not a completed graph-style migration.
The original 1,607 reviewed function IDs are retained in inventory.csv. Exact
per-function staging entries have a scientific purpose and source location;
there are no file-wide runtime exceptions. Home removes individual entries
from deferred_g2.json as it converts its functions. The other group files
are separate so parallel removal does not edit the same lines.

G1 FINAL requires deferred_g1.json to be empty. It currently includes both
remaining independent creators and helpers whose styled calling context
still needs an explicit source route. An entry is not a compliance verdict.
The initial plan bounds the allowed IDs and reasons; current lists may only
shrink. New plotting primitives cannot be admitted through a module wildcard.
Original non-plot exclusions retain their primitive signatures so adding a
drawing operation requires review. Three retired private create_plot helper
identities are recorded explicitly.

Static lexical routing is paired with runtime physical geometry, count/form,
control identity, real RGBA/opacity, typography, missing-cell, manual-choice,
replay and numerical-neutrality tests. Reachability alone does not certify
every conditional execution path or every actual rendered figure.
