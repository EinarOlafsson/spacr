Á macOS, opna ` .pkg `. Núverandi beta er ekki notarið; ef Gatekeeper blokkir það, velja <strong>System Settings → Privacy &amp; Security → Open Anyway</strong>.

Sjá [uppsetningarleiðbeiningarnar](<../../source/installer_guide.rst>) fyrir leiðbeiningar um uppfærslu, fjarlægingu, notkun án nettengingar og bilanagreiningu. Í [kerfiskröfunum](<../../source/system_requirements.rst>) eru ráðleggingar um vinnustöðvar og netþjóna og töflur um GPU-samhæfi.
