Á macOS, opna ` .pkg `. Núverandi beta er ekki notarið; ef Gatekeeper blokkir það, velja <strong>System Settings → Privacy &amp; Security → Open Anyway</strong>.

Leiðbeiningar um uppsetningu, uppfærslu, enduruppsetningu, fjarlægingu, notkun án nettengingar og bilanagreiningu eru í [nýjustu uppsetningarleiðbeiningunum á nightly (á ensku)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>). Í [kerfiskröfunum](<../../source/system_requirements.rst>) eru ráðleggingar um vinnustöðvar og netþjóna og töflur um GPU-samhæfi.
