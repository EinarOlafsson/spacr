## Hreyfimyndaleiðbeiningar fyrir stillingar

Stillingar með sjónræna skýringu bjóða upp á <strong>Animation</strong>-stýringu í verkfæraábendingunni. Skoðaðu [myndasafn stillingahreyfimynda](<https://einarolafsson.github.io/spacr/setting_animations.html>) eða [skrá stillingahreyfimynda](<https://einarolafsson.github.io/spacr/api/spacr/setting_animations/index.html>).
