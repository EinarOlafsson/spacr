## Setja upp spaCR

- <strong>Skjáborðsforrit</strong>: uppsetningarforrit fyrir Linux, macOS eða Windows með eigið Python.
- <strong>pip</strong>: ` python -m pip install spacr ` í Conda-umhverfi.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` í Conda-umhverfi.
