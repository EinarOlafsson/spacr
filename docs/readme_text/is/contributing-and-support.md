## Framlög og aðstoð

Sendu villutilkynningar og afmarkaðar óskir um eiginleika í gegnum [GitHub-mál](<https://github.com/EinarOlafsson/spacr/issues>). Þegar bilun er tilkynnt skal tilgreina útgáfu spaCR, stýrikerfi, útgáfu Python, stillingar einingarinnar og viðeigandi hluta úr annálnum. ` spacr-doctor ` safnar flestum þessara upplýsinga; láttu vélbúnaðarskýrsluna fylgja þegar tilkynnt er um afkastavandamál.
