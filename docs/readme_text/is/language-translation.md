## Tungumál og þýðingar

Viðmótið styður tíu tungumál í leiðsögn og stillingum. AI- og LIVE-stýringar, lýsingar á einingum og yfirfarin samhengishjálp eru einnig þýdd. Skiptu um tungumál undir <strong>spaCR → Stillingar → Tungumál</strong> án endurræsingar. Annálar, slóðir, gagnagrunnsgildi og mælingar eru aldrei þýdd; vísindaleg úttök haldast á viðurkenndri ensku. Sjá [stefnu um samhengishjálp](<../../source/localization.rst#contextual-help>).
