### Kjarnaverkflæði

Aðalvinnuflæðið samanstendur af sex einingum:

- <strong>Mask</strong> hlutgreinir frumur, frumukjarna, sýkla og frumulíffæri með Cellpose.
- <strong>Measure</strong> skrifar lögunar-, styrkleika-, áferðar-, rúm- og samstaðsetningareiginleika ásamt myndúrklippum viðfanga í SQLite.
- <strong>Annotate</strong> merkir myndúrklippur í lyklaborðsstýrðu hnitaneti og styður biðraðir virks náms.
- <strong>Classify</strong> þjálfar líkön byggð á myndum eða mælingum og skráir frammistöðu á fráteknum gögnum með hverjum varðpunkti.
- <strong>Map Barcodes</strong> varpar FASTQ-lestrum á brunna og gRNA og veitir gæðamat fyrir magn, árekstra og þekju.
- <strong>Regression</strong> metur áhrif leiðarsameinda, gena, skilyrða og viðmiða með líkanafjölskyldum sem henta samfelldum gildum, hlutföllum og talningum.
