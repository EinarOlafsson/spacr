## 安装 spaCR

请选择安装方式：

- <strong>桌面应用程序</strong>：适用于 Linux、macOS 或 Windows 的安装程序，自带 Python。
- <strong>pip</strong>：在 Conda 环境中运行 ` python -m pip install spacr `。
- <strong>conda-forge</strong>：在 Conda 环境中运行 ` conda install conda-forge::spacr `。
