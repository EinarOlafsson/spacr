Las integraciones opcionales se instalan por separado, por ejemplo ` spacr[zarr] `, ` spacr[omero] `, ` spacr[napari] ` y ` spacr[czi,nd2,lif] `. Consulte la [guía de instalación (nightly, en inglés)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>) para ver la lista completa de extras y la tabla de compatibilidad de versiones de Python.
