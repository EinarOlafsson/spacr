` --dir ` elige la ruta del clon; ` --branch ` selecciona una rama o etiqueta; ` --no-install ` descarga sin instalar; ` --help ` muestra las opciones. ` packaging/source_install_excludes.txt ` enumera todas las rutas omitidas.
