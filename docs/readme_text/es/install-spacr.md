## Instalar spaCR

Elija una vía de instalación:

- <strong>Aplicación de escritorio</strong>: un instalador para Linux, macOS o Windows con su propio Python.
- <strong>pip</strong>: ` python -m pip install spacr ` en un entorno de Conda.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` en un entorno de Conda.
