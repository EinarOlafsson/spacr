En macOS, abra el archivo ` .pkg `. La beta actual no está notarizada; si Gatekeeper la bloquea, seleccione <strong>Ajustes del Sistema → Privacidad y seguridad → Abrir igualmente</strong>.

Para obtener instrucciones de instalación, actualización, reinstalación, desinstalación, uso sin conexión y solución de problemas, consulte la [guía de instalación actual de nightly (en inglés)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>). Consulte los [requisitos del sistema](<../../source/system_requirements.rst>) para ver recomendaciones sobre estaciones de trabajo y servidores y tablas de compatibilidad de GPU.
