` --dir `은 클론 경로를, ` --branch `는 브랜치나 태그를 선택합니다. ` --no-install `은 설치 없이 가져오며, ` --help `는 옵션을 표시합니다. ` packaging/source_install_excludes.txt `에 제외된 모든 경로가 나열되어 있습니다.

nightly 전체 클론은 9.25 GiB를 다운로드했습니다. 얕은 클론에 ` --filter=blob:none `을 추가해도 체크아웃 크기는 줄어들지 않습니다. Git 객체 저장소는 여전히 2032 MB입니다. Git은 필요할 때 나중에 가져오는 객체를 보고하지 않으므로 전체 다운로드 총량은 측정하지 않았습니다. main의 버전 관리 파일을 체크아웃하면 Git 이력을 제외하고 735 MB를 차지합니다(2026-10-21 측정). 다운로드 크기와 시간은 브랜치에 따라 달라집니다.
