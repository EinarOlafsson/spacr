## spaCR 설치

설치 방법을 선택하세요:

- <strong>데스크톱 애플리케이션</strong>: 자체 Python이 포함된 Linux, macOS 또는 Windows용 설치 프로그램입니다.
- <strong>pip</strong>: Conda 환경에서 ` python -m pip install spacr ` 명령을 실행합니다.
- <strong>conda-forge</strong>: Conda 환경에서 ` conda install conda-forge::spacr ` 명령을 실행합니다.
- <strong>Docker</strong>: CPU 이미지 또는 NVIDIA GPU 이미지를 사용해 Linux 컨테이너에서 명령줄 파이프라인을 실행합니다:
