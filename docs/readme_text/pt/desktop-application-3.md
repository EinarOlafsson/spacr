No macOS, abra o arquivo ` .pkg `. A versão beta atual não é notarizada; se o Gatekeeper a bloquear, selecione <strong>Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim</strong>.

Para instruções de instalação, atualização, reinstalação, desinstalação, uso offline e solução de problemas, consulte o [guia de instalação atual do nightly (em inglês)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>). Consulte os [requisitos do sistema](<../../source/system_requirements.rst>) para recomendações sobre estações de trabalho e servidores e tabelas de compatibilidade de GPU.
