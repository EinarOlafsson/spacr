No macOS, abra o arquivo ` .pkg `. A versão beta atual não é notarizada; se o Gatekeeper a bloquear, selecione <strong>Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim</strong>.

Consulte o [guia de instalação](<../../source/installer_guide.rst>) para obter instruções de atualização, desinstalação, uso offline e solução de problemas, e os [requisitos do sistema](<../../source/system_requirements.rst>) para recomendações sobre estações de trabalho e servidores e tabelas de compatibilidade de GPU.
