As integrações opcionais são instaladas separadamente, por exemplo ` spacr[zarr] `, ` spacr[omero] `, ` spacr[napari] ` e ` spacr[czi,nd2,lif] `. Consulte o [guia de instalação (nightly, em inglês)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>) para ver a lista completa de extras e a tabela de compatibilidade das versões do Python.
