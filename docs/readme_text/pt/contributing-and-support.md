## Contribuições e suporte

Envie relatos de erros e solicitações de recursos bem delimitadas pelo [GitHub Issues](<https://github.com/EinarOlafsson/spacr/issues>). Ao relatar uma falha, inclua a versão do spaCR, o sistema operacional, a versão do Python, as configurações do módulo e o trecho relevante do log. O ` spacr-doctor ` coleta a maior parte dessas informações; inclua o relatório de hardware ao relatar problemas de desempenho.
