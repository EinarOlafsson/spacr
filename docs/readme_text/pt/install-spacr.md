## Instalar o spaCR

Escolha uma forma de instalação:

- <strong>Aplicativo para desktop</strong>: um instalador para Linux, macOS ou Windows com Python próprio.
- <strong>pip</strong>: ` python -m pip install spacr ` em um ambiente Conda.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` em um ambiente Conda.
