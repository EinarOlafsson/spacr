## Guia animado de configurações

As configurações com uma explicação visual oferecem um controle <strong>Animation</strong> na dica de ferramenta. Consulte a [galeria de animações de configurações](<https://einarolafsson.github.io/spacr/setting_animations.html>) ou o [registro de animações de configurações](<https://einarolafsson.github.io/spacr/api/spacr/setting_animations/index.html>).
