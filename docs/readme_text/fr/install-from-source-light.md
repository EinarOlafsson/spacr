### Installation depuis les sources (allégée)

Les contributeurs ont besoin de l’historique des versions ; pour simplement exécuter spaCR, choisissez une option ci-dessous. Mesures de ` nightly ` à ` 05302fd5c ` le 2026-10-07, effectuées avec ` packaging/measure_clone_forms.sh `.

Clone superficiel : 2048 MB téléchargés en 140 s. Seul le dernier commit est conservé ; l’historique antérieur n’est donc pas accessible à ` git log `, ` git blame ` et ` git bisect `. ` git pull ` fonctionne, mais le clone reste superficiel ; ` git fetch --unshallow ` récupère l’historique complet.
