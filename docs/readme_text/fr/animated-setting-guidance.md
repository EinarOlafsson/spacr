## Guide animé des paramètres

Les paramètres accompagnés d’une explication visuelle proposent une commande <strong>Animation</strong> dans leur infobulle. Parcourez la [galerie des animations de paramètres](<https://einarolafsson.github.io/spacr/setting_animations.html>) ou le [registre des animations de paramètres](<https://einarolafsson.github.io/spacr/api/spacr/setting_animations/index.html>).
