## Contributions et assistance

Soumettez les rapports de bogues et les demandes de fonctionnalités bien délimitées via [GitHub Issues](<https://github.com/EinarOlafsson/spacr/issues>). Lorsque vous signalez un échec, indiquez la version de spaCR, le système d’exploitation, la version de Python, les paramètres du module et l’extrait de journal pertinent. ` spacr-doctor ` collecte la plupart de ces informations ; joignez le rapport matériel lorsque vous signalez un problème de performances.
