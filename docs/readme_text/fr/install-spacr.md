## Installer spaCR

Choisissez une méthode d’installation :

- <strong>Application de bureau</strong> : un installateur pour Linux, macOS ou Windows avec son propre Python.
- <strong>pip</strong> : ` python -m pip install spacr ` dans un environnement Conda.
- <strong>conda-forge</strong> : ` conda install conda-forge::spacr ` dans un environnement Conda.
