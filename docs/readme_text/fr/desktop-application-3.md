Sur macOS, ouvrez le ` .pkg `. La bêta actuelle n'est pas notariée; si Gatekeeper le bloque, choisissez <strong>Paramètres du système → Confidentialité et sécurité → Ouvrez de toute façon</strong>.

Consultez le [guide d’installation](<../../source/installer_guide.rst>) pour les instructions de mise à jour, de désinstallation, d’utilisation hors ligne et de dépannage, et la [configuration requise](<../../source/system_requirements.rst>) pour les recommandations concernant les stations de travail et les serveurs ainsi que les tableaux de compatibilité GPU.
