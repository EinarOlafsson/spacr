## Beiträge und Support

Übermitteln Sie Fehlerberichte und klar abgegrenzte Funktionswünsche über [GitHub Issues](<https://github.com/EinarOlafsson/spacr/issues>). Geben Sie bei einer Fehlermeldung die spaCR-Version, das Betriebssystem, die Python-Version, die Moduleinstellungen und den relevanten Protokollauszug an. ` spacr-doctor ` erfasst den Großteil dieser Angaben; fügen Sie bei Leistungsproblemen den Hardwarebericht bei.
