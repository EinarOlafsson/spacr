Öffnen Sie auf macOS das ` .pkg `. Die aktuelle Beta wird nicht beglaubigt; wenn Gatekeeper sie blockiert, wählen Sie <strong>Systemeinstellungen → Datenschutz &amp; Sicherheit → Öffnen Sie trotzdem</strong>.

Anleitungen zur Installation, Aktualisierung, Neuinstallation, Deinstallation, zum Offlinebetrieb und zur Fehlerbehebung finden Sie in der [aktuellen Installationsanleitung auf nightly (Englisch)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>). Die [Systemanforderungen](<../../source/system_requirements.rst>) enthalten Empfehlungen für Arbeitsstationen und Server sowie Tabellen zur GPU-Kompatibilität.
