Öffnen Sie auf macOS das ` .pkg `. Die aktuelle Beta wird nicht beglaubigt; wenn Gatekeeper sie blockiert, wählen Sie <strong>Systemeinstellungen → Datenschutz &amp; Sicherheit → Öffnen Sie trotzdem</strong>.

Anweisungen zum Aktualisieren, Deinstallieren, Offlinebetrieb und zur Fehlerbehebung finden Sie in der [Installationsanleitung](<../../source/installer_guide.rst>). Die [Systemanforderungen](<../../source/system_requirements.rst>) enthalten Empfehlungen für Arbeitsstationen und Server sowie Tabellen zur GPU-Kompatibilität.
