## Modellzoo

spaCR enthält einen Katalog trainierter Modelle und lädt sie bei Bedarf herunter. Öffnen Sie <strong>Model Zoo</strong> auf der Startseite, um Modelle zu durchsuchen und zu installieren, oder geben Sie einen Modellschlüssel in einer Einstellungsdatei an, etwa ` pathogen_model: toxoplasma_pv_v1 `. Das Modell wird bei der ersten Verwendung heruntergeladen und anhand seiner Prüfsumme verifiziert. Jeder veröffentlichte Eintrag enthält eine SHA-256-Prüfsumme. Ein Eintrag ohne Prüfsumme wird abgelehnt, da eine unvollständige oder ausgetauschte Checkpoint-Datei sonst nicht vom Original unterschieden werden kann.
