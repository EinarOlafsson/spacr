## spaCR installieren

Wählen Sie einen Installationsweg:

- <strong>Desktopanwendung</strong>: ein Installationsprogramm für Linux, macOS oder Windows mit eigenem Python.
- <strong>pip</strong>: ` python -m pip install spacr ` in einer Conda-Umgebung.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` in einer Conda-Umgebung.
