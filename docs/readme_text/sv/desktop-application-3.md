På macOS, öppna ` .pkg `. Nuvarande beta notariseras inte. Om Gatekeeper blockerar den, välj <strong>Systeminställningar → Integritet &amp; Säkerhet → Öppna ändå</strong>.

För installation, uppdatering, ominstallation, avinstallation, offlineanvändning och felsökning, se den [aktuella installationsguiden på nightly (engelska)](<https://github.com/EinarOlafsson/spacr/blob/nightly/docs/source/installer_guide.rst>). Se [systemkraven](<../../source/system_requirements.rst>) för rekommendationer om arbetsstationer och servrar samt tabeller över GPU-kompatibilitet.
