## Installera spaCR

Välj en installationsväg:

- <strong>Skrivbordsprogram</strong>: ett installationsprogram för Linux, macOS eller Windows med egen Python.
- <strong>pip</strong>: ` python -m pip install spacr ` i en Conda-miljö.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` i en Conda-miljö.
- <strong>Docker</strong>: kommandoradens bearbetningsflöden i en Linux-container, från CPU-avbildningen eller avbildningen för NVIDIA-GPU:er:
