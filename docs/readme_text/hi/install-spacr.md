## spaCR इंस्टॉल करें

इंस्टॉलेशन का तरीका चुनें:

- <strong>डेस्कटॉप एप्लिकेशन</strong>: Linux, macOS या Windows के लिए इंस्टॉलर, जिसमें अपना Python शामिल है।
- <strong>pip</strong>: Conda परिवेश में ` python -m pip install spacr ` चलाएँ।
- <strong>conda-forge</strong>: Conda परिवेश में ` conda install conda-forge::spacr ` चलाएँ।
