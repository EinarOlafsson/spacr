## योगदान और सहायता

बग रिपोर्ट और स्पष्ट रूप से सीमित फ़ीचर अनुरोध [GitHub Issues](<https://github.com/EinarOlafsson/spacr/issues>) के माध्यम से भेजें। किसी विफलता की रिपोर्ट करते समय spaCR संस्करण, ऑपरेटिंग सिस्टम, Python संस्करण, मॉड्यूल सेटिंग्स और संबंधित लॉग अंश शामिल करें। ` spacr-doctor ` इनमें से अधिकांश जानकारी एकत्र करता है; प्रदर्शन संबंधी समस्या की रिपोर्ट करते समय हार्डवेयर रिपोर्ट भी शामिल करें।
