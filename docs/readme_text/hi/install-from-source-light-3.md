` --dir ` क्लोन का पथ चुनता है; ` --branch ` शाखा या टैग चुनता है; ` --no-install ` बिना इंस्टॉल किए डाउनलोड करता है; ` --help ` विकल्प दिखाता है। ` packaging/source_install_excludes.txt ` में छोड़े गए सभी पथ दिए गए हैं।

nightly के पूर्ण क्लोन ने 9.25 GiB डाउनलोड किया। उथले क्लोन में ` --filter=blob:none ` जोड़ने से चेकआउट छोटा नहीं होता: उसका Git ऑब्जेक्ट भंडार अब भी 2032 MB है। Git आवश्यकता पड़ने पर बाद में लाए गए ऑब्जेक्ट की सूचना नहीं देता, इसलिए कुल डाउनलोड नहीं मापा गया। main की संस्करण-नियंत्रित फ़ाइलें चेकआउट में 1265 MB लेती हैं (2026-10-21 को मापी गईं), जिसमें Git इतिहास शामिल नहीं है। डाउनलोड का आकार और समय शाखा के अनुसार बदलते हैं।
