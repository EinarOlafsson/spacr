macOS पर ` .pkg ` खोलें। वर्तमान बीटा को Apple का नोटरीकरण नहीं मिला है। यदि Gatekeeper उसे रोकता है, तो <strong>सिस्टम सेटिंग्स → गोपनीयता और सुरक्षा → फिर भी खोलें</strong> चुनें।
