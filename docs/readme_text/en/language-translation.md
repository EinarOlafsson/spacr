## Language & translation

The interface supports ten languages across navigation and Preferences. AI and LIVE controls, module descriptions and reviewed contextual help are also translated. Change the language under <strong>spaCR → Preferences → Language</strong> without restarting. Logs, paths, database values and measurements are never translated; scientific output remains canonical English. See the [contextual-help policy](<../../source/localization.rst#contextual-help>).
