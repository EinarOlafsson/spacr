## Install spaCR

Choose an install route:

- <strong>Desktop application</strong>: a Linux, macOS or Windows installer with its own Python.
- <strong>pip</strong>: ` python -m pip install spacr ` in a Conda environment.
- <strong>conda-forge</strong>: ` conda install conda-forge::spacr ` in a Conda environment.
