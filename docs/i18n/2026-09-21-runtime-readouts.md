# Make Masks readout translation slice

Added eight current UI strings in each of sv, de, es, zh_CN, pt, hi, ko, is
and fr: Features; two magnifier failure messages; object area/mean-intensity
readouts with and without “as loaded”; pixel intensity with and without
inversion; and the histogram/threshold action. These are 72 additions with
matching source hashes and reviewed records named
`2026-09-21-make-masks-readouts.json` in each runtime locale directory.

This slice was authored directly and checked against the English for meaning,
negation, measurement units, and placeholder identity. It was not generated by
a GPU model and is not claimed as native-speaker review. All candidates passed
the existing syntax, contextualization, degeneration, false-friend and Chinese
normalization checks. The full reviewed-record check passes: 3,512 records.

Every pre-existing catalog entry and source hash is preserved. Only the eight
new UI entries and their eight hashes were added per locale. The broader
catalog rebuild is still required; no freshness pin, allowlist, or audit rule
was relaxed.

The intake audit's “format fields changed” lines were misleading about the
cause: direct comparison found **zero existing UI translations with changed
format fields**, and **280 missing UI rows per locale**. The audit compares
missing values with the empty string, so any missing source with placeholders
also receives a format-field diagnostic. This slice reduces the missing UI
count to 272 per locale. It does not close the stale labels/tooltips, other
missing UI strings, or API catalog debt. The separate full API audit remains
red on manifest keys, source hashes and translated content freshness.

GPU use was continuously busy during this slice. The required 20 consecutive
idle minutes were not observed; no translation model or other GPU job started.
