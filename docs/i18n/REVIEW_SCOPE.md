# Current localization review scope

This is an evidence report and not a certificate that every sentence was read by a fluent speaker.

Mechanical coverage means every source has A translation. It does not mean a speaker of the language has read it.

Historical dated reports are retained in the private development archive linked from spacr/resources/AI/archive-index.md.
