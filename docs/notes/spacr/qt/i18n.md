### lines 4356-4367

```python
if widget.property(_PASS_STAMP) != stamp:
```

READ BEFORE WRITE, AND IT IS NOT A MICRO-OPTIMISATION. Qt sends a `DynamicPropertyChange` for EVERY `setProperty`, including one that writes the value already there, and an application-wide event filter sees every one of them there are eight of those, so each redundant write is eight Python calls through shiboken.

Measured on a window with two modules open: a repeat pass writes 5,820 stamps of which 5,820 are UNCHANGED. That is 100 %, on every pass after the first -- which is every preference save, every language change and every theme change that retranslates.
