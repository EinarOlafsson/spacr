# Paths a LIGHTWEIGHT source install leaves on the server.
#
# Instruction 328. A full checkout of spaCR is ~427 MB of tracked files on
# top of a multi-gigabyte history, and almost none of that is needed to
# RUN spaCR. This file lists what a source install can skip. It is read by
# packaging/install_from_source.sh and pinned by
# tests/packaging/test_the_lightweight_source_install_still_runs.py, so
# the script and the test can never drift apart.
#
# Syntax is git's sparse-checkout format: `/*` takes everything, and each
# `!` line takes a subtree back out again. Order matters -- the `/*` must
# come first.
#
# EVERY exclusion below has to be justified, because a wrong one produces
# an install that imports fine and then fails hours later on a code path
# nobody exercised during setup. The justifications are load-bearing; if
# one of them stops being true, the test fails.

/*

# --- Not shipped, not imported: development material only -----------------
#
# None of these are inside the `spacr` package, so nothing on an import
# path can reach them. `docs/` alone is 236 MB of built HTML and rendered
# figures that Read The Docs rebuilds from source anyway.
!/docs/
!/tests/
!/instructions/
!/Notebooks/
!/proposals/
!/tools/
!/data/
!/*.pdf

# --- Inside the package, but fetched or regenerated on demand -------------

# Cellpose checkpoints, ~25 MB. MANIFEST.in already carries
# `exclude spacr/resources/models/cp/*`, so these are NOT in the wheel
# either -- spaCR downloads the checkpoint it needs on first use. A source
# install that kept them would be carrying weight the pip install does not.
!/spacr/resources/models/

# ~90 archived renders of the README's home-screen figure, ~17 MB. They are
# the history of one picture, not an input to anything: the live figure is
# regenerated by packaging/generate_readme_visuals.py.
!/spacr/resources/home/versions/

# Superseded icon art, already `prune`d by MANIFEST.in.
!/spacr/resources/icons/backup_icons/

# The extended translation catalogs, 33 MB.
#
# THIS IS THE ONE EXCLUSION THAT COSTS THE USER SOMETHING, and it is opt-in
# to restore: install_from_source.sh --with-translations keeps it.
#
# Dropping it is safe because every `from .i18n_catalogs import ...` in
# spacr/qt/i18n.py is wrapped in `except (ImportError, AttributeError)`,
# and the comment there states the contract directly: "External catalogs
# add coverage; their absence must not make the compact core catalog
# unavailable." So the UI still translates -- through the compact core
# catalog built into i18n.py -- it simply covers fewer strings.
!/spacr/qt/i18n_catalogs/
