--------------------------------------------------------------------------------
A. THE THREE CHOICES
--------------------------------------------------------------------------------

  1. gRNAs -- only the objects annotated with the chosen guides.
  2. gRNAs + other datapoints in selected wells -- those objects AND every
     other object in the same wells. MISSING TODAY.
  3. All datapoints -- the whole table.

The middle one is the comparison that matters, and it is the one that is not
offered: it is what makes an effect readable as an effect. A guide's cells
against every cell in the screen compares two different experiments; a
guide's cells against their own well-mates compares two populations that
shared a plate, a day, a stain and an imaging session.

--------------------------------------------------------------------------------
B. WHAT A SELECTED WELL IS
--------------------------------------------------------------------------------

A selected well is a well containing one of the guides chosen on the volcano
plot. THE VOLCANO IS THE SELECTOR -- the same click that picks a point picks
the wells -- and the user can then narrow that set: "the user should be able
to choose a selection of these wells".

So the well set has two stages: derived from the guide selection, then
editable. Which means it must be VISIBLE. A set the user is invited to narrow
and cannot see is a set they cannot narrow.

Depends on instruction 206: with one guide selectable at a time, the well set
is whatever one guide touched.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

* All three choices are offered and each draws a different population.
* Choosing the middle one plots the guides' objects and their well-mates,
  distinguishable from each other on the plot.
* The selected wells are shown, and narrowing them narrows the plot.
* Selecting different guides on the volcano changes the wells.
* Zero selected guides is handled and says so rather than drawing everything
  or nothing.

DONE 2026-08-21

`spacr/well_scope.py` decides the population; the panel offers the three.

A SEPARATE BOX FROM THE CLASS FILTER. "Which objects are on the plot" and
"which of the classes on it to draw" are different questions, and one box
answering both would have a list whose entries mean two different things.

THE TWO SIDES ARE DISTINGUISHABLE. `select` marks each object `chosen gRNA`
or `well-mate` under the middle scope -- drawing them in one colour would
answer the question by hiding it, and the comparison IS the two populations
side by side.

THE WELL SET IS DERIVED THEN EDITABLE, and `None` is not `[]`. "Not narrowed
yet" and "narrowed to nothing" are different states, and the difference is
what lets a NEW guide selection re-derive rather than stay empty -- a
selection that stayed empty after the user picked a different point would
read as a broken click.

THE ORDER IS THE TABLE'S, not sorted, so a user narrowing the set sees the
wells in the order the screen was laid out.

NO SELECTION DRAWS NOTHING AND SAYS WHY. Falling back to the whole table
would look like a selection nobody made; an unknown scope raises for the
same reason, since silently drawing "all" would answer a different question
without saying so.

Instruction 206's multi-select is what makes the well set more than one
guide's wells.
