--------------------------------------------------------------------------------
THE BUMP
--------------------------------------------------------------------------------

    python packaging/release.py bump

Rules that already apply and are easy to get wrong:
  * bump the PATCH after a batch of work, never per commit;
  * smallest increment that is honest;
  * verify from a CLEAN worktree before pushing, not from this one -- this
    tree has had several agents in it and an uncommitted file would ship.

    git worktree add --detach /tmp/spacr-verify HEAD
    cd /tmp/spacr-verify && python -m pytest -q -m "not slow and not heavy"
