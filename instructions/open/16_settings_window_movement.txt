================================================================================
SETTINGS WINDOW: DRAGGING IT UN-MAXIMIZES THE MAIN WINDOW
================================================================================

Status:    not started
Requested: 2026-08-06 — "whenever i have a settings window up and try to move it the main app goes from full screen to boxed and the settings window is anchored to the middle of the window. i should be able to freely move the settings window irrespective of the main window state"

--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

Not investigated. The symptom — a child moving its parent, and the child
being pinned to the parent's centre — is what happens when a dialog is a
frameless child QWidget with a hand-rolled drag handler, rather than a real
top-level window.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Two bugs in one gesture: the main window loses its maximized state, and the
dialog cannot be placed where the user wants it.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Find the settings dialog (spacr/qt/screens/settings_model.py builds the
   panel; the dialog wrapper is elsewhere — also spacr/qt/preferences.py has
   a dialog worth comparing against).
2. Make it a true top-level: Qt.Window (or Qt.Dialog) with the main window as
   parent for ownership only, so it gets its own frame and its own position.
3. If the drag is hand-rolled, it must move the dialog's own windowHandle,
   never the parent's geometry.
4. Do not write real preferences while reproducing this (INVARIANTS §8) —
   point _settings at a temp QSettings first.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

Maximize the main window, open settings, drag the dialog: the main window
stays maximized and the dialog lands where it was dropped.
