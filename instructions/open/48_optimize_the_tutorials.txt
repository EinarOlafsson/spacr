WHAT THE STATE IS
--------------------------------------------------------------------------------

The generated tutorial library is present under
`docs/source/_extra/tutorials`: one HTML/CSS/JavaScript player, 40 catalogued
lessons, one poster and one silent 1440p MP4 per lesson, 54 narration voices
across eight languages with timing JSON, translated lesson/caption catalogs,
and 40 YouTube 4K links. The player synchronizes the separate narration and
silent video by playback rate and stores theme, progress, language, voice,
quality, and caption preferences in localStorage.

The full checked-in library is 2,879.2 MiB / 4,424 files. Sphinx does not copy
it directly: `tools/docs_media_budget.py` stages 603.3 MiB / 744 files, keeping
all lessons, videos, posters and captions plus the first voice in each
language as an offline fallback. All 54 voices and the 4K masters are served
from Hugging Face. `.github/workflows/docs.yml` builds on main and nightly but
deploys GitHub Pages only from main.

The documented editable source `/media/carruthers/mnt3/claude/tutorials/web/`
and `tools/publish_tutorials.py` are not present on this machine. A filesystem
search under `/mnt/firecuda2` found only the generated copies. The generated
bundle must not be optimized in place until the current source-of-truth
workspace is located, because the next publish would overwrite it.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Optimizing the derived repository copy would be overwritten by the next
publish. Media changes can also desynchronise video, narration, captions, and
scene timings or push GitHub Pages over its size ceiling.
