================================================================================
THE CELL TABLE'S BARS CARRY THE ERROR THE USER PICKS
================================================================================

Status:    filed 2026-08-21, not started.
Requested: 2026-08-21 -- "for the cell table graphs if bar is chosen the user
           should be able to choose SD, Var, or SEM error bars."
Owner:     Qt GUI (cell table graphs)

--------------------------------------------------------------------------------
WHAT IS ASKED
--------------------------------------------------------------------------------

A bar with no error bar is a mean presented as a fact. When the graph type is
Bar, the user picks what the whisker means: SD, variance, or SEM.

THEY ARE NOT INTERCHANGEABLE and the plot must say which one it drew. SD
describes the cells, SEM describes the confidence in their mean, and at
n=3000 they differ by a factor of fifty-five -- a reader who assumes the
wrong one reads a real effect as noise or noise as a real effect. The choice
goes in the axis label or the legend, not only in the settings dialog the
reader never opens.

SAME VOCABULARY AS INSTRUCTION 200, which asks for exactly this on the figure
settings ("for statistics with Bar: SD, SEM, var, etc."). One implementation,
used by both, or the two screens will disagree about what SEM means on the
same data.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

* Choosing Bar offers SD, variance and SEM, and the drawn whisker changes.
* The figure says which one it drew.
* The numbers are checked against a hand-computed case, not just asserted to
  be different from each other.
* The control is absent, not inert, for graph types that have no error bar.
