ATTRIBUTION, FIRST, BECAUSE IT GOVERNS EVERY ACTION IN THIS FILE
--------------------------------------------------------------------------------

"in my name" — the maintainer is the author of this work. So:

  * NO "Generated with Claude", no Co-Authored-By trailer, no AI attribution
    in a commit message, an issue comment, or a closing note. This matches
    the standing rule already in force for commits.
  * A closing comment says WHAT WAS WRONG and WHAT FIXED IT, with the commit
    SHA. It does not say who or what wrote it.
  * Write in the register the repository already uses. An issue comment is
    read by users, so it names the symptom they saw, not the internals.

fix is committed AND a test covers it. "I believe this is fixed" is not a
reason to close; it is a reason to comment.
