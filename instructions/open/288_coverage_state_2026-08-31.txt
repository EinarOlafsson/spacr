IMPORT-GUARD ARMS ARE NOT PINS: THE TECHNIQUE, AND THE CENSUS (2026-08-31)
==========================================================================

This file concluded that all 307 audited sites are unreachable by construction
and that the count "cannot fall without DELETING code". Import-guard arms were
misfiled into that set. They are conditional on the ENVIRONMENT rather than on
the source, which makes them look unreachable wherever the dependency happens
to be installed -- but a test can always make the import fail, so they are
testable items. Confirmed independently on both hosts, including on one where
the package IS installed.

THE TECHNIQUE, which is the general answer for the whole class:

    real = builtins.__import__
    def fake(module, globals=None, locals=None, fromlist=(), level=0):
        if module == name or module.startswith(name + "."):
            raise ImportError(f"blocked for the test: {name}")
        return real(module, globals, locals, fromlist, level)
    builtins.__import__ = fake        # drive the call, then restore

No uninstall, no venv, and no `sys.modules` surgery a later import can undo.
It works whether or not the package is present, which is the point: otherwise
the test passes for one reason here and another reason there.
