================================================================================
SURROGATE MODEL: EXPLAIN A CV CLASSIFIER WITH A FEATURE MODEL
================================================================================

Status:    not started
Requested: 2026-08-06 — "a module that can take a CV module, apply it to a dataset, merge the feature dataset with the CV class predictions then train a ML model that can give feature importance, also do permutation importance and shap feature importance ... an alternative surrogate model strategy to understanding what the model is looking at in addition to the activation map module"

--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

Nothing written. Existing pieces: spacr/deep_spacr.py (CV inference),
spacr/ml.py (classical ML), spacr/attribution.py + the Activation Maps
module, spacr/measure.py for the feature table.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Activation maps say WHERE the model looked. A surrogate model on measured
features says WHAT it responded to, in the units a biologist already
interprets (area, intensity, texture). The two answer different questions and
neither replaces the other.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Score the dataset with the chosen CV model -> per-object class/probability.
2. Join to the object feature table on the object key (see schema.py ::
   OBJECT_KEY_COLUMNS — do not join on png_path, it is not stable).
3. Train a gradient-boosted model to predict the CV prediction from features.
   Report its own accuracy FIRST: a surrogate that cannot reproduce the CV
   model's decisions explains nothing, and this is the number people skip.
4. Three importances: impurity/gain (cheap, biased to high-cardinality),
   permutation (on held-out data), and SHAP. Say in the output which is
   which — they disagree and the disagreement is informative.
5. Guard against leakage: features that are trivially the label (e.g. a
   channel intensity the classifier was trained on) will dominate.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

On a dataset with a known driver, the surrogate reproduces the CV model above
chance and ranks the known driver highly under all three methods.
