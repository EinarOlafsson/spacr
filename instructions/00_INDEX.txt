================================================================================
WHAT IS LEFT — INDEX
================================================================================

Written 2026-08-05. Every file here is one piece of unfinished work, with
enough context to pick it up cold.

Each file says the same four things: what the state is, why it matters,
what to do, and how to know it worked. Where something is NOT worth doing,
that is said too, with the reason -- a decision not to act is also a
result, and re-deriving it later costs the same as deriving it once.

--------------------------------------------------------------------------------
HOW THIS FOLDER WORKS
--------------------------------------------------------------------------------

    TEMPLATE.txt    the shape every task file takes
    open/           tasks not finished. One file per task, written BEFORE the
                    work starts, kept current WHILE it runs.
    done/           finished tasks, with what was actually done and how it
                    was verified.

A task the user asks for gets a file in open/ before any code is touched, and
moves to done/ when it is finished. That is not bookkeeping: a session that
runs out of context loses everything that existed only in the conversation.
`python skill/refresh.py` checks that every file in both folders still has its
sections and that nothing is in both at once.

The numbered files below (01-08) predate this and stay where they are.

--------------------------------------------------------------------------------
A NOTE ON THE TESTS IN HERE
--------------------------------------------------------------------------------

Several of these were found because a test was wrong rather than the code.
That happened often enough this week to be worth stating as a habit: when a
test and the product disagree, find out which one is describing reality
before changing either. Four separate "fixes" to the black box behind the
settings column were aimed at the wrong layer because an offscreen render
kept reporting a clean page for a screen that was black on the user's
display -- see 03 for why that measurement lies.
