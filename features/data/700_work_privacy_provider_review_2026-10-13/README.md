# N700 source-bound privacy and hosted-provider review

Current behavior uses authenticated GitHub reporting and three CLI AI providers.
The account-free relay and hosted provider remain unimplemented. This audit
supplies the requested proposed allowlist, redaction findings, offline test plan,
separate privacy drafts and seven integration seams.

The strict automatic-summary proposal admits reviewed enums, numeric versions
and public stack inventory IDs. It excludes free-form traceback text, settings,
logs, paths, chat history, AI replies and ZIP attachments. Size limits and schema
are proposals; no payload or transport acceptance is claimed.

Ten findings include shallow nested-settings sanitization, preview titles that
do not receive the body path toggle, user edits restored by diagnosis/toggles,
and raw traceback text reaching the selected provider despite show_raw=False.
The preview Cancel/timeout paths do not cancel provider transport. Local crash
ZIPs deliberately retain sensitive details and cannot be treated as anonymous
automatic reports. Twelve planted-data test families are specified but unrun.

An independent peer confirms only five qualified source-flow findings; it does
not certify the proposed schema, vendor policy, remaining findings or runtime.
Root rechecked 18 source/test bindings and all four core files against pinned
Home source. No real report, provider/auth call, key access, account setup, test,
installer, app/catalog edit or service deployment occurred. Home owns final
schema, implementation and destination disclosures after the release freeze.
