F549 native Micro-Manager demo acceptance, 2026-10-15

The recorded run used an isolated Python 3.12 venv with spaCR's installed
dependencies visible through --system-site-packages. No system packages or
existing microscope configuration were changed. Dependencies.json preserves
the actual downloaded wheels, versions and archive hashes. Native-run.json
records runtime versions and the exact spaCR source hash.

Use a private source worktree and a fresh scratch directory. The demonstrated
native backend is Linux-X64. Set these paths before running the commands:

  F549_ROOT=/path/to/private/spacr/worktree
  F549_SCRATCH=/path/to/new/scratch/directory
  F549_EVIDENCE=$F549_ROOT/features/data/549_micromanager_demo_2026-10-15

Create the isolated environment with the Python containing spaCR dependencies:

  mkdir -p "$F549_SCRATCH/tmp" "$F549_SCRATCH/pip-cache" "$F549_SCRATCH/xdg-data" "$F549_SCRATCH/xdg-config" "$F549_SCRATCH/xdg-cache"
  /home/olafsson/anaconda3/envs/spacr/bin/python -m venv --system-site-packages "$F549_SCRATCH/venv"
  export TMPDIR="$F549_SCRATCH/tmp" PIP_CACHE_DIR="$F549_SCRATCH/pip-cache"
  export XDG_DATA_HOME="$F549_SCRATCH/xdg-data" XDG_CONFIG_HOME="$F549_SCRATCH/xdg-config" XDG_CACHE_HOME="$F549_SCRATCH/xdg-cache"
  export CUDA_VISIBLE_DEVICES='' QT_QPA_PLATFORM=offscreen OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1

Run once, under the Home-B resource lock where that coordination applies:

  flock /mnt/wd4tb/scratch/home-b-coordination-20261014/heavy.lock tools/run_capped.sh 6G /usr/bin/time -v "$F549_SCRATCH/venv/bin/python" "$F549_EVIDENCE/replay.py" --root "$F549_ROOT" --adapters "$F549_SCRATCH/adapters/Micro-Manager-75.20261014.post1" --config "$F549_EVIDENCE/MMConfig_demo_minimal.cfg" --output "$F549_SCRATCH/run"

The output directory must not exist. The script verifies the configuration
contains only four DemoCamera software devices before starting an owned Python
headless backend. It checks that backend exists before asking spaCR to open
Core(), preventing fallback to an unrelated Java/server session. It unloads
the owned devices in finally and exits 0 only when the assertions pass.

Acceptance checks: two measurement fixtures selected, stage transform applied,
queue saved and reloaded, two events/four native camera TIFFs acquired, native
final XYZ read back, nonconstant uint16 pixels and TIFF XY metadata verified,
last TIFF equal to the native camera buffer, missing positions skipped, repeat
drain empty, devices unloaded, and owned process exited. The native shared
library mappings and hashes distinguish this from spaCR's simulator.

This run uses native MMCore with software demo devices. It does not validate
physical hardware, scientific hit detection, Java bridge behavior, vendor
metadata or .pos ingestion, or arbitration with a running plate acquisition.
Those boundaries are retained in receipt.json and the feature item.
