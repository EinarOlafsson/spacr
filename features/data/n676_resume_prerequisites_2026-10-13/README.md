paths. It checks 64 classifier crop/label/well bindings, the annotation database
and 2,341 crop paths, six external-mask field bindings, three model-comparison
fields, an investigation archive and six diagnostic panel sets. These are
metadata checks. Copied labels are not independently validated biology; three
training fields are not held-out model validation; complete diagnostic panels
do not establish a completed run. Every audited route remains unready to record.

The lesson 20 operational audit binds the current held integration interfaces
and existing wrappers. Resume requires a final source pin across all wrappers,
a new GNOME launcher, fresh complete accepted clips and scientific attribution,
English review before translation promotion, changed-sentence synthesis and a
verified voice matrix. The old r28 voice script promotes translations immediately
and cannot implement the required English-first sequence unchanged. Commands
in the JSON contain unresolved variables and are preparation only.

Routes 01, 02 and 06 need real GNOME browser or terminal capture. Installation
route 02 requires package/environment lifecycle actions prohibited by the
current session rules; historical verification footage cannot represent a new
installation. No exception has been requested or granted in this audit.

and full decoding but does not enforce the native/gate provenance added by the
lesson 20 helper. Each other remake still needs explicit capture acceptance.

`published: false`. Actual deployment and cache-root verification are separate.
