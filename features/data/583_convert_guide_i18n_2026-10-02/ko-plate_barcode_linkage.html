플레이트 바코드와 시료 메타데이터 연결¶

측정에서 Preferences의 알파 기능 표시를 활성화하고 Plate Barcode Linkage (Alpha)를 엽니다. plate_barcode_source를 테이블 또는 LIMS 서비스 URL로 설정합니다. 연결 작업은 측정 후에 실행됩니다.

로컬 CSV, TSV, Excel 또는 Parquet 테이블에는 바코드 열, 웰 열, 연결할 시료 메타데이터가 필요합니다. 예:

barcode,well,strain,compound,concentration
BC001,A01,RH,DMSO,0
BC001,A02,RH,pyrimethamine,2

바코드 열의 이름이 다르면 plate_barcode_column을 설정합니다. plate_barcodes는 촬영된 플레이트의 이름을 바코드에 매핑합니다. 이 매핑이 없으면 spaCR은 플레이트 폴더의 barcode.txt를 읽거나 플레이트 이름을 사용합니다. 메타데이터에는 농도의 의미를 알 수 있도록 단위를 유지하세요.

변환 중 연결¶

변환에서 알파 기능 표시를 활성화하고 플레이트 바코드 연결 (알파)에서 로컬 샘플 기록 CSV를 선택하세요. CSV에는 바코드 열, 웰 열, 플레이트 맵에 넣으려는 샘플 필드가 필요합니다. 미리보기는 이미지를 쓰기 전에 연결을 검증합니다. 변환은 미리보기에 표시된 출력 플레이트 이름을 사용하며, 이 이름은 소스 폴더 이름과 다를 수 있습니다.

출력 플레이트 바코드를 plate1=BC001; plate2=BC002 형식으로 지정하거나, 획득 데이터의 루트 폴더 또는 실제 소스 플레이트 폴더에 UTF-8 barcode.txt 파일을 두세요. 바코드 하나만 들어 있는 파일은 해당 폴더에 소스 플레이트가 하나일 때만 적용됩니다. 플레이트가 여러 개이면 플레이트마다 source_plate=barcode 항목을 작성하고 줄바꿈이나 세미콜론으로 구분하세요. 이 키는 원래 소스 플레이트 이름입니다. 변환에서 직접 지정하는 항목은 출력 플레이트 이름을 사용하며, 나머지 플레이트의 바코드를 채울 수 있습니다. spaCR는 앞자리의 0을 보존하고 모호하거나 서로 불일치하는 지정을 거부하며, 모든 출력 플레이트에 바코드를 요구합니다.

변환이 완전히 끝나면 대상 폴더의 plate_barcode_linkage/plate_map_lims.csv 파일을 읽으세요. 같은 위치의 plate_barcode_mismatches.csv 파일에서 일치하지 않는 웰과 기타 불일치를 확인하세요. complete.json 기록 파일은 마지막에 작성되며, 이 파일이 없으면 연결 묶음이 불완전하다는 뜻입니다. 변환 화면에는 개수가 제한된 불일치 미리보기와 두 CSV 파일의 경로가 표시됩니다. 원본 이미지, 바코드 파일, 사용자의 기존 플레이트 맵은 바뀌지 않습니다. 이 변환 경로는 로컬 CSV를 받습니다. HTTP LIMS 서비스를 이용하려면 측정을 사용하세요.

LIMS 서비스에서 레코드 읽기¶

https://lims.example/plates/{barcode}/wells 같은 URL을 사용합니다. spaCR은 인코딩된 바코드를 대입합니다. {barcode}가 없으면 barcode 쿼리 매개변수를 추가합니다. 인증이 필요하면 토큰을 환경 변수에 저장하고, 해당 변수의 이름을 plate_barcode_token_env에 입력합니다. 토큰 자체를 URL이나 설정에 넣지 마세요.

서비스는 웰 레코드 목록이나, wells, records, results, data, items 중 하나의 키 아래에 그 목록을 담은 객체를 반환할 수 있습니다. 목록 바깥의 일반 필드는 해당 웰들의 메타데이터 기본값을 제공합니다:

{
  "strain": "RH",
  "wells": [{"well": "A01", "compound": "DMSO"}],
  "next": "?page=2"
}

spaCR은 next, next_url, @odata.nextLink, links.next``를 따릅니다. 링크는 URL 문자열이거나 ``href 필드가 있는 객체일 수 있습니다. 상대 링크는 응답 URL을 기준으로 해석합니다. 링크가 없거나 null 또는 빈 문자열이면 목록이 끝납니다. 메타데이터 기본값은 다음 페이지에도 이어지며, 웰에 명시된 필드는 그 기본값보다 우선합니다. 페이지 탐색 필드는 시료 메타데이터에 포함되지 않습니다.

모든 링크와 HTTP 리디렉션은 최초 서비스와 같은 스킴, 호스트, 포트를 유지해야 합니다. 충돌하는 링크와 반복되는 페이지는 오류입니다. 수집량은 응답당 16 MiB, 전체 조회당 64 MiB, 바코드당 페이지 주소 1,000개, 전체 조회당 레코드 100,000개로 제한됩니다. 오류가 발생하면 부분적인 플레이트 맵을 반환하지 않고 메타데이터 조회를 중단합니다. 기존 측정 결과는 계속 사용할 수 있습니다. 다음 페이지 URL을 제공하지 않는 공급업체별 커서 프로토콜에는 별도의 어댑터가 필요합니다.

결과 확인¶

완성된 맵은 measurements/plate_map_lims.csv에 저장됩니다. profiling_metadata 설정이 비어 있으면 이 맵으로 채웁니다. 화합물과 농도 열이 있으면 비어 있는 viability_plate_map도 채웁니다. 사용자가 이미 제공한 맵은 조용히 교체하지 않고 비교합니다.

measurements/plate_barcode_mismatches.csv와 로그에서 누락된 바코드, 여러 플레이트가 공유하는 바코드, 일치하지 않는 웰, 충돌하는 레코드, 기존 맵과의 불일치를 검토합니다. 처리 조건 간 비교를 해석하기 전에 이러한 불일치를 해결하세요.
