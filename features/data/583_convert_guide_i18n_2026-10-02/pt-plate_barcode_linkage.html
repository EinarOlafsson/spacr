Vincular códigos de barras de placas aos metadados de amostras¶

Em Medição, ative Mostrar recursos alfa nas Preferências e abra Plate Barcode Linkage (Alpha). Defina plate_barcode_source como uma tabela ou uma URL de serviço LIMS. A vinculação ocorre após a medição.

Uma tabela local CSV, TSV, Excel ou Parquet precisa de uma coluna de código de barras, uma coluna de poço e os metadados de amostra a anexar. Por exemplo:

barcode,well,strain,compound,concentration
BC001,A01,RH,DMSO,0
BC001,A02,RH,pyrimethamine,2

Defina plate_barcode_column se a coluna de código de barras tiver outro nome. plate_barcodes associa o nome de uma placa fotografada ao seu código de barras. Caso contrário, o spaCR lê barcode.txt na pasta da placa ou usa o nome da placa. Mantenha unidades de concentração significativas nos metadados.

Vinculação em Converter¶

Em Converter, ative Mostrar recursos alfa e escolha um CSV local de registros de amostras em Vinculação de placas por código de barras (Alpha). O CSV precisa de uma coluna de código de barras, uma coluna de poço e dos campos de amostra que você deseja incluir no mapa da placa. A prévia valida a vinculação antes de gravar imagens. Converter usa os nomes das placas de saída mostrados na prévia; eles podem ser diferentes dos nomes das pastas de origem.

Atribua códigos de barras às placas de saída no formato plate1=BC001; plate2=BC002, ou coloque um arquivo barcode.txt em UTF-8 na raiz da aquisição ou em uma pasta real de placa de origem. Um arquivo que contém apenas um código de barras sem atribuição só se aplica quando essa pasta contém uma única placa de origem. Para várias placas, escreva uma entrada source_plate=barcode por placa, separada por quebras de linha ou ponto e vírgula; as chaves são os nomes originais das placas de origem. As atribuições explícitas em Converter usam os nomes das placas de saída e podem completar as placas restantes. spaCR preserva os zeros à esquerda, rejeita atribuições ambíguas ou contraditórias e exige um código de barras para cada placa de saída.

Após uma conversão completa, leia plate_barcode_linkage/plate_map_lims.csv no destino. Consulte plate_barcode_mismatches.csv nesse local para ver poços sem correspondência e outras divergências. O registro de conclusão complete.json é gravado por último; sua ausência significa que o pacote de vinculação está incompleto. A tela Converter mostra uma prévia limitada das divergências e os caminhos dos dois arquivos CSV. As imagens originais, os arquivos de códigos de barras e os mapas de placas existentes do usuário permanecem inalterados. Esse fluxo de Converter aceita um CSV local; use Medição para um serviço HTTP LIMS.

Ler registros de um serviço LIMS¶

Use uma URL como https://lims.example/plates/{barcode}/wells. O spaCR insere o código de barras codificado. Sem {barcode}, acrescenta um parâmetro de consulta barcode. Se for necessária autenticação, coloque o token em uma variável de ambiente e informe o nome dessa variável em plate_barcode_token_env. Não coloque o token na URL nem nas configurações.

O serviço pode retornar uma lista de registros de poços ou um objeto que contenha essa lista em wells, records, results, data ou items. Campos simples fora da lista fornecem valores padrão de metadados para seus poços:

{
  "strain": "RH",
  "wells": [{"well": "A01", "compound": "DMSO"}],
  "next": "?page=2"
}

O spaCR segue next, next_url, @odata.nextLink ou links.next. O link pode ser uma string de URL ou um objeto com um campo href. Links relativos são resolvidos com base na URL da resposta. Um link ausente, null ou uma string vazia encerra a lista. Os valores padrão de metadados são mantidos nas páginas seguintes; campos explícitos de um poço substituem esses valores. Campos de paginação não se tornam metadados de amostras.

Cada link e redirecionamento HTTP deve manter o mesmo esquema, host e porta do serviço original. Links conflitantes e páginas repetidas são erros. A coleta é limitada a 16 MiB por resposta, 64 MiB por consulta, 1.000 endereços de páginas por código de barras e 100.000 registros por consulta. Um erro interrompe a consulta de metadados sem retornar um mapa parcial da placa. Os resultados de medição existentes continuam disponíveis. Protocolos de cursor específicos de fornecedores que não oferecem uma URL para a próxima página precisam de um adaptador separado.

Inspecionar o resultado¶

O mapa preenchido é gravado em measurements/plate_map_lims.csv. Ele preenche a configuração profiling_metadata se estiver vazia. Quando existem colunas de composto e concentração, também preenche viability_plate_map se estiver vazia. Um mapa existente fornecido pelo usuário é comparado, não substituído silenciosamente.

Revise measurements/plate_barcode_mismatches.csv e o registro em busca de códigos de barras ausentes ou compartilhados, poços sem correspondência, registros conflitantes e divergências em relação a um mapa existente. Resolva essas divergências antes de interpretar comparações entre tratamentos.
