Vincular códigos de barras de placas con metadatos de muestras¶

En Medición, active Mostrar funciones alfa en Preferencias y abra Plate Barcode Linkage (Alpha). Establezca plate_barcode_source en una tabla o en la URL de un servicio LIMS. La vinculación se ejecuta después de la medición.

Una tabla local CSV, TSV, Excel o Parquet necesita una columna de código de barras, una columna de pocillo y los metadatos de muestra que se adjuntarán. Por ejemplo:

barcode,well,strain,compound,concentration
BC001,A01,RH,DMSO,0
BC001,A02,RH,pyrimethamine,2

Establezca plate_barcode_column si su columna de código de barras tiene otro nombre. plate_barcodes relaciona el nombre de una placa fotografiada con su código de barras. De lo contrario, spaCR lee barcode.txt en la carpeta de la placa o utiliza el nombre de la placa. Conserve unidades de concentración significativas en los metadatos.

Vinculación en Convertir¶

En Convertir, active Mostrar funciones alfa y elija un CSV local de registros de muestras en Vinculación de placas por código de barras (Alpha). El CSV necesita una columna de código de barras, una columna de pocillo y los campos de muestra que desee incluir en el mapa de placa. La vista previa valida la vinculación antes de escribir imágenes. Convertir utiliza los nombres de las placas de salida que aparecen en su vista previa; pueden diferir de los nombres de las carpetas de origen.

Asigne códigos de barras a las placas de salida con el formato plate1=BC001; plate2=BC002, o coloque un archivo barcode.txt en UTF-8 en la raíz de la adquisición o en una carpeta real de placa de origen. Un archivo que contiene un único código de barras sin asignación solo se aplica cuando esa carpeta contiene una única placa de origen. Para varias placas, escriba una entrada source_plate=barcode por placa, separadas por saltos de línea o puntos y coma; las claves son los nombres originales de las placas de origen. Las asignaciones explícitas en Convertir utilizan los nombres de las placas de salida y pueden completar las placas restantes. spaCR conserva los ceros iniciales, rechaza las asignaciones ambiguas o contradictorias y exige un código de barras para cada placa de salida.

Tras una conversión completa, lea plate_barcode_linkage/plate_map_lims.csv en el destino. Revise allí plate_barcode_mismatches.csv para ver los pocillos sin correspondencia y otras discrepancias. El registro de finalización complete.json se escribe al final; su ausencia significa que el paquete de vinculación está incompleto. La pantalla Convertir muestra una vista previa limitada de las discrepancias y las rutas de ambos archivos CSV. Las imágenes originales, los archivos de códigos de barras y los mapas de placa existentes del usuario permanecen sin cambios. Esta ruta de Convertir acepta un CSV local; utilice Medición para un servicio HTTP LIMS.

Leer registros de un servicio LIMS¶

Utilice una URL como https://lims.example/plates/{barcode}/wells. spaCR sustituye el código de barras codificado. Sin {barcode}, añade un parámetro de consulta barcode. Si se necesita autenticación, guarde el token en una variable de entorno e indique su nombre en plate_barcode_token_env. No incluya el token en la URL ni en los ajustes.

El servicio puede devolver una lista de registros de pocillos o un objeto que contenga esa lista bajo wells, records, results, data o items. Los campos simples fuera de la lista proporcionan metadatos predeterminados para sus pocillos:

{
  "strain": "RH",
  "wells": [{"well": "A01", "compound": "DMSO"}],
  "next": "?page=2"
}

spaCR sigue next, next_url, @odata.nextLink o links.next. El enlace puede ser una cadena URL o un objeto con un campo href. Los enlaces relativos se resuelven con respecto a la URL de la respuesta. Un enlace ausente, null o una cadena vacía finaliza la lista. Los metadatos predeterminados se mantienen en las páginas siguientes; los campos explícitos de un pocillo prevalecen sobre esos valores. Los campos de paginación no se convierten en metadatos de muestra.

Cada enlace y redirección HTTP debe mantener el mismo esquema, servidor y puerto que el servicio original. Los enlaces contradictorios y las páginas repetidas son errores. La recopilación se limita a 16 MiB por respuesta, 64 MiB por consulta, 1.000 direcciones de página por código de barras y 100.000 registros por consulta. Un error detiene la consulta de metadatos sin devolver un mapa de placa parcial. Los resultados de medición existentes siguen disponibles. Los protocolos de cursor específicos de un proveedor que no facilitan una URL de página siguiente necesitan un adaptador independiente.

Inspeccionar el resultado¶

El mapa completo se escribe en measurements/plate_map_lims.csv. Rellena el ajuste profiling_metadata si está vacío. Cuando existen columnas de compuesto y concentración, también rellena viability_plate_map si está vacío. Un mapa existente proporcionado por el usuario se compara, no se sustituye silenciosamente.

Revise measurements/plate_barcode_mismatches.csv y el registro para detectar códigos de barras ausentes o compartidos, pocillos sin correspondencia, registros contradictorios y discrepancias con un mapa existente. Resuelva esas discrepancias antes de interpretar comparaciones entre tratamientos.
