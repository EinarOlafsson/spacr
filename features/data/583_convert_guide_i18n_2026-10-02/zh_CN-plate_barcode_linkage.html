将板条码与样本元数据关联¶

在 测量 中，先在 Preferences 中启用 显示 Alpha 功能，再打开 Plate Barcode Linkage (Alpha)。将 plate_barcode_source 设为一个表或 LIMS 服务 URL。关联步骤在测量完成后运行。

本地 CSV、TSV、Excel 或 Parquet 表需要条码列、孔位列以及要附加的样本元数据。例如:

barcode,well,strain,compound,concentration
BC001,A01,RH,DMSO,0
BC001,A02,RH,pyrimethamine,2

如果条码列使用其他名称，请设置 plate_barcode_column。plate_barcodes 将成像板的名称映射到其条码。否则，spaCR 会读取板文件夹中的 barcode.txt，或使用板名称。请在元数据中保留有意义的浓度单位。

转换时关联¶

在 转换 中，启用 显示 Alpha 功能，然后在 板条码关联（Alpha） 中选择本地样本记录 CSV。CSV 需要包含条形码列、孔位列，以及您希望填入板图的样本信息列。预览会在写入图像之前验证关联。转换使用预览中显示的输出板名称；这些名称可能与源文件夹名称不同。

按 plate1=BC001; plate2=BC002 的格式分配输出板条形码，或在采集根目录或实际源板文件夹中放置一个 UTF-8 编码的 barcode.txt 文件。只包含一个纯条形码的文件，仅适用于该文件夹中只有一个源板的情况。有多个板时，为每个板填写一条 source_plate=barcode 记录，以换行或分号分隔；这些键是 原始来源 的板名称。转换中的显式分配使用 输出 板名，可用于补齐其余板的条形码。spaCR 保留前导零，拒绝含义不明确或相互冲突的分配，并要求每个输出板都有条形码。

转换完整完成后，读取目标目录中的 plate_barcode_linkage/plate_map_lims.csv 。在同一位置检查 plate_barcode_mismatches.csv ，了解未匹配的孔位及其他不一致情况。complete.json 凭据最后写入；缺少该文件表示关联数据包尚未完整生成。转换界面显示限定数量的不匹配项预览，以及两个 CSV 文件的路径。原始图像、条形码文件和用户已有的板图均保持不变。此转换流程接受本地 CSV；如需使用 HTTP LIMS 服务，请使用测量。

从 LIMS 服务读取记录¶

使用类似 https://lims.example/plates/{barcode}/wells 的 URL。spaCR 会替换为经过编码的条码。如果没有 {barcode}，则添加 barcode 查询参数。如果需要身份验证，请将令牌放入环境变量，并将该变量的名称填入 plate_barcode_token_env。不要将令牌放入 URL 或设置中。

服务可以返回孔记录列表，也可以返回一个对象，将列表放在 wells、records、results、data 或 items 下。列表之外的普通字段为其中各孔提供元数据默认值:

{
  "strain": "RH",
  "wells": [{"well": "A01", "compound": "DMSO"}],
  "next": "?page=2"
}

spaCR 会跟随 next、next_url、@odata.nextLink 或 links.next。链接可以是 URL 字符串，也可以是含 href 字段的对象。相对链接根据响应 URL 解析。链接缺失、为 null 或为空字符串时，列表结束。元数据默认值会延续到后续页面；孔记录中明确给出的字段会覆盖这些默认值。分页字段不会成为样本元数据。

每个链接和 HTTP 重定向必须与原始服务保持相同的协议、主机和端口。链接冲突或页面重复均视为错误。收集限制为每个响应 16 MiB、整个查询共 64 MiB、每个条码 1,000 个页面地址，以及整个查询共 100,000 条记录。出现错误时会停止元数据查询，不返回不完整的板映射。现有测量结果仍然可用。不提供下一页 URL 的供应商专用游标协议需要单独的适配器。

检查结果¶

填好的映射写入 measurements/plate_map_lims.csv。它会填充空的 profiling_metadata 设置。如果存在化合物和浓度列，还会填充空的 viability_plate_map。对于用户已提供的映射，只进行比较，不会静默替换。

检查 measurements/plate_barcode_mismatches.csv 和日志，查找缺失条码、共用条码、未匹配孔、冲突记录，以及与现有映射不一致的情况。在解读处理条件之间的比较前，请先解决这些差异。
