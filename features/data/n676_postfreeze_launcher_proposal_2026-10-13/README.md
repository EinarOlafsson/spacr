# Prepared source-pinned launcher for the post-release recording

These text copies make the external launcher reviewable. It requires an explicit
isolated final worktree and exact clean revision, puts that worktree first for
app imports, removes the editable finder and checks the actual spaCR import.
It reuses the existing private GNOME driver, rejects desktop display :0 and
requires a fresh external stage and live matching GPU scheduler holder.

Only AST parsing and shell syntax were checked. No queue, host, GPU turn or
recording was launched; no final app revision is selected. Existing capture,
ready and integration worktrees remain unchanged. Holder matching is a
preflight safeguard, not independent proof of scheduler lock ownership.

Before use, root must receive Home release done and final Workbench source,
recheck final interfaces, hold an appropriate RAM lease for the 12G cap, verify
source propagation into every wrapper, and run alone through gpu_turn with its
unchanged idle/gap guards. The command proposal contains unresolved placeholders
and does not authorize immediate execution or establish capture acceptance.
