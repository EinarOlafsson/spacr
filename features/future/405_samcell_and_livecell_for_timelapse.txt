--------------------------------------------------------------------------------
WHAT IT IS, READ FROM THE REPOSITORY 2026-09-14
--------------------------------------------------------------------------------

github.com/saahilsanganeriya/SAMCell. Label-free biological cell
segmentation on Meta's Segment Anything backbone -- SAM-Base (ViT-B), 89M
parameters, encoder pretrained on 11M images. MIT licence.

    pip install samcell
    samcell segment image.png --model samcell-generalist.pt
    samcell.FinetunedSAM() ; samcell.SAMCellPipeline()

Dependencies: Python >= 3.8, torch >= 1.9, transformers >= 4.26, OpenCV >= 4.5,
scikit-image >= 0.19, pandas >= 1.3.

TRAINED ON LIVECELL, which is the whole reason this item exists: 5,000+
PHASE-CONTRAST images across 8 cell types, plus Cellpose Cytoplasm (~600
images from diverse sources). Two checkpoints ship, SAMCell-Generalist and
SAMCell-Cyto.

AN EARLIER DRAFT OF THIS FILE POINTED AT THE WRONG REPOSITORY --
github.com/NathanMalta/SAMCell, which has no README -- and said so rather than
guessing at its contents. The maintainer supplied the right one. Recorded
because "the repository has no README" was a true statement about the wrong
project, and a true statement about the wrong thing is the most convincing
kind of wrong.

--------------------------------------------------------------------------------
WHY TIMELAPSE SPECIFICALLY
--------------------------------------------------------------------------------

Every Cellpose model in spaCR's zoo is fluorescence-oriented and all three
published entries are Toxoplasma-specific. Timelapse is routinely
phase-contrast or brightfield, so a live-cell run today asks a fluorescence
model to do something it was not trained for.

AND A SEGMENTATION FAILURE IN TIMELAPSE COMPOUNDS RATHER THAN STAYING LOCAL.
A single bad frame is one bad measurement. A model that is systematically
weaker on label-free images produces a track that breaks, and a broken track
is a lineage error that propagates through every downstream number. That is
why the maintainer's "especially for timelapse" is the right emphasis, and why
the scorecard for this one has to count SPLITS AND MERGES rather than only
Dice -- those are the failures that break a track.

--------------------------------------------------------------------------------
WHAT TO BUILD
--------------------------------------------------------------------------------

  * ONE BACKEND SEAM SHARED WITH 404. `ModelEntry.kind` is already the
    discriminator -- 'cellpose' and 'detector' both exist. DINOCell emits
    Cellpose-style flows and may need no new mask path at all; SAMCell emits
    masks through `SAMCellPipeline`, so IT is the one that decides whether a
    second path is needed. Establish that before writing either.
  * AN OPTIONAL DEPENDENCY, not a core one. `samcell` pulls torch,
    transformers and a ViT checkpoint. A user who never opens it must not pay
    for it: item 282's lazy-import discipline is the standard, and
    `tests/test_perf_guard.py` is what enforces it by asserting the module is
    absent from `sys.modules` after the Qt launch path.
  * BOTH CHECKPOINTS IN THE ZOO, named for what they were trained on.
    Generalist and Cyto are different answers and a user choosing between them
    needs to know which is which -- `ModelEntry.trained_on` is where that
    goes, as it already does for the three Toxoplasma entries.

--------------------------------------------------------------------------------
HOW IT WILL BE CHECKED
--------------------------------------------------------------------------------

A phase-contrast or brightfield timelapse runs end to end and produces tracks,
with no import of `samcell` in a process that does not use it. And a scorecard
-- `spacr/scorecard.py`, which already scores Dice, IoU, boundary F1, AUPRC
and splits/merges -- against a labelled held-out set OF THE SAME MODALITY,
published beside whatever Cellpose scores on the same frames.

The comparison is the deliverable. "Better on label-free" is the claim, and a
number measured on fluorescence data does not test it.

The held-out set is being labelled for the purpose (see 370); the integration
can land before it, the RECOMMENDATION cannot.
