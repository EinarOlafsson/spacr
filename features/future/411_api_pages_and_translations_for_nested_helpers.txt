HOW IT MUST BE DONE WHEN IT IS PICKED UP
--------------------------------------------------------------------------------

  * IN SLICES, BY MODULE. Each slice is rendered, then its blocks are
    translated and reviewed, before the next slice. A bad slice is reverted
    alone.
  * NO REPAIR RUN AS THE TRANSLATION. The 2026-09-15 GPU pass was 78% wrong on
    API blocks (615 of 788; inserted parliamentary transcripts, "beef" for a
    digest, inverted negations). Machine draft, then read every block against
    its English, then author reviewed records -- the only order that ends with
    something true.
  * THE DOCS AUDIT FAILS CLOSED ON BLOCKS LEFT IN ENGLISH. Rendering a slice
    before its translations exist turns docs red unless the slice carries an
    explicit, dated exemption that the audit prints on every run.
  * Every pin that counts rendered symbols moves with each slice, proved by
    subtraction (the AutoAPI pre-filter constant among them).
