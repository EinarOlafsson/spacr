--------------------------------------------------------------------------------
WHAT IT IS FOR, TWO USES OF ONE ANNOTATION
--------------------------------------------------------------------------------

1. AN OPTIONAL "IS THIS OBJECT REAL" CLASSIFIER AFTER DETECTION. For each of the
   cross-channel models (toxoplasma_from_hoechst, toxoplasma_from_cellmask,
   cell_from_hoechst, nuclei_from_cellmask) a small classifier, trained on the
   maintainer's real / not-real calls, that a user can switch on after object
   detection to drop false objects. It fits spaCR's existing post-detection
   step (spacr.object_classifier, item 449: classify_objects / remove_labels)
   and should ship in the Model Zoo beside the model it cleans up after, with a
   scorecard like every other model (item 370).

2. CLEANING THE TRAINING DATA. The same calls, per label, say which masks in
   the training sets are wrong. Labels judged "not real" are removed from the
   ground truth (the field keeps its other labels; a field left with nothing is
   dropped or kept as an honest negative), the datasets are republished as a
   new version, and the models are retrained on the cleaned sets.

--------------------------------------------------------------------------------
THE CROPS
--------------------------------------------------------------------------------

One crop per ground-truth OBJECT, for EVERY field of each dataset, each crop
with the SAME THREE CHANNELS whatever the model's input was:

    Hoechst (nucleus stain), Toxoplasma (parasite stain), CellMask (cell stain)

    object set             masks it is cut from                  datasets
    Toxoplasma PV objects  the parasite/PV target masks          toxoplasma_from_hoechst,
                                                                 toxoplasma_from_cellmask
    cell objects           the cell target masks                 cell_from_hoechst
    nucleus objects        the nucleus target masks              nuclei_from_cellmask

The two Toxoplasma sets share their fields and targets (both learn the same
parasite masks from different inputs), so their PV crops should be cut ONCE
and shared, with each crop recording which datasets it belongs to -- otherwise
the same parasite is annotated twice.

SIZES, from the datasets' own counts: 3,030 fields in each Toxoplasma set and
3,029 each in the cell and nucleus sets, host cells balanced over HFF (~4,000),
HeLa (~4,060) and THP-1 (~4,058) per the project's START_HERE; tens of objects
per field for PV and nuclei and hundreds for cells (fields.csv n_objects, e.g.
292 cells in one CSA field). Expect several hundred thousand crops: this needs
a batching, resumable job, and annotation needs to be efficient (below).

--------------------------------------------------------------------------------
HOW IT SHOULD BE BUILT
--------------------------------------------------------------------------------

  * spaCR's own Measure crops, not a new cutter: rebuild each field as a merged
    array with the three channels plus the one mask, name it the way Measure
    reads (<experiment>-<plate>_<well>_<field>, as build_pv_count_dataset does,
    item 449), and let Measure write one PNG per object with measurements.db
    indexing them -- then Annotate opens the set directly (png_list), and the
    annotations land in the database the classifier trains from.
  * Keep each crop traceable to (dataset, field stem, label id), so a "not real"
    call can be turned back into "remove label N from mask M" in step 2.
  * Crop size and padding per object type (a cell needs more context than a
    nucleus); record the choice.
  * One folder per dataset and plate, as for item 449, so annotation can be
    split and resumed.
  * Resumable and memory-capped (tools/run_capped.sh); CPU is enough -- no GPU.

ANNOTATION AT THIS SCALE. Several hundred thousand crops cannot all be judged
by eye. Worth deciding before cutting: annotate a stratified sample (by screen,
host cell, plate, object size, the model's own confidence) and let the first
classifier propose calls for the rest, reviewing the doubtful ones (active
learning); or annotate everything in Annotate's fast multi-select mode. The
maintainer's call.

THE CLASSIFIER. One per object type (PV, cell, nucleus), trained on the
real/not-real annotations with spaCR's Classify (image crops, three channels),
a split grouped by WELL as every spaCR split is (item 94), a held-out score
recorded as the model's scorecard, and an option in Mask generation / the
cross-channel models' use to drop objects the classifier calls not real, with
its threshold.

--------------------------------------------------------------------------------
DONE WHEN
--------------------------------------------------------------------------------

  * Crops exist for every object of every field of the four datasets, three
    channels each, indexed in a measurements.db per plate, opening in Annotate.
  * The maintainer has annotated them (or the chosen sample).
  * A real/not-real classifier per object type is trained, scored on held-out
    wells, published to the Model Zoo, and selectable after detection.
  * The labels called not real are removed from the datasets, the cleaned
    datasets are republished as a new version, and the cross-channel models are
    retrained on them and scored against the old ones.

PROGRESS 2026-09-21
--------------------------------------------------------------------------------

  1. STACKS (tools/build_ground_truth_crop_stacks.py). One (H, W, 6) uint16
     stack per field -- hoechst, toxoplasma, cellmask, cell mask, nucleus mask,
     PV mask -- in <root>/<plate>/merged, root
     /mnt/wd4tb/af3/projects/cross_channel_models/ground_truth_crops, with a
     fields.csv per plate tying each spaCR field name to the dataset stem and
     the datasets that hold it. 3,719 fields over 12 experiment-plates. The
     Toxoplasma plane is local (data/_dsred_source) for every field sampled;
     the NAS fallback is there for any that are not. A mask a field's datasets
     did not draw is written empty, so that field gives no crop of that type.

  2. CROPS (tools/measure_ground_truth_crops.py). Measure, ONE OBJECT TYPE PER
     RUN: the three ground-truth masks come from different datasets and do not
     nest (a PV straddling two ground-truth cells made Measure refuse the
     field), so each type is measured alone under <root>/<type>/<plate>. No
     size filters, no edge-cell merging, uninfected kept, heavy measurements
     off. Verified on 6 fields: crops per type EQUAL the labels per mask
     (CSA plate1: 76 PV / 292 cell / 306 nucleus; THP1 PLATE1: 66 / 173 /
     169). Crops are full resolution, not resized, RGB = CellMask / Toxoplasma
     / Hoechst, windowed and rimmed per type from measured object extents
     (PV 128 px, rim 1.5 x sqrt(area); nucleus 128 px, 0.5; cell 320 px, 0.3)
     so each label is judged with its surroundings. png_list in each
     measurements.db, so the crops open in Annotate.

  Next: the full crop run over every plate, then the maintainer's annotation.
