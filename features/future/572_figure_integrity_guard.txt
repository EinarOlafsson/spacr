FIGURE-INTEGRITY GUARD: DISPLAY RANGES, SATURATION, LOSSY FORMATS, PROVENANCE

Status: IMPLEMENTED AS ALPHA 2026-09-26 (see the note of that date). A
checked export in spacr.plot.save_figure (and the Save figure dialog) warns
on mismatched display ranges, saturation/clipping, repeated panels and lossy
formats, and stamps provenance into the file metadata and a sidecar.
Owner: unassigned. From the 2026-09-26 non-GPU list. Ships as an ALPHA feature (features/README.md, item 569): hidden unless Preferences -> Show alpha features is on.

WHAT TO BUILD
    When exporting image figures and montages, warn when panels meant for
    comparison use different display ranges, when pixels are saturated, when
    a lossy format is chosen for quantitative images, and stamp provenance
    (source files, display settings, processing steps, spaCR version) into
    the exported file's metadata and a sidecar.

DONE WHEN
    Exports with mismatched ranges or saturation raise the warning; the
    provenance sidecar reproduces the panel from the source files.

NOTE 2026-09-26 -- BUILT, AS AN ALPHA FEATURE

What was built (no new module; all in spacr/plot.py as private helpers)
    save_figure(..., integrity=None) runs the check before writing when it
      is switched on: integrity=True/False decides, else the environment
      variable SPACR_FIGURE_INTEGRITY=1/0, else the Preferences toggle
      (off by default). A figure with no image panel (AxesImage of at
      least 16x16 px) is written exactly as before, with no sidecar.
    Checks, per figure (_integrity_report):
      display_range -- panels in one comparison group whose low or high
        display limits spread by more than 5 % of the combined range. Group
        = an explicit compare name, else the channel label of a traced
        panel, else (untagged single-channel panels of >= 64x64 px) the
        colour map. Untagged RGB panels have their range baked in and are
        not compared.
      saturation -- warning when > 0.1 % of source pixels sit at the
        integer type's ceiling (detector saturation), or > 5 % are above
        the top of the display range (clipped). On an untagged RGB panel
        the clip measure cannot tell saturation from annotation colours, so
        it is a note there.
      duplicate -- identical displayed arrays, or thumbnails (32x32)
        correlating >= 0.97 AND 96x96 high-pass texture >= 0.2, both at the
        best of the eight flips/rotations; invariant to linear contrast.
        Same-source panels are reported as a note (declared reuse).
      lossy_format -- JPEG/WebP/GIF/HEIC/AVIF written (warning) or asked for
        and redirected to PNG/PDF (note).
      resampling -- note when a panel is written with fewer than half its
        pixels per side.
    Provenance: every panel's shape, dtype, cmap, clim, interpolation,
      display range (source units when traced), clip/saturation fractions,
      SHA-256 of the displayed array, source files (path, size, full
      SHA-256 up to 256 MiB), processing steps, and figure-level spaCR /
      matplotlib / numpy / python versions, format, DPI and the open
      run_journal run (dir, app, manifest.json path). Stamped into the
      file: PNG text chunk "spaCR provenance", PDF Subject. Written to
      <figure>.provenance.json with the written file's SHA-256. Warnings
      are printed and recorded on the open run (Run.record_warning); the
      sidecar is recorded with Run.record_output.
    Tracing: _tag_panel(artist, source, steps, display_range, channel,
      compare, raw) attaches provenance to an imshow artist. plot_image_grid
      now tags every tile (source PNG, per-channel percentile range, steps
      rescale + to_uint8), using one shared stretch helper so the figure and
      the replay run the same arithmetic. _reproduce_panel(sidecar, n)
      rebuilds a panel from its source file and says whether it is
      bit-identical to what was exported.
    The Save figure dialog (qt/widgets/save_figure_dialog.py) runs the same
      check and stamp on matplotlib figures it writes. The cell-montage
      save and every pipeline figure already go through save_figure.

Validation (CPU only; /mnt/firecuda2/codex/scratch-docs/572/validate.py,
200 synthetic figures per condition, results.json beside it)
    False positives (any warning on a clean figure):
      6 distinct fields, shared range           0/200
      12 similar centred single-cell crops      0/200
      two channels of one field, own LUTs       0/200
    Planted repeats (6 fields / 12 cell crops):
      exact, flip, rot90, linear contrast, gamma 0.6    200/200 each
      + noise 5 % of range                     198/200 fields, 200/200 cells
      + noise 15 % of range                      0/200 (missed)
      75 % crop re-zoomed to full size           0/200 (missed; not built)
    Planted display-range mismatch: one panel's upper limit x0.6 200/200,
      x0.9 200/200, x0.97 0/200 (below the 5 % tolerance); per-panel
      autoscaling 200/200.
    Planted clipping, by true clipped fraction of the planted panel: <2 %
      0/150, 2-5 % 0/127, 5-10 % 126/126, >10 % 197/197.
    Detector saturation at 65535: 1 % of pixels 200/200, 0.2 % 200/200.
    Lossy JPEG written: 200/200.
    plot_image_grid tiles rebuilt bit-identical from the sidecar: 90/90.
    Export time, 6 x 512x512 uint16 panels, PNG 300 dpi, interleaved:
      off 0.52 s median, on 0.53 s median; the report alone 0.02 s.

ALPHA: widget FigureIntegrityCheck (Preferences -> Figures, "Check figure
integrity on export"); no settings keys, choices, apps or models. Registered
as ALPHA_FEATURES[572]['widgets'] in spacr/settings.py. With Show alpha
features off the toggle is not built; a value saved while hidden still
reaches save_figure (tests/qt/test_figure_integrity_alpha_gate.py).

What is left
    Cross-figure repeat detection (an index of panel signatures per run or
    output folder) and reused REGIONS (a crop of one panel inside another,
    at another zoom): the 75 % crop case above is missed. Splice detection.
    Repeats with heavy added noise (15 % of range) are missed.
    Detector saturation is only seen at the integer type's ceiling: a
    12-bit camera stored in uint16 saturates at 4095 and is not flagged.
    Only plot_image_grid tiles are traced to source files so far;
    plot_image_mask_overlay channel panels, cell_montage_view crops and
    other imshow sites are checked but untraced (no source, not replayable).
    Their callers can add _tag_panel to become reproducible.
    The picture right-click export (qt/widgets/picture_export.py) saves a
    rendered QImage with no source data and is not checked.
    Warnings go to the console, the run journal and the sidecar; the GUI
    shows no dialog for them.
    The new captions are in _AWAITING_CATALOG_REBUILD; UI catalogs not
    regenerated.
