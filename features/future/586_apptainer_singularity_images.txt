GPU RUN 2026-09-30
`apptainer run --nv spacr-cuda.sif spacr-doctor` plus a torch.cuda check,
via gpu_turn.sh. First run (10:01): rc 1, 12 passed, 2 failed.
  * qt extra -- a real image bug. --nv binds the host's libglvnd
    dispatchers (libEGL.so.1, libGL.so.1, libGLX.so.0, libGLdispatch.so.0)
    into /.singularity.d/libs, which is on LD_LIBRARY_PATH and so shadows the
    image's copies. Host glibc 2.39, image (Ubuntu 22.04) 2.35, so
    `import PySide6.QtGui` failed: "GLIBC_2.38 not found (required by
    /.singularity.d/libs/libEGL.so.1)". Fix: spacr.def %environment puts the
    image's /usr/lib/<arch>-linux-gnu first on LD_LIBRARY_PATH. Only those
    four of the bound names exist there, so libcuda and libnvidia-* still
    come from the host. New test in
    tests/test_the_apptainer_image_is_the_docker_image.py (15 pass).
  * running checkout -- a smoke-script artefact, not an image bug. The script
    cd'd into the spaCR worktree and Apptainer starts in $PWD, so the
    doctor correctly flagged a source tree whose edits the image ignores.
    /mnt/wd4tb/scratch/586/gpu_run.sh now starts in its own folder.

SLURM SETTINGS BIND CORRECTION (2026-10-02, partial)
    The wrapper accepted separate Mask/Measure settings paths but explicitly
    bound only the Mask settings directory. A Measure file outside the default
    home/working-directory mounts could therefore become inaccessible after
    Mask had already run. A fake-Apptainer reproduction using the original
    script confirmed that exact second-command failure.

    Both files are now preflighted before Mask, resolved to absolute canonical
    paths (including symlink targets), and both parent directories are bound
    into the image. Paths with spaces, separate/shared folders and existing
    per-task worker limits are preserved. Missing Measure settings fail before
    any analysis command. No settings or input images are rewritten.

    Validation: 20 unique checks passed across the 19-case initial cohort and
    five-case affected rerun (1.88 and 1.02 seconds), under 1 GiB, CPU0, zero
    swap. Five focused cases use a fake Apptainer executable to validate actual
    shell arguments; the other 15 cover existing definition/entrypoint contracts.
    This is not a real Slurm, Apptainer or GPU acceptance run. The --nv
    Mask+Measure and publication gaps above remain open.
    Receipt: features/data/586_slurm_settings_binds_2026-10-02.json.
