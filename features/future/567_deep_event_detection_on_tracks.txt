EVIDENCE
    https://forum.image.sc/t/trackmate-cell-division-inaccurate-tracking/74988

WHAT TO BUILD
    Classify short track windows (image sequence + track features) into
    events (mitosis, parasite egress, invasion, host death), time-stamp
    them, correct tracker division errors from detected mitoses, and report
    event timing per condition (feeds a Kaplan-Meier view).

DONE WHEN
    On annotated timelapses, events are detected with a stated
    precision/recall and timing error in frames.

ALPHA: 2026-09-27. Built behind Preferences -> Show alpha features, registered
    as ALPHA_FEATURES[567]: settings timelapse_events (default False),
    timelapse_events_annotations (None), timelapse_events_model (None),
    timelapse_events_window (9), timelapse_events_threshold (0.5) and
    timelapse_events_conditions (None), shown on the Timelapse app under
    "Event Detection (Alpha)". No widgets, apps or zoo rows.

WHAT WAS BUILT (2026-09-27)
    spacr/timelapse.py, private helpers only; CPU only (torch, at most four
    threads), no GPU turn was used.
    - After each field is tracked, _run_event_features_step stores per-object,
      per-frame shape and intensity features and 16x16 image crops
      (tracks/events/<stem>_features.csv, _crops.npz).
    - At the end of the run (core.preprocess_generate_masks),
      _run_event_detection_step: windows of each track (speed, area change,
      shape, intensity, track starts/ends, tracks starting or ending nearby,
      crops) go to a small network (per-frame conv encoder of the crops +
      temporal 1D convolution). Classes are whatever the annotation table
      names (mitosis, egress, invasion, host_death ...). With annotations it
      is scored by leave-fields-out cross-validation
      (event_detection_scores.csv: precision, recall, F1, mean/max timing
      error in frames, match within 2 frames), trained on all annotated
      fields and saved as event_model.pt (loaded tensors-only); otherwise
      timelapse_events_model is applied.
    - Events are time-stamped as per-track probability peaks
      (<stem>_events.csv, events.csv).
    - Division correction: detected mitoses link new tracks starting beside
      the mother in parent_track_id (<stem>_corrected.csv); lineage trees
      (item 537) are redrawn from those links only, so broken tracks are no
      longer inferred as divisions (events/lineage).
    - Timing per condition: time from each track's first frame to its first
      event of each kind, censored at the track's end, through item 571's
      _time_to_event_groups/_statistics/_figure (Kaplan-Meier, log-rank):
      event_timing_<event>_curves/summary/tests.csv and figure.

VALIDATION (synthetic, CPU; scratch-docs/567/validate.py)
    Eight 30-frame fields, 9 cells each: two mitoses (rounding, brightening,
    two daughters under new ids), one host death (shrink, brighten, end),
    and distractors: a broken track, a transient rounding decoy, a cell that
    vanishes. Leave-fields-out, 24 annotated events:
    - with image features and crops: precision 1.00, recall 1.00, timing
      error 0.0 frames (mitosis 16/16, host death 8/8), 129 s on CPU;
    - tracks only (no images): mitosis P 1.00 / R 1.00, host death P 0.50 /
      R 1.00 (vanishing cells taken for deaths), timing error 0.0 frames.
    - Division links re-made from detected mitoses: 31 of 32 true links,
      2 false links (a broken track restarting beside a dividing mother).
    Tests: tests/test_event_detection_on_tracks.py (features, windows,
    held-out scores, re-linking, timing per condition, saved-model reuse,
    scoring, refusal), tests/qt/test_event_detection_alpha_gate.py.

WHAT IS LEFT
    - No annotated real timelapse was available: the done-when numbers are
      synthetic. Annotate a Toxoplasma egress/invasion movie and a dividing
      host-cell movie and rerun the scores.
    - Egress and invasion were not simulated; they need parasite and host
      tracks read together (events across two object types).
    - No own-env backend and no GPU training; the network is small enough
      for the CPU. A larger pretrained video model would need an isolated
      env via _segmentation_backends.
    - No annotation tool in the GUI: annotations are a hand-made table.
