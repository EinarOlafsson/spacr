WHAT IS THERE TODAY (nightly, 2026-09-22)
--------------------------------------------------------------------------------

* Home has four sections (spacr/qt/app.py, SECTION_ORDER ~497): Core, Data,
  Tools and Assays. Assays holds exactly four modules (~1062-1065):
  `analyze_plaques` (Plaque Assay), `recruitment`, `invasion`, `replication`.
* Their icons are spacr/resources/icons/{analyze_plaques,recruitment,invasion,
  replication}.png; `replication.png` is the one this item's Toxoplasma page
  takes as its own.
* Every Home tile is a module screen. What this item introduces is a NEW KIND
  OF SCREEN: an organism page that is a description plus a grid of module
  tiles, sitting between Home and the assay modules.

WHAT TO BUILD
--------------------------------------------------------------------------------

1. HOME'S ASSAYS SECTION BECOMES THREE ORGANISM TILES: "Toxoplasma",
   "Plasmodium spp." and "Candida spp.". Toxoplasma's icon is the current
   replication icon. The four assay modules leave Home's top level and live
   inside the Toxoplasma page (their settings, runs and API are unchanged --
   only where they are reached from changes).
2. THE ORGANISM PAGE, one layout used by all three:
     * LEFT: images of the organism above a description -- what it is, what it
       causes, why it is imaged -- and a row of links: ToxoDB / PlasmoDB /
       CandidaDB (all VEuPathDB), UniProt, NCBI Taxonomy, and where it exists
       a genome browser and the relevant strain resource (e.g. BEI, ATCC).
       Every image needs a licence that allows shipping it (or is made by the
       maintainer); record the source beside each.
     * RIGHT: a grid of eight module tiles, drawn exactly like Home's tiles.
     * A tile that is not built yet is dimmed and says "Coming soon" when
       hovered; it opens nothing.
3. EIGHT TILES PER ORGANISM. The first four of Toxoplasma are the modules that
   exist today; the rest are proposals, to be confirmed by the maintainer:

   TOXOPLASMA GONDII
     1. Plaque Assay          (exists)  lysis over days; plaque number and size
     2. Recruitment           (exists)  host protein at the vacuole membrane
     3. Invasion Assay        (exists)  attached vs invaded, two-colour staining
     4. Replication Assay     (exists)  parasites per vacuole
     5. Egress                (new)     time-lapse: when vacuoles rupture and
                                        parasites leave, per condition
     6. Gliding motility      (new)     trail length and speed of extracellular
                                        parasites (spaCR already tracks motility)
     7. Bradyzoite conversion (new)     cyst-wall staining: tachyzoite to
                                        bradyzoite switching per condition
     8. Host cell damage      (new)     monolayer integrity, host death and
                                        detachment after infection

   PLASMODIUM SPP.
     1. Parasitaemia          (new)     infected red cells per field, from
                                        Giemsa or fluorescence
     2. Blood-stage staging   (new)     ring / trophozoite / schizont per cell
     3. Merozoite invasion    (new)     invasion of erythrocytes over minutes
     4. Liver-stage growth    (new)     exo-erythrocytic form size and number in
                                        hepatocytes
     5. Sporozoite motility   (new)     gliding trails and speed
     6. Cell traversal        (new)     wounded host cells along a sporozoite's
                                        path (dextran uptake)
     7. Gametocyte maturity   (new)     stage and sex ratio for transmission work
     8. Drug response imaging (new)     growth inhibition curves per compound
                                        from images rather than a plate reader

   CANDIDA SPP.
     1. Filamentation         (new)     yeast to hyphae: how many switch, how far
     2. Germ tube formation   (new)     the early filamentation readout, per cell
     3. Biofilm               (new)     biofilm area and thickness over time
     4. Adhesion              (new)     cells bound to an epithelial monolayer
     5. Epithelial invasion   (new)     inside vs outside, two-colour staining
                                        (the same idea as Toxoplasma's invasion)
     6. Phagocytosis          (new)     uptake and killing by macrophages
     7. Morphology            (new)     yeast / pseudohyphae / hyphae per cell
     8. Antifungal response   (new)     growth and morphology against drug
                                        concentration

4. ICONS: one per new tile, in the style of the existing icons

5. EVERY CAPTION IS A TRANSLATED STRING in nine languages -- organism names,

6. THE ROUTE MUST STAY SHORT for people who already use the assays: Home ->

WHAT TO BE CAREFUL WITH
--------------------------------------------------------------------------------

* A "Coming soon" tile is a promise. Either it carries a date or it says
  plainly that it is not built; the maintainer decides the wording.
* The organism pages hold prose about biology. It should be short, sourced and
  correct, and say where the numbers come from; the maintainer is the
  authority on what it claims.
* This is a new screen KIND, so it needs its own place in the Home registry,
  the API pages, the tutorials (see item 472's map of what feeds what) and the
  walkthroughs.

DONE WHEN
--------------------------------------------------------------------------------

* Home's Assays section is three organism tiles, Toxoplasma carrying the
  replication icon.
* Each organism page shows images, a sourced description and its links, and a
  grid of eight tiles; the four Toxoplasma assays open and run as before.
* Unbuilt tiles are dimmed and say "Coming soon" on hover.
* Search, the command palette, recipes and scripts still reach every assay
  module directly.

2026-09-22 — IMPLEMENTATION AND MAINTAINER'S EXPANDED PAGE REQUEST
--------------------------------------------------------------------------------
Home's Assays section now opens three organism directories, each containing
exactly eight Home AppTiles. The four existing Toxoplasma assay registry keys
remain directly accessible through command palette/help search, CLI and saved
recipes; their pipelines were not modified. The other twenty tiles are
inert, dimmed proposals with Coming soon tooltips. The new directories remain
alpha while translation and final review are outstanding.

The maintainer subsequently requested much more text, several sections that
reference the modules, horizontal expansion of the left information pane,
prettier illustrations using Starplast's apicomplexan diagram, and precisely
Home's button shape. Implemented:
* Each organism has an introduction, four substantive assay-referenced
  sections, a cell illustration, compartment selector, source attribution,
  and research-resource links. Toxoplasma's four active assays have links
  directly in the prose. The planned workflows are described as proposals.
* A horizontal QSplitter separates independently scrolling information and
  module panes. Drag its divider or use Widen text / Restore columns. Tiles
  reflow after divider movement and scrollbar/viewport resizing.
* AppTile uses Home's 172/260 width bounds, 124 height, 48 icon size, Preferred
  width policy and 4-pixel spacing (all scaled through the existing helpers).
* Toxoplasma and Plasmodium use the SwissBioPics apicomplexan SVG from
  Starplast 53703bafdf0604576a05b589400051a6b09e62ea. Toxoplasma exposes
  Starplast's hyperLOPIT-to-UniProt SL mapping; Plasmodium uses common
  compartment labels without transferring Toxoplasma measurements.
* Candida uses SwissBioPics' generic budding-yeast illustration, explicitly
  identified as a schematic rather than a species/morphology reference.
* The original SVGs are bundled unchanged, with source URLs and SHA-256s in
  spacr/resources/images/organism_sources.json. Runtime rendering adds a
  schematic pastel palette and selection outline and removes hidden metadata,
  canvas backgrounds and the logo. Visible attribution credits Philippe Le
  Mercier / SIB and links the source and CC BY 4.0 licence. No runtime network
  access, PyQt6 dependency or import from the separate Starplast checkout.
* Shared hyperLOPIT shapes are disclosed. SL0171 (mitochondrial membrane)
  exists as an empty metadata group in the source; selecting it highlights
  the mitochondrial outline and explicitly explains that no separate shape
  exists. Dense granules use the stated generic cytoplasmic-granule shape.
* Twenty-two native vector module icons are bundled. The existing icon loader
  now renders SVG through Qt into the same bounded, theme-aware raster cache.
