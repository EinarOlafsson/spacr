CONFLUENCY IN MEASURE, FOR ANY CHANNEL

Status: IMPLEMENTED AS ALPHA 2026-09-26. Measure writes confluency per field
and per well with a monolayer QC flag, from texture, intensity or cell masks;
the infection report and any per-well table use it as filter and denominator;
the Measure preview draws the covered area. Hidden with Alpha features.
Owner: unassigned. Proposed from image.sc research on 2026-09-26 (what users
ask for in other applications).

WHAT TO BUILD
    Measure confluency (fraction of the field covered by cells / monolayer)
    in Measure for any channel: brightfield/phase (texture/variance based),
    fluorescent cytoplasm or membrane stains, or from the cell masks
    themselves; per field and per well, with a monolayer QC flag usable as a
    denominator and filter in plaque and infection assays. (Maintainer:
    'just confluence in general in measure, not just bright field'.)

DONE WHEN
    Confluency agrees with hand-drawn coverage within 5 % on brightfield and
    fluorescent test fields and appears in the measurement database.

2026-09-26 — Implemented as Alpha
    Measure computes confluency, the covered fraction of each field, when
    `confluency` is on. `confluency_source` picks how, per run: auto (the
    default: cell masks when the run has cell masks, texture otherwise),
    masks (union of the segmented cells as Mask wrote them, before
    Measure's size filters), texture (brightfield/phase: local standard
    deviation in a `confluency_window` square, split by Otsu on its log,
    then cut halfway between the two levels in variance so the edge is not
    inflated by half a window) or intensity (fluorescent cytoplasm or
    membrane stains: Otsu on the smoothed, 99.9 %-clipped channel, then the
    cut moved a quarter of the way from background to stained level so dim
    cell rims count). A field whose pixels do not separate into two classes
    (separation under 3.2 pooled SDs) is decided whole, empty or confluent,
    by its texture-to-noise ratio. A z-stack is max-projected.
    Code: spacr/measure.py (_texture_coverage, _intensity_coverage,
    _mask_coverage, _field_confluency, _measure_field_confluency,
    _confluency_overlay, _confluency_by_well, _aggregate_confluency_by_well,
    _monolayer_qc); spacr/infection.py (infection_report); the Measure
    preview in spacr/qt/widgets/measure_preview.py. No new modules. The
    helpers are underscored on purpose, as 569's are: a public name joins
    the API documentation inventory, whose catalogs only the docs lane
    regenerates. Making them public is a docs-lane change.
    Database: measurements.db:confluency, one row per field (source,
    channel, confluency, covered_px, field_px, automatic threshold,
    separation, monolayer_ok), and confluency_well, rebuilt at the end of
    each run: pooled confluency (covered over imaged pixels), per-field
    mean/median/min/SD, fields_below_qc and monolayer_ok against
    `confluency_qc_threshold` (default 0.8). Time-lapse keeps timeID.
    Filter and denominator: infection_report gains `confluency` and
    `parasites_per_confluency` metrics and a monolayer_ok column whenever
    the run measured confluency, and `monolayer_filter=True` drops wells
    that fail QC. measure._monolayer_qc joins confluency onto any per-well
    table (a plaque per_image table through `well_of`), adds
    `<column>_per_confluency` and can drop failing wells. analyze_plaques
    itself is not wired: its images carry no plate/row/column, so the join
    has to be told the well.
    Preview: with plot on, each field gets a <field>/confluency.pdf overlay
    in results/; the Measure preview has a Confluency toggle that runs the
    same function on the loaded field and shows the tinted covered area and
    the percentage with its QC verdict.
    Accuracy: synthetic fields of known coverage 0-100 % agree within 1
    percentage point for texture (brightfield) and intensity (fluorescent),
    exactly for masks. The ten Toxo PV Make Masks fields against their
    hand-drawn ground truth: intensity within 1.1 points on every field
    (Otsu alone gave half the drawn area), texture within 1.2. Sixteen
    plate1 fields, cell stain (channel 1) against the fields' Cellpose cell
    masks: intensity within 3.5 points, texture within 4.9 -- the DONE WHEN
    5 % holds, with texture the weaker of the two on fluorescence, as
    expected.
    Tests: tests/test_confluency_in_measure.py (synthetic sources, uniform
    fields, z-stacks, source resolution, overlay, real Toxo PV and plate1
    fields, the measure_crop end to end for three sources with the per-field
    and per-well tables and QC flag, per-well pooling, _monolayer_qc as
    filter/denominator on a plaque-style table, the infection report) and
    tests/qt/test_measure_confluency_preview.py (overlay, auto source from
    the panel's cell slice, failure reporting, Alpha gating).
    Not done: a manual threshold override; a hand-drawn brightfield
    reference field (none exists in the example data, so brightfield rests
    on the synthetic fields); wiring the flag into analyze_plaques.

REAL-DATA VALIDATION 2026-09-30 (CPU) -- brightfield/phase against hand-traced cells
    Data: LIVECell (Edlund et al. 2021, Nat Methods; CC BY-NC 4.0).
    Incucyte phase contrast, 8 cell lines, expert-drawn whole-cell
    outlines. Read-only from the live_cell project staging
    (/mnt/wd4tb/af3/projects/live_cell/data/incoming/livecell_phase).
    Ground truth = the fraction of pixels inside any drawn cell. Texture
    source, window 15. Script: /mnt/wd4tb/scratch/538/541/val541.py.
    Receipt: features/data/538_541_580_real_data_validation_2026-09-30.json.
    - As shipped, official test split (1512 fields): MAE 19.4 points,
      bias -17.3, 38 % of fields within 5 points. Confluent SKOV3/A172
      fields came out 0 %. Their pixels do not split into two classes, and
      the whole-field call (texture ratio >= 3) read them as empty. A
      confluent phase monolayer reads only 2-3 because its fine texture
      raises the noise estimate too. Bare plastic crops read 1.1-1.7
      (train/val crops: empty median 1.25, full median 2.19).
    - Fix (spacr/measure.py): the texture source now calls a non-splitting
      field covered from ratio 1.8 (_CONFLUENCY_PHASE_RATIO_MIN). The
      intensity source keeps 3.0. New test
      test_a_faint_phase_monolayer_is_decided_covered; the 31 confluency
      tests pass, synthetic brightfield still within 2 points.
    - After the fix, test split: MAE 9.4 points, median |error| 6.5, bias
      -3.8, 42 % of fields within 5 points, mean IoU 0.60. By line (MAE):
      BT474 4.0, MCF7 4.3, SkBr3 5.2, BV2 6.0, A172 9.1, Huh7 9.1
      (under-reads flat cell interiors), SHSY5Y 9.3, SKOV3 19.8 (flat,
      low-contrast cells; many fields do not separate and are called
      whole).
    - Tried and not adopted: lower separation minimum (SKOV3 worse);
      other cut levels between the two texture classes (log-space 0.8 gave
      val MAE 8.1 vs 8.9 on test non-uniform fields but broke the synthetic
      2-point tolerance); window 9/11/25; filling holes.
    Verdict: the DONE WHEN (within 5 % of hand-drawn coverage) holds on
    fluorescence (Toxo PV, plate1) and on well-textured phase lines, but
    NOT on LIVECell phase overall. Per field it is within 5 points on 42 %.
    Brightfield/phase needs the confluency_window tuned per cell line, or
    a learned model. Still left: a manual threshold override, and
    per-cell-line guidance.
