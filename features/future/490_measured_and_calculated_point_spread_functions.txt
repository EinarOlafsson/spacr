first in Make Masks enhancement, then in Mask generation and Measure after

2026-09-23 — NUMERICAL ENGINE IMPLEMENTED; INTEGRATIONS REMAIN
spacr.point_spread supports calibrated2D/3D measured TIFF/NPY kernels and
explicit sampled Gaussian approximations from FWHM/spacing. Immutable kernel
bytes retain normalized shape/sampling/hash and source-file SHA256. Odd spatial
axes, finite nonnegative positive signal and calibrated sampling are checked;
NPY/TIFF shapes are bounded before decoding. No implicit channel interpretation,
kernel resampling, optical inference, integer clipping or source mutation.
Convolution and Richardson–Lucy use half-sample symmetric boundaries. The
adjoint folds boundary contributions exactly, with sensitivity normalization;
an independent dense direct-convolution matrix verifies asymmetric-kernel RL.
Each channel is independent; cancellation checks separate expensive operations.
Outputs are float32 in original intensity units; all settings enter provenance.

2026-09-23 — MAKE MASKS CONTROLS AND COMPARE/APPLY IMPLEMENTED
Image enhancement now offers off-by-default PSF convolution or Richardson–Lucy,
a Gaussian approximation with explicit Y/X FWHM, or a measured2D TIFF/NPY.
Image and measured-kernel pixel spacing are explicit; zero/unset or mismatched
calibration refuses processing. Kernel loading/generation runs off-thread,
with generation guards. Captured immutable bytes remain unchanged if a file
changes on disk; Reload explicitly reads the new version. Controls wrap in a
narrow settings column and link to point_spread.apply_psf API help.

The fixed chain order is stretch/background/PSF/denoise/contrast/sharpen before
detection. PSF failures propagate instead of silently skipping the operation.
Compare and Apply run in background; cancellation reaches deconvolution's
iteration checks. Whole-image detection reuses the scientific float result
from the background Apply worker, rather than recomputing PSF on the GUI thread.
Wand uses those scientific intensities too; display scaling is separate.
Mask history records operation, image spacing, kernel/file identity, iterations,
boundary/algorithm and the fact that measurements still use original pixels.
