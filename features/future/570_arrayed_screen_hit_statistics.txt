2026-09-26 — Built as an alpha option of Control Charts
    Statistics live in spacr/sp_stats.py (no new module): mad, robust_z_scores
    (median/1.4826 MAD of the negative control, Zhang's z*),
    ssmd_unreplicated (mm, umvue, robust SSMD*) and ssmd_replicated (mm,
    umvue, robust, on paired differences to the plate's negative median),
    median_polish (a port of R stats::medpolish: same sweep order, eps 0.01,
    maxiter 10), b_scores (effects fitted on the sample wells so a control
    column is not a column effect; residual / scaled MAD as cellHTS2 does),
    call_hits (both/up/down), screen_wells (wells located by the plate_qc
    reader; controls by a column and its levels or by well_spec positions
    such as c1, r1, A01), score_screen / score_arrayed_screen (per-plate or
    pooled negative reference; B-score always fitted per plate, pooled scope
    uses one screen-wide scale), treatment_ssmd (replicate SSMD per
    treatment), hit_table (ranked), hit_heatmap and write_hit_report.
    Per-plate Z' in the plate summary comes from control_chart.zprime_frame,
    the function the Z' chart uses. Heatmaps are the house small multiple
    (figures/plates.build_plates, new outline= option and score_ramp, a
    rust-to-green diverging map symmetric about zero, hits outlined) written
    through spacr.plot.save_figure. write_hit_report writes hit_table.csv,
    hit_scores_wells.csv, hit_plates.csv, hit_treatments.csv (with a
    treatment column) and hit_heatmap_<ssmd|robust_z|b_score>.
    Screen: Control Charts gains a "Score hits" toggle and its options (call
    by SSMD/robust z/B-score, threshold, direction, SSMD estimator,
    per-plate or pooled reference, treatment column), a Hits section with
    the summary and ranked table, and an Export hits button. It scores on
    its own job runner, so a two-plate screen too short to chart is still
    scored. It reuses the form's control column and negative/positive picks.
    Checks: robust z, SSMD (all three estimators, both designs) against
    values worked by hand; both UMVUEs unbiased by simulation; median polish
    reproduces R's ?medpolish deaths example exactly (overall 8, rows
    6 -1 0 2 -8, columns 0 -1 0, the printed residuals); robust z equals
    scipy's normal-scaled MAD and pycytominer 1.7.1 RobustMAD to 1.5e-6
    (run from the downloaded wheel; the test skips where pycytominer is not
    installed); B-score removes a planted row and column gradient (Spearman
    with column and row under 0.1, fitted slopes 1.5 and 0.8 recovered) and
    keeps the planted hit, where robust z calls over 100 gradient wells;
    planted up/down hits called exactly and ranked first by every method.

2026-09-30 -- real-screen check (CPJUMP1); no code change
Data: Cell Painting Gallery cpg0000 CPJUMP1, U2OS 48 h compound plates
BR00117010-13, well profiles (1,536 wells). Known actives: the annotated
poscon_diverse wells (112). Negatives: DMSO negcon wells (256). The DMSO
wells were split two ways per plate: one half is the reference, the other
half is scored as samples, so false positives are counted on wells the
reference never saw. Published list: CPJUMP1 replicability (Chandrasekaran
et al. 2024, compound_U2OS_long, 202 of 306 compounds active at corrected
p < 0.05). This is a multivariate profile call, so a single readout can
only recover part of it. Defaults: rank by SSMD, threshold 3 for every
method, direction both, per-plate reference, SSMD estimator mm.
Readout: cell count (CellProfiler Cells_Number_Object_Number well mean).
  SSMD: recall 0.63 (71/112), precision 1.00, 0/256 DMSO called.
  robust z: recall 0.79, precision 0.94, DMSO false-positive rate 2.3%
  (a normal control would give 0.27% at |z| >= 3; real DMSO wells have
  heavier tails).
  B-score: recall 0.57, precision 1.00, 0 DMSO called.
  |SSMD| AUROC positive controls vs DMSO 0.96, so the default SSMD 3
  (Zhang's "very strong") is conservative; a lower cut trades precision
  for recall.
  Against the published list (a compound counts as called when most of
  its replicate wells are hits): SSMD calls 61 compounds, all published
  actives (precision 1.00, recall 0.30); robust z 71 (1.00, 0.35);
  replicate SSMD per treatment 81 (1.00, 0.40).
Readout: nuclear area. SSMD recall 0.43, precision 0.98; robust z 0.57,
  0.88 (DMSO rate 3.5%); B-score 0.49, 0.97; against the published list
  precision 1.00, recall 0.25-0.31.
Reference implementation on the real readout: spaCR's robust z equals
pycytominer 1.7.1 normalize(method="mad_robustize", samples=negcon) per
plate to 1.5e-6 relative, Spearman 1.0, and both call the same 351 wells
at |z| >= 3.
Readout choice: item 563's old anomaly distance (skewed, heavy right
tail) inflated robust z false positives to 11-14% of DMSO wells. Its
score is now a bounded control percentile and is not meant as a 570
value. Score a measured feature here, and use 563 for multivariate
ranking.
Verdict: the hit calls recover the known actives that change the chosen
readout, with very few false positives. None of the 570 code was weak on this data, so it
is unchanged. Receipt:
features/data/563_570_real_screen_validation_2026-09-30.json (scripts in
/mnt/wd4tb/scratch/563/scripts). Plots: write_hit_report on the cell-count
readout wrote the SSMD, robust z and B-score heatmaps of all four plates
and the tables. Per-plate Z' is -0.8 to -1.3 with the fourteen positive
controls pooled, because their effects on cell count range from none to
total loss. LEFT: cellHTS2 B-score parity.

2026-10-01 — FINAL CELLHTS2 REFERENCE ACCEPTANCE; DONE AS ALPHA
Executed unchanged Bscore, adjustVariancebyPlate and
adjustVariancebyExperiment from pinned cellHTS2 2.69.0 source commit
88e87ebc294490547a2f224eca75a6de14dafea3. A private WebR 0.6.0 runtime supplied
actual R 4.6.0 stats::medpolish/mad without installing R or dependencies into
the application. A data-only S4 adapter supplies the object slots/accessors;
the upstream numerical source was neither translated nor modified.

Four pinned CPJUMP1 plates BR00117010–13 supply 1,536 real wells, including
112 annotated diverse positive controls. Cell-count proxy and nuclear area,
each under plate and pooled scoring, give 6,144 reference scores. The
comparison found a real defect: spaCR used general median-polish defaults
(10 iterations, eps 0.01), whereas cellHTS2 uses 200 and 1e-5. On cell count
this changed 12 per-plate hit calls at threshold 3. B-score now uses the
reference stopping settings and R's rounded MAD factor 1.4826 for both
plate and pooled scaling. General MAD, robust z and SSMD are unchanged.

After correction, every score matches within 1.50e-13 absolute, all hit
calls agree, and no distinct reference score is reversed in the ranking.
Near-zero floating-point ties are compared at 1e-10; raw tie-sensitive
Spearman values are preserved, not presented as exact equality. Both real
four-plate B-score heatmaps were written and visually inspected. The older
Sep30 B-score recovery/call metrics remain historical, not post-fix claims.
