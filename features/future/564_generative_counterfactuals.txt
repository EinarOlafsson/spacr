EVIDENCE
    No image.sc thread; from the literature / general practice.

WHAT TO BUILD
    Train a conditional generative model (e.g. diffusion or StyleGAN as in
    Phenexplain, Lamiable et al., Nat Commun 2023) on crops and render how a
    control cell would look under a hit condition, to make subtle phenotypes
    visible beyond Grad-CAM.

DONE WHEN
    Counterfactual sequences for a known phenotype show the expected change,
    and a classifier's score moves monotonically along them.

ALPHA: 2026-09-28
    Built as an alpha, CPU-validated. Settings counterfactuals,
    counterfactual_crops and counterfactual_epochs (ALPHA_FEATURES[564]) form
    the Counterfactuals heading of Activation Maps, hidden unless
    Preferences -> Show alpha features is on.

    Method (spacr/attribution.py, private helpers): a small class-conditional
    autoencoder (encoder -> latent; decoder takes latent + class code) trained
    on crops at <=64 px against the frozen classifier, which labels each crop
    with its own prediction. Loss = reconstruction + classifier cross-entropy
    for another class on the edited crop + mean absolute edit size. The
    counterfactual is the crop plus (decode(target) - decode(own class)),
    upsampled, so the edit is exactly zero at the crop's own class and all
    detail the small generator cannot draw is kept. Sequences interpolate the
    class code in 7 steps; the classifier scores every step. The report
    compares against a class-mean-shift baseline. generate_activation_map
    collects the first counterfactual_crops crops and writes
    counterfactuals/counterfactual_{cells,summary}.csv and
    counterfactual_sequences.pdf next to the maps.

    CPU validation (synthetic crops, 32 px, known phenotype: bright puncta
    inside a smooth cell; 400 crops, 30 epochs, 6 s on CPU; classifier 99.5%
    held-out accuracy). Held-out 100 crops, both directions:
        flip rate 0.99 (class-mean shift baseline 0.09)
        monotone score along the sequence 1.00, mean Spearman 0.996
        median edit 0.062 of the crop's intensity range, 12% of pixels
        changed by >10% of the range (baseline edit 0.016)
    Control -> hit on 50 held-out control crops: flip rate 1.00, puncta
    energy (image minus its 5x5 blur, positive part) rose in every sequence
    and monotonically, from 14.9 to 18.2 (real hit crops 20.3), so the edit
    adds the expected phenotype, about 60% of the way to real hits.
    Caveat: the same classifier guides and scores the edits, so the flip
    rate alone can reflect an adversarial edit; the edit size, the phenotype
    feature and the baseline are the checks against that.
    Script: /mnt/wd4tb/scratch/564/validate_cpu.py. GPU run (larger N and
    epochs) ready at /mnt/wd4tb/scratch/564/gpu_train.sh, not run.

    What is left: validation on real screen crops with a known phenotype
    (the DONE WHEN asks for real data); a diffusion/StyleGAN generator in its
    own env for photorealistic counterfactuals at full crop size (the alpha
    uses a tiny autoencoder); a per-condition (plate/well metadata) target
    instead of the classifier's classes; a Qt viewer for the sequences.

PER-CONDITION TARGET AND QT VIEWER 2026-10-03 (alpha, CPU)
    New setting counterfactual_condition (ALPHA_FEATURES[564], Counterfactuals
    heading): 'class' (default, as before) or 'plate', 'well', 'row',
    'column', read from each crop's <plate>_<well>_... file name. With a
    condition, the generator's codes are conditions; each condition's target
    is the classifier's mean class probabilities over its training crops
    (soft cross-entropy), held-out crops morph to the next condition, rows
    carry source_condition/target_condition, the class-mean baseline is per
    condition, and the step score is p.t/(t.t) (equal to the target-class
    probability for class targets). Fewer than two conditions skip with a
    note. The run also writes counterfactual_frames.npy.
    Qt viewer: Activation Maps header button "Counterfactuals…"
    (ActivationCounterfactualViewer, alpha widget) opens a counterfactuals
    folder and lists every sequence (source -> target, score change,
    flipped) and draws the saved frames with the score per step.
    CPU check (synthetic puncta crops, control vs hit wells, 20 epochs):
    flip rate >= 0.7 and above the per-condition baseline, monotone >= 0.8.
    Tests: tests/test_generative_counterfactuals.py,
    tests/qt/test_generative_counterfactuals_alpha_gate.py.
    Still left: real screen crops with a known phenotype; a
    diffusion/StyleGAN generator in its own env; picking the target

2026-10-04 — DIFFUSION GENERATOR (alpha, GPU-validated on BBBC014)
    ALPHA: new setting counterfactual_generator (ALPHA_FEATURES[564],
    Counterfactuals heading, default 'autoencoder'): 'autoencoder' as before
    or 'diffusion'. spacr/attribution.py gains _CounterfactualDiffusion and
    _train_counterfactual_diffusion, no new module. It is a class-
    conditional DDPM (cosine schedule, small U-Net, width 64) with
    classifier-free guidance (class dropped 15% in training); the class
    code mixes learned class embeddings, so codes interpolate. It offers the
    autoencoder's encode/decode API: encode is unconditional DDIM inversion
    to noise level `strength`, decode is guided DDIM sampling under a code,
    so _cf_edit (residual, exactly zero at the own class), the sequences,
    the baseline and the report are unchanged. The classifier only labels
    the training crops; nothing is trained against it. Sequences now decode
    all steps in one batch. The report gains generator, realism_fd and
    realism_fd_unedited: Frechet distance on hand features (per channel
    mean, std, central disk/ring ratio, gradient magnitude) between the
    counterfactuals and real training crops of their target, and the same
    for the unedited sources. With out_dir the diffusion weights are saved
    as counterfactual_diffusion.pt. Defaults (strength 0.95, guidance 4,
    50 DDIM steps, width 64) are the setting chosen below.

    Data: BBBC014 MCF7 (CC BY 3.0), 2-channel 64 px nucleus-centred crops
    (Hoechst, NF-kB); control = TNF-a columns 10-12, hit = columns 1-3; train
    rows A-C (8,553 crops), held-out row D (2,906): 100 crops to tune
    strength/guidance, 2,806 to test, disjoint. Classifier (3-layer CNN)
    row-D accuracy 0.980. Diffusion: 400 epochs, 2,547 s on the RTX 3090 Ti,
    final denoising loss 0.042.
    Tune (100 crops): strength 0.3-0.7 barely edits (flip <= 0.01, edit
    <= 0.005); flip/realism FD (unedited 5.62) at guidance 2 / 4:
    0.80: 0.09/5.42, 0.38/5.02   0.85: 0.34/4.96, 0.71/4.24
    0.90: 0.77/3.93, 0.94/3.15   0.95: 0.93/2.80, 0.99/2.32
    Chosen 0.95 / 4 (flip >= 0.8, lowest FD). At 1.0 (probe on 48 control
    crops) the NF-kB ratio overshoots to 3.2 (real hits 1.6): the cell is
    lost.
    Held-out test, 2,806 crops, both directions:
                              diffusion   autoencoder   class-mean shift
        flip rate             0.990       0.9996        0.013
        monotone / Spearman   0.979/0.980 0.999/1.000   -
        median edit L1        0.089       0.018         0.041
        pixels changed >10%   29%         1.5%          -
        realism FD            1.94        31.65         (unedited 4.83)
        NF-kB disk/ring, control -> hit: before 1.20, real hits 1.58
                              1.68 (rose  1.26 (rose
                              in 97%)     in 100%)
    Conclusion: both flip the classifier, but the autoencoder does it with
    a tiny edit that is visible as speckle (counterfactual_sequences.pdf),
    moves NF-kB only 15% of the way to real hits and makes the crops much
    less like real cells (FD 4.8 -> 31.7): an adversarial edit. The
    diffusion edits move NF-kB into the nucleus all the way to the real
    hits' level and are closer to real target cells than the sources were
    (FD 4.8 -> 1.9), without ever being trained against the classifier.
    Their price: the edit is not minimal; at strength 0.95 the model
    redraws the neighbourhood (neighbouring nuclei move), so a sequence
    shows "a cell like this, in the target class", not the same cell.
    Scale matters: through _counterfactual_report on 600 random crops
    (450 train, 60 epochs, width 32) diffusion flips only 0.13 and FD
    worsens (8.1 -> 9.3); the app defaults (256 crops, 30 epochs) are far
    too small for it, and the tooltip says so.
