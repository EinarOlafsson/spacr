FILTERS ARE ANY scikit-image REGIONPROP, ADDED BY THE USER

Status: DONE 2026-09-25 (engine, Make Masks list, object_filters setting;
        see BUILT below). Filed 2026-09-24. The old per-object bounds were
        retired into object_filters rows the same day, by the maintainer's
        decision (see the last note).
Owner: Claude (item 511 worktree).

REQUEST (the maintainer, 2026-09-24, verbatim)
    "there should be other filter options as well, basically the user should be
    able to pick any sikit-image regionprop to filter on. but this should be
    opti in not one row for each filter. the user should be able to add filters
    from scikit-image regionprops, that is to say."

WHAT TO BUILD
Instead of a fixed row per filter, an "Add a filter" control that offers every
property skimage.measure.regionprops computes for a labelled image (area,
eccentricity, solidity, extent, perimeter, axis lengths, intensity statistics
where an intensity image is available, and the rest), then adds one row with a
minimum and a maximum. Rows can be removed. The chosen filters travel with the
mask's provenance and apply in Make Masks and in Mask generation alike. Offer
only the properties that are real for the image at hand (an intensity property
needs an intensity image), rather than failing later.

DONE WHEN
A user can filter objects on a property spaCR never hard-coded, the filter is
recorded, and removing it restores the objects it hid.

2026-09-25 -- DECISION APPLIED: THE OLD PER-OBJECT BOUNDS ARE RETIRED

The maintainer, 2026-09-25: "RETIRE Mask's old per-object {obj}_min_area,
_max_area, _min_intensity, _max_intensity settings from the form; saved
settings that carry them are migrated into object_filters rows on load

SCOPE. The twelve keys {cell,nucleus,pathogen}_{min,max}_{area,intensity}.
The organelle family (organelle_min_area and the slots' *_min_area, and
organelle*_min/max_intensity) is NOT retired: the organelle segmenters use
organelle_min_area as a segmentation parameter (spacr/object.py, the
remove_small_objects calls in the classical routes), not only as a filter.
Say if the organelle bounds should follow.

THE LOAD PATH, one fold, spacr/settings.py _fold_object_bounds:
  * each retired key present is popped and handed to
    mask_engine.legacy_filters (0 = off, as before); the rows are appended
    to that object's object_filters list. A row the file already has for
    the same property wins (a filter list is the later spelling).
  * a value that is not a finite number >= 0 is LEFT in place, unmigrated,
    so the run, the doctor and the Live preview refuse it as they did
    (_validated_intensity_bounds); moving it would have made it "off".
