DONE 2026-09-28
- spacr/qt/prerun.py: install_qc_banner puts a "QC" toggle (AiToggleLabel,
  same minimum width as 3D/Time) in the action row just left of the 3D and
  Time switches (_insert_before_dimension_switches) and puts the banner in
  _SegQCDialog, a non-modal QDialog that gets the glass card
  (widgets.glass.glass) and re-reads the verdict whenever it opens. Closing
  the popup turns the switch off. The banner is no longer in the runtime
  panel, so nothing above the action row changes height.
- spacr/qt/screens/settings_model.py: new Measure layout plus
  _APP_CATEGORY_PARENTS / _category_parents, a per-module nesting table
  (a shared CATEGORY_PARENTS entry would also split children by object and
  move the families on every other module). _nest_sections now lets a
  parent that is itself a category keep its own rows (Features,
  Input & Experiment). A child of a hidden parent is hidden with it.
  Tree: Input & Experiment [src, experiment, plot, test_mode, test_nr;
  Cloud (Alpha)] / Mask & Channel Mapping / Image Preprocessing [Bleach
  Correction (Alpha), Spectral Unmixing (Alpha), Image Deconvolution (PSF),
  Illumination Correction, Intensity Calibration (Alpha), Plate Barcode
  Linkage (Alpha)] / Features [own rows; Confluency, Cell Cycle, Wound
  Closure, Viability, CellProfiler, GPU Measurement, Time To Event] /
  Object Filtering / Crop Output / 3D Calibration (Beta) / Postprocessing
  [Runtime & Reliability, Profiling (Alpha), Measurement Backend (Alpha)].
- spacr/settings.py get_setting_dependencies: every time_to_event* key is
  greyed unless timelapse is on, with a reason naming timelapse.
- Category blurbs: FEATURES, POSTPROCESSING, CLOUD (ALPHA), and Measure's
  own IMAGE PREPROCESSING and IMAGE DECONVOLUTION (PSF). The dead
  MEASUREMENT FEATURES and PREVIEW & DIAGNOSTICS blurbs were removed.
- Tests: tests/qt/test_prerun.py (action bar geometry at 1200x720 and
  1400x900, with and without the QC switch and a failing verdict; the
  switch opens and closes the popup), tests/qt/test_measure_settings_
  regrouped.py, tests/qt/test_time_to_event_alpha_gate.py (greying).

NOT ALPHA, ON PURPOSE: Illumination Correction and Image Deconvolution (PSF)
are stable features with stable keys, and ALPHA_FEATURES is keyed by
setting, so marking them alpha would hide them on Mask generation and
Timelapse too. They keep their stable headings under Image Preprocessing.
No new alpha keys were added; every alpha sub-category was already
registered by its own item.
