--------------------------------------------------------------------------------
THE PARTS, AS ASKED
--------------------------------------------------------------------------------

  1. BOX SIZE: the maximum is no longer 512 (spacr/qt/screens/make_masks.py
     _MAGNIFIER_SIZE_RANGE = (32, 512)); it can go as high as the open image
     is high or wide.
  2. COLLAPSIBLE SETTINGS CATEGORIES in Make Masks, the way the core
     applications fold theirs.
  3. CELLPOSE MODELS: with Cellpose chosen, every Cellpose model in the model
     zoo can be picked, and there is a Model zoo button for Cellpose.
  4. THRESHOLDS: the flow threshold and the cell-probability threshold the
     detection uses can be chosen.
  5. CLICK-AND-DRAG: pressing and pulling keeps generating and applying new
     objects, merging the objects the cursor passes over.
  6. WHAT IS SAVED: an option between saving every object in the zoom area and
     saving only the objects touching the mouse -- so non-centred objects can
     be turned off, and dragging over an object selects and merges all of its
     frames into one object over the centre of the ROI.
  7. OTSU: controls over the Otsu threshold (threshold correction).
  8. SHIFT + SCROLL increases or decreases the box size.
  9. THE EXISTING CELLPOSE-SAM SETTINGS CATEGORY applies to magnifier detection
     when Cellpose is on, and gains the Otsu settings.
 10. OTHER MODELS "if you can": a live YOLO, or DINOCell (spaCR already has
     DINOCell and SAMCell behind `segmentation_backend`, items 404/405).

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

  * The box can be set to the image's full height/width, by field and by
    Shift+scroll, and stops there.
  * Every Make Masks settings category folds and unfolds, and remembers it, as
    the core applications' do.
  * With Cellpose on, the model list is the model zoo's Cellpose models, the
    Model zoo button opens the zoo, and the flow / cell-probability / Otsu
    values set in the Cellpose-SAM category are the ones the magnifier's
    detection actually uses (a test checks the values reach the call).
  * A press-and-drag across cells produces merged objects along the path, as one
    undo step; with "only objects touching the mouse", objects away from the
    cursor are not saved, and dragging over one object merges its pieces into a
    single object centred on the ROI.
  * DINOCell (and SAMCell) are selectable detectors where installed, with a
    clear message where not; YOLO is either added or recorded here with why not.
  * New labels and tooltips are translated in all nine languages.
