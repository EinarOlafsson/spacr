WHAT TO BUILD
  1. A CONSOLE in Make Masks, to the right of the image and below the shortcut
     list, collapsible like every other panel (item 471's primitive). Every
     progress line, warning and failure that currently piles up in the corner
     lands there instead -- including "the magnifier could not segment this
     region" and the stacked progress bars.
  2. THE INSTALL BUTTON TELLS THE TRUTH: while installing it says so, when the
     backend is installed it is greyed and reads that Cellpose 3 is installed,
     and a failure says why, in the console.
  3. CELLPOSE 3 PROVEN ON REAL IMAGES, for object detection AND for image
     enhancement (denoise/upsample), with the timings measured and written
     down. It is reported as "extremely slow": measure where the time goes --
     the worker's model load per call, the whole-field size, the environment's
     torch build -- and fix what can be fixed (keep the model loaded, tile,
     or say plainly that it is slow and why).

DONE WHEN
The console exists and carries that text; the install button reports state
honestly; and the item records real measurements of Cellpose 3 segmenting and
enhancing real images, with the speed either improved or explained.

   restoration_controls.py:17 _restoration_device -> SPACR_DEVICE, else

   'cpu'. (b) A chain with restoration waits 400 ms to settle before
