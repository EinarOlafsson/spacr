--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

The plaque project finished curation on 2026-09-19 and assembled
data/curated_v5: 488 image+mask pairs, 27,582 plaques, deduplicated by pixel
content (893 bundles collapsed to 569 unique images; 81 excluded as skipped).
It is the first plaque dataset covering all four domains:

  literature 298 fields   malnio 96   patrick 67   bigbean 27

Round 5 trains on a grouped split -- by figure for literature, by plate for the
microscope sources, with malnio's own held-out 20 forced into test:

  train 332 fields / 18,532 objects    valid 75 / 4,756    test 81 / 4,294

tools/run_train_r5.py scores F1, precision and recall PER DOMAIN on the test
split, and scores r3 and r4 on the same fields.

spaCR lists toxoplasma_plaque_v1 (cpsam_plaque_r3, repo
einarolafsson/toxoplasma-plaque-segmentation-cpsam) at model_zoo.py line ~350.
Its row quotes "0.8560 in-domain / 0.8060 literature" from 3-fold CV over the
89-well curated set of August -- a fifth of the data that now exists, and no
malnio at all.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

spaCR's plaque users get a model that has never seen a phone-camera well, and a
row whose numbers come from a set that no longer represents the data. Per-domain
scores also let a user predict whether the model suits THEIR images, which a
single blended F1 cannot.
