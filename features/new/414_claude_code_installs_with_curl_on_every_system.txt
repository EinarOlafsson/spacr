WHAT IS THERE NOW
--------------------------------------------------------------------------------

The AI Console talks to vendor coding-agent CLIs, and the Providers dialog
shows each one's install command. For Claude Code the command depends on the
platform (spacr/qt/ai/providers.py, `ClaudeCliProvider.install_hint`, ~303-307):

    Windows          npm install -g @anthropic-ai/claude-code
    macOS / Linux    curl -fsSL https://claude.ai/install.sh | bash

A Windows machine without Node.js has no `npm`, so the command fails with
"'npm' is not recognized ...". The filer read the maintainer's "nmd not
recognized" as exactly that, and the maintainer CONFIRMED the reading with the
question tool on 2026-09-15: "Yes, Claude Code in spaCR" -- "Change the install
command spaCR shows for Claude Code to curl on Windows too, in all nine
languages."

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

  * Claude Code's install hint uses curl on EVERY system, Windows included --
    no Node.js prerequisite. Windows 10 (1803+) and 11 ship `curl.exe`.
  * Use the vendor's CURRENT official native installer commands, checked
    against Anthropic's Claude Code setup documentation at build time rather
    than copied from here. At filing, the documented Windows forms were a CMD
    command that downloads `install.cmd` with curl and a PowerShell `irm ...
    install.ps1 | iex`; the request says curl, so the curl form is shown.
  * The command must run in the shell the dialog tells the user to open (CMD
    vs PowerShell differ: in PowerShell `curl` can resolve to an alias, so name
    `curl.exe` explicitly or say which shell).
  * Every place the command appears changes together: the Providers dialog,
    the install-consent text, the AI Console empty state, tutorials and docs,
    and their translations in all nine languages.

Found beside it, NOT part of this request: the Codex and Gemini hints are
npm-first on every system (providers.py ~341 and ~373). They fail the same way
on a machine without Node.js.

  * A test pins that no Claude Code install hint on any platform starts with

2026-09-15 -- BUILT
--------------------------------------------------------------------------------

spacr/qt/ai/providers.py `ClaudeCliProvider.install_hint` now shows Anthropic's
documented native installer, with curl, on every system -- checked against
https://code.claude.com/docs/en/setup on 2026-09-15 (docs.anthropic.com
redirects there):

    macOS / Linux   curl -fsSL https://claude.ai/install.sh | bash
    Windows         cmd /c "curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd"

The Windows hint wraps the documented CMD command in `cmd /c "..."` so it also
works when pasted into PowerShell, where `curl` can resolve to an alias and
PowerShell 5.1 rejects `&&`. `install.cmd` ends with `exit /b`, so the trailing
`del` still runs.

  * No translation was needed: the hint is in no runtime catalog table, so every
    language already shows the command verbatim.
  * No tutorial or docs page shows the command.
  * tests/qt/test_claude_code_install_hint.py: no Claude Code hint on any
    platform starts with `npm`, and the Windows hint is shell-safe. On the old
    code its three Windows checks fail.
  * OWED: a paste-and-run on a clean Windows machine without Node.js, in both
    CMD and PowerShell, then `claude --version` in a new terminal.
  * Unchanged, as filed: the Codex and Gemini hints are still npm-first.
