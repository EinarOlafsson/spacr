A LINE RULER IN IMAGE EDITING AND MASK PREVIEWS

Status: DONE 2026-09-25. Validated 2026-09-22; since 2026-09-25 the ruler also reads
the micron spacing an opened file's header states (see the last note).
Owner: implementation; API/settings descriptions and translations coordinated with the documentation lane.

REQUEST
Draw a line on an image and read its length in Make Masks and applicable Mask Generation live previews.

ACCEPTANCE
Use image coordinates, so zoom/pan do not change the length. Report pixels, and calibrated physical length when valid pixel spacing is available. Drawing a ruler must not edit masks; endpoints and readout remain visible until cleared.

Validate real UI interaction and affected pixel/mask behavior with focused tests.

2026-09-22 — IMPLEMENTED: Ruler joins Make Masks' tool row and the live
preview action row. Left-drag measures; right-click in Ruler clears. Image
endpoints and labels survive zoom, pan and display refreshes; opening a field
clears the ruler/calibration. Paired preview views share the same ruler.
ImageRuler is reusable, reports pixels by default, and offers explicit
validated per-axis physical calibration through set_spacing; no calibration
is inferred from magnification or loaded metadata. Masks/history are untouched.
Ruler and magnifier gestures are mutually exclusive. The shortcut panel now
scrolls at laptop height instead of compressing its text; right-button help
follows the active tool.208 focused checks pass in40.67s;68 affected checks
pass after the shortcut layout change in13.23s. Reviewed actual MainWindow
1366x768 and paired preview1100x700 renders, each showing a100px line.

2026-09-25 — THE RULER READS THE SPACING A FILE STATES; CLOSED
What remained of the ACCEPTANCE: "calibrated physical length when valid
pixel spacing is available". On 2026-09-22 nothing in spaCR read a pixel
size from an image, so both hosts cleared calibration on every field. Item
509 has since added spacr.point_spread.image_optics_metadata, which reads
only what a TIFF header states (OME PhysicalSizeX/Y, an ImageJ micron
calibration, centimetre resolution tags). ImageRuler.calibrate_from_file
now takes that stated size and nothing else: a magnification in the file
name, the objective table and the defaults never calibrate the ruler. It
clears first, so a file that states nothing stays in pixels, and it refuses
when the header's (Y, X) is not the displayed array's (a resampled or
cropped display is not measured with the file's pixels). Make Masks calls it
when a field is installed (_apply_loaded_pair), the Mask Generation live
preview when an image is loaded (_install_loaded_image); set_spacing is
unchanged for explicit calibration and Plaque keeps its own.
