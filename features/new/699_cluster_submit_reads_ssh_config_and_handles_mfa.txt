--------------------------------------------------------------------------------
WHAT TO BUILD
--------------------------------------------------------------------------------

1. "Find my SSH settings" button in the Submit to cluster popup.
   - Searches the usual places: ~/.ssh/config (and Include'd files),
     /etc/ssh/ssh_config, %USERPROFILE%\.ssh on Windows, plus known_hosts for
     host names; lists the Host entries found (alias, HostName, User, Port,
     IdentityFile, ProxyJump/ProxyCommand, ControlMaster settings).
   - The user picks one; the dialog fills server, user, port, key file and
     jump host. A "Choose folder..." button lets the user point at another
     .ssh folder manually.
   - Read-only: spaCR never edits the user's SSH files and never copies or
     uploads private keys; it stores only the path to the key.
2. Second-factor logins (Great Lakes uses Duo; others use Okta Verify).
   - Use keyboard-interactive authentication and show the server's prompts
     verbatim in a spaCR dialog (password, "Passcode or option (1-3)", push
     choice), so Duo/Okta push, phone call and one-time codes all work
     without hard-coding any vendor.
   - Reuse one authenticated connection for the whole session (OpenSSH
     ControlMaster/ControlPersist where available, or one persistent
     paramiko/asyncssh transport) so the user approves the second factor
     once, not on every file copy or squeue poll.
   - Clear messages for a denied or timed-out push, with a retry.
   - Never store passwords or one-time codes; optional OS keychain storage of
     the password only if the user ticks a box.
3. A "Test connection" button that logs in, runs `hostname` and `sinfo`, and
   reports success or the exact failing step.
4. Every new string through tr(); help text names Great Lakes as an example.

--------------------------------------------------------------------------------
ACCEPTANCE
--------------------------------------------------------------------------------

- With a ~/.ssh/config Host entry for Great Lakes, one click fills the form.
- Logging in to Great Lakes with Duo push works once per session; a job
  submits and its status updates without further prompts.
- Tests: config parsing (Include, wildcards, ProxyJump), Windows paths, a
  fake keyboard-interactive server with a two-step prompt, denied push.
