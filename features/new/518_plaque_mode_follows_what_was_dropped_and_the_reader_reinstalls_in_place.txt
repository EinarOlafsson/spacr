WHY IT ASKED TO "REINSTALL FROM THE MODEL ZOO"
  The only sentence of that shape is the reader worker's own, in
  _worker_read_pdf (spacr/_segmentation_backends.py:2905-2910 on nightly
  83a726b59): "This figure reader was installed before it read PDFs.
  Reinstall the plaque figure reader from the Model Zoo to add pdfplumber."
  It is raised when `import pdfplumber` fails inside the reader's
  environment, i.e. whenever a PDF is read in Figure mode (a drop, the PDF...
  button, a paper fetch).

  On THIS machine now it is not a false alarm and not reproducible: the
  readiness check (_backend_state('papers')) says installed, the
  environment ~/.spacr/backends/papers (built 2026-09-24 11:22 by spaCR's
  installer) records and holds pdfplumber 0.11.10 and imports it under -I,
  and a real PDF read through the worker returns its pages. 475's
  backend-environment changes did not touch this path (_clean_env,
  _worker_env and _serve_env pass the papers worker through unchanged). An
  environment built before item 424 pinned pdfplumber (2026-09-21 23:16)
  does raise it: the 469 sandbox reader
  (/mnt/wd4tb/spacr_testdata/backends_sandbox/papers, 2026-09-21 16:20, no
  pdfplumber) reproduces it. ~/.spacr/backends/papers was not modified.

  What made the message a dead end, and is fixed:
  * Nothing checked the install record before reading, so the old reader
    was only found by failing mid-read.
      -> _stale_requirements (spacr/_segmentation_backends.py:799) compares
         the record's requirements with the pins spaCR has now;
         plaque_papers.reader_problem (spacr/plaque_papers.py:895) answers
         ('', '') / ('install', why) / ('reinstall', why) from disk only.
  * The Model Zoo cannot reinstall: _install_backend returned at once for
    an installed backend (spacr/_segmentation_backends.py:1532 on nightly).
      -> reinstall=True (line 1575) stops the running worker and builds the
         environment again.
  * The worker blamed an old install for ANY ImportError, including a
    pdfplumber that is present but fails to load.
      -> only a ModuleNotFoundError naming pdfplumber says "installed before
         the reader read PDFs"; anything else says pdfplumber does not load,
         with the real error (line 2939). Neither mentions the Model Zoo.

  Now a src naming a PDF, or a folder of PDFs, in Figure mode is read the way

  PDF's own text".

THE READER INSTALLS IN PLACE
  _offer_install (plaque_preview.py:3609) opens the Model Zoo's own
  BackendInstallDialog through install_backend(watch=..., reinstall=,
  why=) (model_zoo_picker.py), and follows its job signals the way 507's
  _BackendInstallButton does: the status line says "Installing Plaque
  figure reader...: <step>", then "Plaque figure reader is installed", or
  "Installing ... failed. Nothing was left half-built. <pip's words>", or
  "Cancelled. Nothing was left behind." The dialog has a Reinstall face
  (title, button, and a sentence that the environment is deleted and built
  again). Figure mode's banner shows Reinstall when the record lacks a pin.
  A PDF that needs the reader offers the install before reading
  (fetch_paper, :4427) and reads it once the install worked; a reader that
  only says so while reading (ReaderNeedsInstall from the worker) gets the
  same offer when the fetch returns. One offer per PDF.

THE MODE FOLLOWS THE INPUT
  plaque_inputs (dnd_handlers.py:1565) reads the top level of what was
  dropped or named: PDFs, plaque images, and paper folders (paper.json,
  legends.csv or text_layer.json -- Figure mode's input). input_mode_question
  / input_mode_box / follow_the_input (plaque_preview.py:4701-4845), a
  QMessageBox so it wears spaCR's glass dialog:
    PDFs or paper folders in Plaque mode  -> "Switch to Figure mode?"
       (Switch reads the first PDF; Stay leaves it unread)
    images in Figure mode                 -> "Switch to Plaque mode?"
       (Switch sets src; Stay reads them as figures)
    both                                  -> "PDFs are read in Figure mode,
       images in Plaque mode." with Figure mode: read the PDFs / Plaque
       mode: read the images / Cancel.
  For drops (PlaqueDropHandler.apply_all, dnd_handlers.py:1532; a folder of
  PDFs is now accepted) and for src (400 ms after typing stops, asked once
  per source and mode, only while the screen is shown; a src a drop wrote
  is not asked about again).
