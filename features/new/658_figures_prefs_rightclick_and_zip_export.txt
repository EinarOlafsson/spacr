THE STYLE API (part B consumes this; all private, no API-pin moves):
  spacr/figure_style.py
    GENERAL_DEFAULTS     + legend_size, colormap, figure_width, figure_height,
                           despine_offset, also_save, vector_text, error_bars,
                           ci_level, error_capsize, jitter_width, point_alpha,
                           point_overlay (36 keys).
    STYLE_CHOICES        format + tiff; also_save; colormap leads with the
                           colour-blind-safe viridis/cividis; error_bars + ci.
    rc_params            legend.fontsize, image.cmap, errorbar.capsize,
                           pdf/ps/svg fonttype, custom figure size.
    _user_deltas(kind, general, overrides)  the settings the user changed.
  spacr/figures/style.py
    _preference_deltas(kind=None)   the same, read from the preference store.
    _apply_user_style(fig, kind=None, *, force=False)
        THE one post-hoc application: font family, title/label/tick/legend
        sizes, line width, marker size, palette (default-palette colours are
        remapped by position), colormap, background, grid, spines, despine
        offset. Applied once per figure (flag `_spacr_user_style_applied`),
        so a right-click restyle is never undone by a later save. A figure
        may carry `_spacr_graph_kind` to pick its per-graph layer.
  spacr/plot.py
    save_figure          applies _apply_user_style, honours the style format,
                           DPI, vector text and "Also save" (second copy).
    figure_output_preferences  a style format/DPI the user changed wins.
    FIGURE_FORMATS       png, pdf, svg, tiff.
    spacrGraph           palette, error bars (sem/sd/ci at CI level/ci95/
                           none), cap size, jitter width, point alpha, marker
                           size and point overlay follow the preferences.

ONE MENU ON EVERY CANVAS. `figure_settings._attach_figure_menu(canvas)`
installs a per-canvas event filter that opens `build_figure_context_menu` on
a right-click. It is attached in graph_builder._canvas_class (shared by graph
builder, sweep panel, feature explorer, volcano, measurement compare, PCA,
save-figure preview, control chart, dose response, map barcodes),
train_compare.panel_canvas_class and the UMAP explorer canvas. The figure
queue already built that menu. Volcano and Gate Editor keep their own menus
and append the shared entries (`_add_figure_tools`).
  * "Edit figure…" (was "Figure settings…"): FigureSettingsDialog, which has
    titles, labels, limits, scales, fonts, colours, legend, size and DPI, all
    applied live. It now opens on every canvas, not only the queue.
  * "Change graph type": the kinds that fit the data (groups: box, violin,
    strip, swarm, bar, point, boxen, box/bar with points, hist, kde, ecdf;
    two measurements: scatter, line, hexbin, kde, regression; one
    distribution: hist, kde, ecdf, box, violin, strip, boxen; counts: count,
    heatmap; matrix: heatmap, clustered heatmap). It redraws in place from
    the stored data with `figures.bundle._draw`, then applies A's
    `figures.style._apply_user_style`. The older "Graph type" submenu (the
    spaCR house types via create_grouped_plot) is still there.
  * "Statistics…": `_StatisticsDialog`. The test is chosen automatically, and
    the user can override the test, the subject column, paired and the
    correction. Apply stores the choice on the figure spec and draws the
    test line and significance brackets (`bundle._annotate`).
  * "Save figure (zip)…": `bundle._save_zip` writes ONE zip with the image in
    the preference format plus PNG (through save_figure), data.csv,
    statistics.csv, statistics.txt, spec.json (the full recipe) and
    recreate_figure.py (the same `_draw`/`_annotate` source, so it re-creates
    the figure from the CSV and JSON without spaCR).

DATA AND SPEC ON EVERY FIGURE. `bundle._register_figure_data(fig, frame, x=,
y=, hue=, kind=, **spec)`. Graph Builder registers at every render and the
volcano when its menu opens. create_grouped_plot figures are read through
their `_spacr_replot` recipe. Any other single-axes figure falls back to
`derive_replot_recipe` (its points read back from the artists).

STATISTICS, ONE CSV (`figures.stats._auto_statistics`). The columns are
test_stage, test_name, groups, statistic, df, p_value, p_adjusted,
correction, effect_size, effect, n, chosen_by (auto/user) and reason.
  * Groups: Shapiro-Wilk per group, then Bartlett (all normal) or Levene. Two
    groups get Student's t, Welch's t or Mann-Whitney; paired data gets
    paired t or Wilcoxon. Three or more get one-way ANOVA then Tukey HSD,
    Welch's ANOVA then Games-Howell, Kruskal-Wallis then Dunn (corrected), or
    Friedman then pairwise Wilcoxon (corrected).
  * Two measurements: Pearson or Spearman, chosen by normality.
  * Counts: chi-square, or Fisher's exact when an expected count is under 5.
    Fisher on a table larger than 2×2 is Fisher-Freeman-Halton with a seeded
    Monte Carlo p. Pairwise tables are corrected.
  * Proportions (0/1 outcome): two-proportion z or Fisher's exact; with
    three or more groups, chi-square then corrected pairwise z.

PART C — EVERY FIGURE REGISTERS ITS DATA (2026-10-05)
--------------------------------------------------------------------------------

ONE HELPER. `figures.bundle._register_figure_data(figure, data, x=, y=,
hue=, kind=, **spec)` is the only way a figure gets its data. It takes a
figure or an axes; a frame, a series, a mapping of group to values, a
vector, or a callable returning one (so building the frame can never break
the figure: an error is logged and the figure is left unregistered). Kinds
"image", "mask", "montage" and "overlay" (or arrays of 2+ dimensions that
are not a heatmap) mark a PICTURE: its arrays and metadata are kept instead
(`_spacr_image`), and `_is_image_figure` says which.

REGISTERED AT CREATION in every figure-producing function (about 170 call
sites in 55 modules): regression and diagnostics (regression_diagnostics,
regression_panels, regression_qc, utils.model_metrics, plot._show_residules,
_reg_v_plot), plate maps and heatmaps (figures.plates, measure wound plate,
gene sweep grids, correlation/confusion matrices, toxo heatmaps), UMAP and
embeddings (utils.plot_embedding, umap_explorer, pca_view, hyperparam
panels), classify training curves (deep_spacr._plot_training_curves,
io.read_plot_model_stats, train_compare.plot_curves and its screen) and
confusion/calibration figures, Measure and QC (DNA histogram, wound curves
and half-closure, viability thresholds/controls, seg_qc robustness,
sequencing QC, illumination QC, permutation QC), plaque (colony sizes and
overlays) and motility (timelapse track plots, new `_track_frame`), survival
(Kaplan-Meier and hazard ratios), dose-response (measure viability dose,
dose_response screen), control charts (canvas, anomaly review, hit
structures as a picture), and the figure-queue producers (figures.sheet
`attach`/build_panel/build_sheet, distributions, create_grouped_plot,
spacrGraph, the legacy plot.py functions, sim, toxo, submodules).
Micrographs, masks, overlays, montages, Grad-CAM/saliency/IG maps register
as pictures.

MENU SHOWS ONLY WHAT APPLIES. A picture's menu has Edit figure, Legend,
Appearance, the plain saves and "Save figure (zip)…"; no Graph type, Change graph type, Statistics, the folder
"Save", Grid or Axis scale. Its zip (`bundle._save_image_zip`) holds the
figure in the default formats, each array as image_<n>.tif (.npy without
tifffile) and metadata.json (spec, titles, size, every array's shape and
dtype). A plot's zip now also tests a figure's `_spacr_groups` when it has
no x/y (figure-sheet panels).
