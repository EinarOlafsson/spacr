ALPHA, 2026-09-28: what was built.
  1. Every "(Alpha)" category is now "<Name> α" (16 of them, in
     spacr.settings.categories and every module layout). The heading reads
     "CONFLUENCY α" -- the name upper-cased, the mark kept lower-case -- and
     no longer "· ALPHA"; a whole alpha module's headings end with α too.
     The colour is one token, spacr.qt.theme.ALPHA_INK (#00948F), set on
     QToolButton#SectionHeader[maturity="alpha"] in every theme (3.7:1 on
     the light theme's white, 4:1 or more on every dark surface).
     settings_section_maturity reads a trailing α as alpha.
  2. Mask generation (and Timelapse, which shares its layout): the Cloud
     category is "Cloud α" (its keys were already alpha, item 550); the
     illumination correction, PSF and image enhancement settings are alpha
     ON THESE TWO MODULES ONLY, through a new ALPHA_FEATURES kind,
     'module_settings' ({module: (keys,)}), registered under 591. The same
     keys stay ordinary on Measure and on the Illumination Correction
     module, whose whole form they are.
  3. Image Preprocessing keeps its own rows and nests "Illumination
     Correction α", "Image Deconvolution α" (the PSF settings) and "Image
     Enhancement α" below them (settings_model._APP_CATEGORY_PARENTS; the
     old top-level categories are gone from both layouts). With alpha
     features off the three sub-headings hide; Image Preprocessing stays.
  4. Untested features (below): three that were not behind the flag now are.
  Tests: tests/qt/test_591_alpha_categories_read_as_alpha.py (hidden off,
  shown on, a value set while hidden reaches collect(), scoping, heading
  text, colour in dark and light). Captions for the new titles and the Image
  Deconvolution blurb wait in _AWAITING_CATALOG_REBUILD.
