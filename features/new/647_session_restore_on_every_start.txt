================================================================================
SESSION RESTORE ON EVERY START
================================================================================

Status:    DONE 2026-10-04
Requested: 2026-10-04, by the maintainer, who approved this program-level
           feature in the step-4 review ("is the program itself missing
           something?"), from the gap audit of the same day.

WHAT TO BUILD
  Session restore on every start: reopen the last module, settings and folder after any exit or crash, not only after updates.

DONE WHEN
  The feature works on Linux, macOS and Windows, is reachable from the GUI
  where it applies, has tests, and is documented.

DONE 2026-10-04
  spacr/restart_state.py keeps the last session (module, settings, folder)
  in the Qt preference store; MainWindow writes it every 30 s and on a clean
  close, and every ordinary start reopens it (a CLI module or a Force restart
  record wins). Preferences -> Modules -> Session switch (RestoreLastSession,
  default on); "Open fresh" status-bar button and `spacr-qt --fresh` skip it.
  Tests: tests/qt/test_session_restore_and_settings_autosave.py. Docs:
  docs/source/features.rst "Picking up where you left off".
  Left: catalog rebuild for the new captions (in _AWAITING_CATALOG_REBUILD);
  a Windows/macOS manual check (store is QSettings, so no path code differs).
