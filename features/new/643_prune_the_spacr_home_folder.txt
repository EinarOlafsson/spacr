2026-10-14 — active worker-thread run journals protected from pruning:
The storage worker's thread-local current_run is empty while a pipeline runs
on another thread. An active journal older than the age floor could therefore
appear in the prune plan and delete_runs could remove it, breaking its next
manifest write. Two native temporary-thread cases reproduced both failures.

A guarded process-wide set now retains every open_run directory throughout
its pipeline and finalization. Prune planning includes that snapshot; explicit
delete_runs refuses active directories and their descendants/ancestors using
the existing still-running refusal. The thread-local current_run contract and
nested restoration remain unchanged. Protection is always removed at context
exit, including pipeline and finalizer failure, so completed records remain
deletable. The lock is reinitialized after fork where supported.

environment/provenance/provider operations are stubbed. Closed, failed and
nested runs and active child-folder preservation are covered. No captions,

Scope is active runs registered in THIS process, including its storage
worker. Separate-process/remote-host live-run detection and native fork/OS
acceptance are not established by these tests. No real jobs, logs, annotations,
