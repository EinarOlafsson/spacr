--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

`tools/extract_source_notes.py` classifies every comment in the package,
moves the ones worth keeping to `docs/notes/<same path>.md`, and strips them
from the source. It is a dry run unless `--execute`, and it writes
`--discard-log` so a real run throws nothing away irrecoverably.

THE SAFETY PROPERTY IS AST EQUALITY, AND IT IS NOT SKIPPABLE. Every file is
compared `ast.dump(ast.parse(before)) == ast.dump(ast.parse(after))` before
it is written, and a file whose AST moved is refused. A comment strip that
changes behaviour is the only way this task can do harm, so it is the one
thing the tool will not do.

Current measurement: 512 modules stripped, 491 notes files written, ~50,500
comment lines removed. The 71 `#` lines that remain in `spacr/` are all
inside string literals -- QSS selectors (`#Sidebar`), a GLSL `#version 120`,
and `# BEFORE` / `# AFTER` examples inside docstrings.

HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

Not a full-suite run in one process. That was tried and is not survivable:
`tests/conftest.py` enforces a 6 GB ceiling with `os._exit(3)`, and the run
reached 5.3 GB at 9 % after 80 minutes, projecting ~14 hours. Use
`tools/run_pytest_batches.py` the way CI does, or raise
`SPACR_TEST_MEMORY_GB` deliberately.

    python tools/extract_source_notes.py          # dry run, expect no changes

A clean dry run on a merged tree means nothing was missed.
