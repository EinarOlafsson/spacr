--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

`tools/extract_source_notes.py` classifies every comment in the package,
moves the ones worth keeping to `docs/notes/<same path>.md`, and strips them
from the source. It is a dry run unless `--execute`, and it writes
`--discard-log` so a real run throws nothing away irrecoverably.

THE SAFETY PROPERTY IS AST EQUALITY, AND IT IS NOT SKIPPABLE. Every file is
compared `ast.dump(ast.parse(before)) == ast.dump(ast.parse(after))` before
it is written, and a file whose AST moved is refused. A comment strip that
changes behaviour is the only way this task can do harm, so it is the one
thing the tool will not do.

Current measurement: 512 modules stripped, 491 notes files written, ~50,500
comment lines removed. The 71 `#` lines that remain in `spacr/` are all
inside string literals -- QSS selectors (`#Sidebar`), a GLSL `#version 120`,
and `# BEFORE` / `# AFTER` examples inside docstrings.

WHY THE PACKAGE-WIDE RUN WAS REVERTED TODAY, AND WHAT THE TOOL MUST LEARN

Running `tools/extract_source_notes.py spacr --execute` removes comments that
are INSTRUCTIONS TO THE GATES, not prose:

    -def changeEvent(self, event) -> None:            # noqa: N802
    -from ..fractal_defaults import (GPU_ONLY_PATTERNS,  # noqa: E402
    -raise AssertionError(                            # pragma: no cover
    -from . import illumination as _illumination  # noqa: E402,F401

Five such comments went in one run, and ruff then reported 1,460 errors. The
AST-equality check cannot catch this: removing `# noqa` does not change the
AST, it changes what ruff, mypy and coverage.py do with the file. A stripped
`# pragma: no cover` silently moves the coverage ratchet.

SO, BEFORE THIS ITEM IS RUN AGAIN: the classifier must treat any comment
matching `noqa`, `pragma`, `type: ignore`, `isort:`, `fmt: off/on`, or
`coding:` as UNTOUCHABLE -- never moved to notes, never stripped, whatever
the prose classifier thinks of it. Add a test that feeds each of those
through the tool and asserts the line survives, then re-run per-directory
with `ruff check` and the coverage ratchet after each directory rather than
once at the end.

The package-wide run was reverted in full today; only setup.py is kept.
