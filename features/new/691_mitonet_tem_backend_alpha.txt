MITONET AS AN ALPHA MAKE MASKS BACKEND FOR TEM
================================================================================

--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

N690 made Make Masks open TEM images and published ten TEM fields with
mitochondria masks (spacr-example-tem). Its assisted segmentation was
Cellpose-SAM, which drafts F1 0.467 there: it outlines every organelle. The
N690 agent ran empanada's MitoNet_v1_mini TorchScript with its own
post-processing and got F1 0.823. empanada-dl pins numpy==1.22, so it cannot
be a dependency.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

A usable first draft on TEM turns curation from drawing every mitochondrion
into correcting a few, which is what makes curated TEM training data cheap.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Add MitoNet_v1_mini to the model zoo as an external (third-party) model:
   weights from Zenodo record 6861565 on first use, cached and checksummed
   like the other zoo weights; record the weights' licence (CC-BY-4.0,
   citation Conrad and Narayan, Cell Systems 2023) and the code licence
   (BSD-3-Clause). Not under the "spaCR" heading.
2. Port the post-processing (semantic and instance-centre heads, offsets,
   then instances) into an existing module; no empanada-dl, no new module.
3. Offer it in Make Masks' Object detection Method box as
   "MitoNet (TEM mitochondria)", registered in ALPHA_FEATURES with a literal
   setObjectName, hidden unless Show alpha features is on.
4. CPU-only tests without network (synthetic heads, a mocked download, the
   alpha gate), and the F1 of the ported code on spacr-example-tem.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

- With Show alpha features on, Make Masks' Method box offers MitoNet (TEM
  mitochondria); choosing it on a TEM field drafts mitochondria; the first
  run downloads the weights, later runs reuse the verified cache.
- The Model Zoo lists the row under a Third-party heading with its licence
  and citation; with the gate shut neither the row nor the heading shows.
- The ported code reproduces N690's F1 0.823 on spacr-example-tem.

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- The full MitoNet_v1 (221 MB) and the quantized variants are not offered.
- No fine-tuning on Toxoplasma TEM; no multi-class organelle model.
- empanada's 3-D (orthoplane) inference is not ported; 2-D only.

undone before the network; whole-image runs count tiles on the run ticket

models mitonet_mini_v1, widgets MakeMasksMitoNetSettings and
ModelZooSourceThirdParty; alpha slide regenerated (63 features).

F1 0.844, Dice 0.842, so stitching costs nothing.
