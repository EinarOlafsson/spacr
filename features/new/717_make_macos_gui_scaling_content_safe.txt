MAKE MACOS GUI SCALING CONTENT-SAFE
================================================================================

Status:    DONE 2026-10-21 — macOS/laptop scale, dialog, toggle, icon and tooltip acceptance passed
Requested: maintainer, 2026-10-21 — prevent clipped text, controls, icons and popup content at every supported scale
Priority:  P1
Owner:     Codex macOS GUI lane — implementation and focused validation

SCOPE
Make scaling resilient throughout the Qt GUI, with macOS as the immediate
acceptance platform. Text must receive enough space or adapt instead of being
cut off, including Home's bottom help and module buttons such as Live, 3D and
AI. Button icons must retain their intended proportion to their button as GUI
scale changes and must never be clipped.

Popup windows must initially fit their useful content on the available screen,
including the usual content of tabbed dialogs, while remaining freely
resizable. Content that cannot reasonably fit must be scrollable. macOS boolean
controls must retain a clean ring or borderless silhouette, never bracket-like
edges, and must not become oversized at particular GUI scales.

Every tooltip API link must display exactly "API". A shown tooltip must remain
visible while the pointer is still over its source or the tooltip itself. The
default GUI and font scales, including the reset-to-default action, are 90%.
