--------------------------------------------------------------------------------

in the settings as explicitly user-supplied, and spacr/crops.py
reconcile_merged_mask_dims raises when such a value disagrees with the
merged folder's .spacr_plane_layout.json. A GUI run always carries every
key, so a value the form filled in (here cell 2 / pathogen 3 for channels
[0, 1]) counts as explicit. The reporter's merged folder recorded no
pathogen plane, so the run stopped. Whether the form's value was the
user's or a derived default is what the fix must establish; the issue's
settings carry no other signal. No fix exists on nightly, main or any PR.

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------

Reproduce with a merged folder whose manifest records no pathogen and the
reporter's settings. Decide from the code which values are derived vs
typed, keep the refusal for a genuinely explicit wrong plane, and make the
error actionable (which setting, what the folder has, how to fix). Test it.
