WHAT TO BUILD
  1. Make Masks and Plaque Assay both accept dropped FILES (one or several
     images, any supported format) as well as a dropped folder. Several
     files become the queue/list in the order dropped; a mix of files and
     folders is accepted.
  2. Plaque Assay has its own drop handling and its own messages. Today a
     folder dropped on it is refused with Make Masks' message ("... can't be
     used as is; Make Masks needs a folder ..."), which means it reuses
     Make Masks' drop validator. Plaque must accept its own inputs (a folder
     of plaque images, plaque image files, or a PDF/figure in figure mode)
     and word any refusal in plaque terms.

DONE WHEN
Offscreen tests drop a folder, one file, several files and a mix on each of
Make Masks and Plaque Assay and see them loaded; no Plaque message mentions
Make Masks.

NOTE 2026-09-25 -- implemented
ROOT CAUSE OF THE PLAQUE MESSAGE. The drop registry mapped Plaque Assay to
Make Masks' policy: spacr/qt/dnd_handlers.py:3538 (at 9996410da)
    "analyze_plaques": MakeMasksDropHandler,
That handler accepted only a folder with images at its top level
(dnd_handlers.py:1435) and refused anything else with its own sentence,
"Make Masks needs a folder of images to fine-tune Cellpose against."
(dnd_handlers.py:1455), which the "Did you mean..." dialog prints under
"<folder> can't be used as-is." (spacr/qt/dnd.py:1011). So a Plaque folder
whose images were one level down, or a figure folder, got Make Masks' words.

WHAT CHANGED
  * spacr/qt/dnd.py: DropHandler.apply_all(paths, screen) (default declines);
    _deliver_drop hands every accepted path of ONE drop to it once, in drop
    order, before falling back to per-path apply(). Needed because apply()
    once per path cannot tell a drop's second file from the next drop.
  * spacr/qt/dnd_handlers.py
      - MakeMasksDropHandler: accepts image files (mask_engine.IMAGE_EXTS)
        as well as folders, accepts_multiple, apply_all -> the screen's
        open_paths(). A screen without open_paths still gets src as before.
      - CellposeFolderDropHandler: the old folder-only policy and sentence,
        kept for train_cellpose / cellpose_masks / cellpose_all, whose src is
        a folder the run lists.
      - PlaqueDropHandler (registry: "analyze_plaques"): plaque images
        (plaque_papers.IMAGE_SUFFIXES), folders of them, mixes, and a PDF.
        One folder -> src as before. Files that are exactly one folder's
        images -> that folder. Any other selection -> plaque_selection_folder:
        plaque_selection_<time>/ beside the first image (temp folder if not
        writable) holding symlinks (hard links as fallback) to the images,
        never copies; the run writes its masks beneath it as for any folder.
        A PDF in Figure mode goes to the panel's fetch_paper (the PDF...
        button's route); in Plaque mode it is refused in plaque words.
  * spacr/qt/screens/make_masks.py: MakeMasksScreen.open_paths(paths). One
    folder -> _open_folder as before. Otherwise a queue of the named fields
    in drop order (a folder stands for its images); when they span several
    folders a parallel _field_folders list sets _folder per field in
    _load_current, so each mask lands in its own <folder>/masks. Recrop
    insert/pop keep the list aligned; "Mask the whole folder" refuses a
    multi-folder queue.
