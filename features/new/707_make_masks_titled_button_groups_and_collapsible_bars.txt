   every saved mask to the remembered make_masks/vvvv_export_dir or else
   <folder>/vvvv/make_masks; AppScreen._on_run overwrites a run's
   export_vvvv with it, so Mask generation and Measure write vvvv/mask and
   vvvv/measure as before. export_vvvv is in _APP_HIDDEN_KEYS for mask,
   measure (and timelapse, already) and out of their category layouts, so
   no module form shows it; the key stays in the settings dict, so headless
   and CLI runs keep their own value.

   (makeMasksGroup property, title label MakeMasksGroupTitle; theme.py
   styles them as cards): MakeMasksToolsGroup (a FlowLayout, so tools wrap
   rather than scroll), MakeMasksAnnotationGroup, MakeMasksIoGroup,
   MakeMasksNavigationGroup. Keep and Save mask are _SplitMenuButtons (as
   Load test data); Hide judged fields, First unreviewed, Blind, Save on
   navigation and Upload data are QActions under the old attribute and
   object names. Open File / Folder: click = folder; arrow menu = Open

   stack (empty state / view tabs) now lives in the image container, so IO
   stays usable before anything is open. Uncertainty and SAM2 tracking

   "index / total · name" bottom left of the image (blinded: the code).
