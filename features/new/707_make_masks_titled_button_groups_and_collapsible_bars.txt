2026-10-16 — what was done (Claude, worktree mm-layout)
--------------------------------------------------------------------------------

A. Preferences -> Plugins now exists whenever the plugin catalogue OR the
   new "Export to vvvv" checkbox (object name PreferencesExportVvvv) is
   shown. The checkbox is registered under item 685 in ALPHA_FEATURES in
   place of the two retired Make Masks buttons, so it shows only with "Show
   alpha features" on; default off (key plugins/export_vvvv).
   preferences._vvvv_export_enabled() is the one switch: Make Masks exports
   every saved mask to the remembered make_masks/vvvv_export_dir or else
   <folder>/vvvv/make_masks; AppScreen._on_run overwrites a run's
   export_vvvv with it, so Mask generation and Measure write vvvv/mask and
   vvvv/measure as before. export_vvvv is in _APP_HIDDEN_KEYS for mask,
   measure (and timelapse, already) and out of their category layouts, so
   no module form shows it; the key stays in the settings dict, so headless
   and CLI runs keep their own value.

B. _build_ui/_build_tool_row/_build_navigation_bar build four QFrames
   (makeMasksGroup property, title label MakeMasksGroupTitle; theme.py
   styles them as cards): MakeMasksToolsGroup (a FlowLayout, so tools wrap
   rather than scroll), MakeMasksAnnotationGroup, MakeMasksIoGroup,
   MakeMasksNavigationGroup. Keep and Save mask are _SplitMenuButtons (as
   Load test data); Hide judged fields, First unreviewed, Blind, Save on
   navigation and Upload data are QActions under the old attribute and
   object names. Open File / Folder: click = folder; arrow menu = Open
   folder… / Open file (2D or 3D)… (_on_pick_file: volumes through
   open_volume, 2D files open their folder at that image). Measure…: click
   = Organize for Measure (2D); _add_measure_section(label, callback)
   adds further sections (the 3D one) to its menu. Undo/Redo became
   QActions _act_undo/_act_redo that the Edit menu reads (app.py). The body
   stack (empty state / view tabs) now lives in the image container, so IO
   stays usable before anything is open. Uncertainty and SAM2 tracking
   (both alpha, not named in the request) moved to Object operations too.
   DEFAULT_BRUSH_RADIUS = 1. _MaskCanvas.field_label paints
   "index / total · name" bottom left of the image (blinded: the code).

C. The image container is a vertical CollapsibleSplitter (Top bar / Image /
   Bottom bar as EDGE panes, fold keys make_masks/TopBar and
   make_masks/BottomBar); the title bar is an EDGE pane of
   MakeMasksChrome (make_masks/Title). All persist via set_folded_panel.

D. collapse_arrow.HANDLE_SCALE = 0.75 scales tab and chevron;
   _collapse_arrow_geometry() computes both in floating point around
   QRectF(rect).center(), so they are centred to the sub-pixel on every
   splitter handle and the dock edge.

E. tests/qt/test_707_make_masks_titled_groups_and_collapse.py (placement and
   titles, one button per group, renamed/removed labels, Keep and Save
   menus, Measure extension point, open file, brush 1 px, overlay format,
   persisted collapse states, arrow geometry, vvvv preference); existing
   tests moved to the new names.

Screenshot: /mnt/wd4tb/scratch/mm-layout/make_masks_layout_dark.png (1920x1080
offscreen).
