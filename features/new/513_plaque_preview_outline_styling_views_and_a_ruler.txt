NOTE 2026-09-25 -- part 3 built: the four views, from 505's widget
BUILT (spacr/qt/widgets/plaque_preview.py; no new module)
  * The Overlay/Objects/Cell probability/Flows QTabWidget and its three
    extra _ImageViews are gone. The image pane is now
    segmentation_views.SegmentationViews(self, canvas=self._view): the
    plaque _ImageView is the one canvas, so zoom, pan, clicks and the one
    ruler work on every view. A view dropdown (make_selector,
    "PlaqueViewSelector") sits first in the zoom row, as in Mask
    generation's live preview; figure mode hides it and forces Overlay
    (it replaces the hidden tab bar).
  * View names, order and drawing are the shared ones: Overlay, Masks,
    Flows, Cell probability (IMAGE_TABS is now an alias of
    segmentation_views.VIEWS; "Objects" became "Masks"). Masks use
    render_labels' palette, cell probability is render_cellprob on magma,
    and "This run gave no cell probability map." / "This run gave no
    flows." come from the widget. plaque_preview.render_cellprob IS
    segmentation_views' (re-exported, the duplicate deleted);
    render_objects delegates to render_labels.
  * Overlay keeps the plaque's own renderer (set_renderer(OVERLAY)):
    _overlay_source + _show_overlay replace every direct _view.set_image
    on the main pane, and _render_overlay_view returns
    boxed_picture(rgb, boxes, selected, box_thickness) -- the box painting
    moved out of _ImageView.set_image into module function boxed_picture
    -- so line weights, fill, colours and well boxes are unchanged. A
    Masks renderer adds "No plaques were found in this image."
    (NO_PLAQUES) for an empty run.
  * _ImageView gains set_pixmap/picture/picture_name/set_picture_name
    (the canvas contract). array() is now the shown picture's pixels (in
    figure mode that includes the boxes; only tests read it).
  * Right-click: on Overlay (and the well crop) the menu is unchanged; on
    Masks/Flows/Cell probability it holds only "Save picture...", which
    saves the shown view, offered as plaque_<view>.png
    (e.g. plaque_cell_probability.png). A view showing a sentence has no
    picture: save says "There is no picture to save yet."
