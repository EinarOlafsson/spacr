WHAT LANDED
* One serialisable chain: spacr/qt/detect_chain.py:811 SETTINGS_FIELDS and
  :829 chain_settings() write a Chain's image steps as nineteen enhance_*
  settings; spacr/psf_pipeline.py:261 prepare_chain() reads them back into
  an equal Chain (bool/number words from a settings file are coerced) and
  folds the psf_* PSFPlan in as the chain's PSF stage. :209 chain_problems()
  is the validator (also the Mask preflight, spacr/validate.py:1490).
* Applied per selected segmentation channel at the PSF stage, after
  illumination and before normalization: :315 apply_chain() (strict -- a
  failing step raises on a plate run instead of being skipped) through the
  existing _SegmentationPSFSession.correct, so V1 (io.concatenate_and_
  normalize) and V2 (pipeline_v2.stream_masks_from_stack) both get it; and in
  the Live preview worker (spacr/qt/widgets/live_preview.py:908).
  With the chain on, order is the chain's own: background -> PSF -> denoise
  -> contrast -> sharpen. Morphology/split and deep restoration stay Make
  Masks' own (label reshaping; model in an isolated backend).
* Off by default and bit-identical when off: prepare_chain returns None, the
  PSF-only path is untouched, and the application record gains no
  "enhancement" key, so records made before 508 still match.
* Provenance: psf/segmentation_application.json configuration.enhancement
  (_configuration, :354) lists the steps that ran and the order; the Live
  preview provenance and status line carry it too.
* Resume: validate_psf_resume (:374) and io._resume_normalized_archives /
  core.preprocess_generate_masks refuse archives made with another chain
  (or with the chain switched off) via processing_requested (:298).
* New transforms in the chain (so in Make Masks and Mask alike): percentile
  clip, logarithm (gain), square root (contrast stage, CONTRAST_ORDER :85),
  total-variation denoise "tv" (Chambolle; scikit-image has no anisotropic
  diffusion, TV is its edge-preserving equivalent). The Gaussian filter is
  denoise=gaussian (already present, named so in the tooltips).
* Make Masks: new card rows (make_masks.py:10529, :10562) and a "Use in Mask
  generation" button (:10834) that writes mask_settings() (:10819: chain +
  psf_controls.mask_settings(), psf_controls.py:228) into the Mask screen
  (and Timelapse if built) and navigates there.
