--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Cell from hoechst is the strongest cross-channel result there is -- it nearly
triples stock cpsam_v2 (0.3012 -> 0.8697) -- and it answers a question users hit
constantly: a screen imaged only with a nuclear stain and no cell mask. It is
reachable today only by someone who already knows the repo name.

--------------------------------------------------------------------------------
WHAT TO DO

   "cellpose", repo_type "model".
2. Mind the two layouts: cell-from-hoechst puts its weights under weights/ and

quotes the DELTA rather than the ratio, because stock's near-zero mAP makes any
ratio look enormous.

WHAT THE SECOND LAYOUT COST, since this file warned about it: fetch() builds a
row's URL from repo_id + name when "uri" is empty, so a nested weight needs an
explicit uri. The catalogue's own invariant test then rejected a row whose local
name was not the URL's last segment -- which is right, and is now an EXACT
match rather than the substring test it was, with "remote_name" for the one
repository (the YOLO26 detector) that publishes its weight as weights/best.pt.
