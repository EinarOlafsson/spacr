IMPLEMENTATION NOTE (2026-09-25)

Hugging Face (created 2026-09-25, public, README only, nothing else uploaded):
  https://huggingface.co/datasets/einarolafsson/community_toxoplasma_plaque_figures
  https://huggingface.co/datasets/einarolafsson/community_toxoplasma_plaques
  Two DATASET repositories, not two folders of one repo. Evidence: every
  spaCR training set on the account is its own dataset repo beside the model
  it trains (toxoplasma-plaque-well-detector-dataset, toxoplasma-plaque-
  dataset); user-models is a MODEL repo, and images with labels belong in a
  dataset repo. Each README states licence (CC BY 4.0, the licence of both
  existing plaque datasets; model_share carries none of its own), purpose
  (YOLO well detector / next plaque model), layout, and that contributions
  are reviewed.
  Layout, one folder per upload, contributions/<yyyymmdd-hhmmss-rand>/:
    contribution.json (licence, consent, spaCR version, counts)
    figures: images/<page>.png, labels/<page>.txt (YOLO "0 cx cy w h"),
             meta/<page>.json (DOI/citation/PMCID, boxes in px, provenance)
    plaques: images/<stem>.<ext> (original file, unchanged),
             masks/<stem>.tif (uint16 labels), meta/<stem>.json (provenance)

Design choices
  * Upload = a pull request on the dataset (upload_folder(create_pr=True)),
    with the contributor's own HF login (model_share.find_token, the same
    auth as model sharing). Any logged-in user may open a PR on a public
    repo, so no write token ships with spaCR, and every contribution is
    reviewed before it is merged. Without a login the dialog says how to
    log in and keeps the annotations.
  * Figure mode: a small box editor (_BoxEditor) seeded from spaCR's YOLO
    detection (the preview's boxes when already shown, else
    seed_well_boxes). Drag to add, drag box/corner to move/resize,
    right-click or Delete to remove. Untouched proposals are orange, touched
    or new ones green. Provenance per page: proposed/kept/moved/deleted/added.
  * Plaque mode: Make Masks' own brush (curation_tool.BrushPanel on a
    LayerCanvas; paint, right-drag erase, New label, [ ] size, undo),
    seeded from the plaque model (the preview's mask when shown, else
    plaque_pass). Provenance per image from seed vs final mask:
    kept/edited/removed seed ids plus added count (model_share.seed_changes).
  * Upload is disabled until every listed image has >= 1 box/plaque; an image
    can be left out of the list instead. write_contribution also refuses any
    bare image, so the rule does not depend on the button.
  * Consent (right to share + CC BY 4.0) is asked before the first upload and
    remembered in preferences (community_training_data/consent). Figure
    uploads carry the paper's DOI/citation from paper.json, editable in the
    dialog.
  * Ruler: skipped on the coordinator's instruction (the maintainer confirmed
    it is visible).

Reusable for item 528 (coordinator's request, same day): the upload
plumbing takes a target name, not a mode.
  model_share (no Qt):

      creates the public dataset + README when missing (owner token only;

    write_contribution(target, items, dest, *, consent, contribution_id="")
      -> folder; masks items: {name, source, labels, seed?, extra?}; boxes
      items: {name, image, boxes, paper?, provenance?}; refuses bare images.
    contribute(folder, target, token) -> PR URL (ensure_community_repo, then
      upload_folder(create_pr=True)).
  model_share_dialog (Qt): ConsentDialog, community_consented(),
    ask_community_consent(parent=None, *, ask=None) -> bool (asked once,
    remembered under community_training_data/consent),
    upload_with_own_login(folder, target) -> PR URL (tr()'d log-in message).
  plaque_preview.ContributeDialog(mode, paths, *, seeder, known, paper,
    upload, threaded, parent, target=None): Plaque mode with target="<name>"
    already annotates masks for any collection.

2026-09-26 -- LEFTOVER CLOSED: a whole plaque is deleted with one click

  The note above left "whole-plaque delete is by erasing with the brush".
  The mask page of "Contribute training data" now has a checkable "Delete
  object" button above the brush panel. While it is down, a left or right
  click on a plaque removes that plaque whole. Brush and Delete object take
  turns (pressing one puts the other down); Backspace/Delete undo the last
  delete exactly as they undo a stroke.
  * spacr/curation.py: MaskCuration.delete_object(label) sets every element
    of that label to 0 as ONE undoable stroke and records a "delete" entry
    in the ledger (target = the label, n_changed = its pixels). Label 0 or
    an id the mask does not hold changes and records nothing.
  * spacr/qt/widgets/plaque_preview.py: _DeleteObjectTool (a duck-typed
    CanvasTool, so the canvas module is still imported only when a mask
    page is built), _MaskPage.delete_button / delete_at / deleted_objects.
    deleted_objects() is read from the ledger and drops a delete that was
    undone. The dialog passes it as extra={"deleted_objects": [...]}, so
    each image's meta file records [{"label", "pixels", "seeded"}] beside
    the existing provenance (whose "removed" still lists every seeded
    plaque that is gone, however it went).
  Tests (tests/qt/test_523_...): a mouse click on the canvas with the tool
  armed deletes label 2 only (a background click does nothing); the ledger
  holds ("delete", 2, 100); Backspace brings it back and empties the
  record; delete again; Brush puts the tool down; the uploaded meta carries
  deleted_objects and objects == 1. MaskCuration.delete_object refuses 0
  and absent ids and undoes to the exact original.
  test_523: 12 passed. With curation, curation_tool, every plaque Qt file,
  528 and the comment/help-index guards: 453 passed.
  New tr() strings: "Delete object", "Click an object to remove it whole.
  Backspace undoes the last delete. Press Brush to paint again."
  API: one new public callable, MaskCuration.delete_object. The pins were
  already off on nightly f046bcc36 (9,779 callables vs pinned 9,735); this
  makes it 9,780.



2026-09-26 -- THE UPLOAD SPACE TAKES CONTRIBUTIONS: NO HUGGING FACE LOGIN NEEDED

  Approved by the maintainer 2026-09-25 ("Extend the Space"). The note
  above left: "The central upload Space only takes models, so a contributor
  needs a free HF login to open the PR."
  * tools/model_upload_space/contribution.py (new, Space-side, plain
    Python with the HfApi passed in): receive(archive, target, api) takes
    ONE contribution folder as a tar, exactly as write_contribution lays it
    out, and opens a PULL REQUEST on the target dataset with the Space's
    token (create_pr=True; never a commit to main).
      - Targets: figures, plaques (by kind or full id) and
        einarolafsson/community_<name> (with or without the owner). Every
        other target is "unknown" and refused before the archive is read
        (user-models, another owner's repo, odd characters, "..").
      - Limits: archive and unpacked total 2 GB, 500 MB per file, 4,000
        files; only regular files (links/devices refused), no absolute or
        ".." paths, one top folder with a safe name.
      - Allow-list: contribution.json at the top; images/ .png .jpg .jpeg
        .tif .tiff .bmp; masks/ .tif (masks layout) or labels/ .txt (boxes
        layout, every line a YOLO "0 cx cy w h"); meta/ .json. Anything
        else is refused and named. Image and mask files must start with
        their format's magic bytes.
      - Pairs: every image has exactly one mask (or label file) and one
        meta file of the same stem, and no mask/meta without an image;
        the missing or stray names are listed.
      - contribution.json: valid JSON, layout matches the target, licence
        CC BY 4.0, consent recorded, image count matches.
      - A community_<name> dataset that does not exist yet is created with
        the same README spaCR writes (CREATE_NEW_DATASETS=0 as a Space
        secret turns that off); Plaque Assay's two must already exist.
      - The PR description records the archive's sha256, the image count,
        the spaCR version and a hash of the sender's address.
  * tools/model_upload_space/app.py: gr.Blocks with two tabs and explicit
    api_name "upload" (unchanged arguments, so the Model Zoo's Add keeps
    working) and "contribute" (file, target), rate limit 10 contributions
    per IP per hour. Token: CONTRIBUTION_TOKEN secret if set, else HF_TOKEN.
    README says what each endpoint does.
  * spacr/qt/widgets/model_share.py: central_contribute(folder, target)
    tars the folder, checks the 2 GB cap before sending, uploads it and
    calls "contribute" (the Gradio HTTP calls are now _gradio_upload /
    _gradio_call, shared with central_upload, which behaves as before).
    contribute(folder, target, token=None) prefers the contributor's own
    login (token given or find_token()); with none it uses the Space; with a
    login that cannot create a new community_<name> dataset it also uses
    the Space (528's leftover).
  * spacr/qt/widgets/model_share_dialog.py: upload_with_own_login uses the
    login when there is one, the Space otherwise; when the Space cannot take
    it the error says why and how to send it with a login instead.
