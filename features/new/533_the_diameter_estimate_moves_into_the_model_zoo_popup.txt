THE DIAMETER ESTIMATE MOVES INTO THE MODEL ZOO POPUP

Status: DONE, 2026-09-26. Filed 2026-09-26.
Owner: Claude. Related: 516 (the diameter estimate itself), 503/504/525
(the model zoo picker in Mask generation).

REQUEST (the maintainer, 2026-09-26, verbatim)
    "in mask generation the, diamiter calculation should be a button in the
    model zoo button popup window not on the main screen. pressing the button
    should bring another pupup with all the information in the current
    container."

WHAT TO BUILD
  * Remove the diameter-estimate panel (DiameterPanel) from Mask generation's
    main screen.
  * Add a "Measure diameters…" button inside the Model zoo popup opened from
    Mask generation.
  * Pressing it opens its own popup (spaCR dialog dress) holding everything
    the current panel shows: the per-object estimates, notes and the actions
    that apply them to the settings.

DONE WHEN
The main screen no longer shows the diameter panel; the Model zoo popup has
the button; the new popup shows the same information and still applies the
estimates to the settings (offscreen tests for each).

DONE, 2026-09-26
The Mask generation screen no longer carries the diameter panel.
`spacr.qt.prerun.install` now installs only Measure's QC banner, and
`prerun.register` wraps only the Measure factory, so the Mask screen is built
by chaining's factory exactly as before, minus the panel.
`install_diameter_panel` and `diameter_panel` are gone.

The Model zoo popup (`ModelZooPicker`) walks up from the widget that opened
it (`prerun.diameter_screen_of`). When that is the Mask generation screen,
or anything inside it such as the per-object model cell or a
`*_model_name` field's button, a "Measure diameters…" button sits at the
bottom left, beside the dialog's own buttons. Opened from anywhere else,
there is no button.

Pressing it opens `prerun.DiameterDialog`. This is a QDialog, so
spacr.qt.widgets.glass gives it the card, the rounded corners and the rim,
and it holds the whole `DiameterPanel`: the measure button, one row per
object type with the value, the 10th-90th percentile range, object and field
counts, confidence and method, the note, "Use N" per row and "Use all". A
red Close sits at the bottom right. The panel still writes through the
opening screen's settings model, so "Use" lands in that screen's
`<object>_diameter`. The popup opens window-modal on the zoo and is reused,
not rebuilt, and it closes when the zoo does. The last measurement is kept on
the screen (`_diameter_estimates`), so the next popup, even from a later zoo
window, shows it again without measuring twice.

install tests became popup tests, plus new ones for the screen lookup and
