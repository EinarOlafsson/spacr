WEB MASK GENERATOR: DROP AN IMAGE, GET MASKS, FLOWS, PROBABILITY AND A CSV,
ONE PAGE PER MODEL CLASS, IN THE SPACR SITE STYLE
================================================================================

Status:    new 2026-10-13
Requested: maintainer, 2026-10-13: "i would like a new web page in the same
           style as the spacr web page where the user can drop in or upload a
           picture or a pdf or whatever other supported filetype and the
           webpage will generate masks for the user. this means the page will
           need to have access to some type of gpu acceleration. the user
           should then be able to download a zip of the picture, the mask,
           flows, cell probability and a csv with data for the object. one
           page per model class (pv, plaque, plaque well, cell from hoechst,
           toxo from hoechst, etc.), like the tabs on the spacr homepage. and
           the site should link to hugging face so the user should be able to
           import a random image from an appropriate test data source on
           hugging face."

--------------------------------------------------------------------------------
DESIGN QUESTIONS TO SETTLE FIRST (ask the maintainer with the question tool)
--------------------------------------------------------------------------------

- GPU: (a) a Hugging Face Space with ZeroGPU running spaCR's real Cellpose-
  SAM pipeline behind a small API, the static site calling it; (b) in-browser
  WebGPU/ONNX (no server, but Cellpose-SAM at ~300 M parameters is heavy and
  YOLO/plaque-well detection would need separate exports); (c) both, browser
  first with Space fallback. Cost, quotas, privacy (uploaded images leave the
  user's machine in (a)) and the file-size limit follow from the choice.
- Hosting: a new page on the existing site (site-src) or a separate site in
  the same style.

Decided 2026-10-13 (maintainer): BOTH GPU paths are options the user can
pick on the page: "Hugging Face Space (ZeroGPU)" running spaCR's real
pipeline, and "In my browser (WebGPU)" running exported models locally (no
upload). The pages live ON the spaCR site (site-src), as a new section
beside the Models tab.

--------------------------------------------------------------------------------
WHAT TO BUILD
--------------------------------------------------------------------------------

1. Pages: one tab/page per model class, matching the spaCR homepage tabs:
   parasite vacuoles, plaques, plaque wells, cells from Hoechst, nuclei from
   cell mask, vacuoles from cell mask, vacuoles from Hoechst, live cells, and
   any later default model. Each page shows the model's score card and its
   recommended input (channels, magnification, file types).
2. Input: drag-and-drop or upload of every format spaCR reads that makes
   sense on the web (TIFF incl. multi-channel/OME-TIFF, PNG, JPEG, CZI/ND2
   where the reader is available, and PDF by rasterising its pages), with a
   channel picker when the image has several channels.
3. "Random test image": loads a random image from the matching Hugging Face
   test dataset for that model class, credited and linked.
4. Run: the real spaCR model and settings for that class (same weights, same
   defaults, diameter from magnification per item 696), with progress, and
   an overlay preview of the masks on the image.
5. Download: one ZIP with the input image, the mask (label TIFF), the flows,
   the cell probability, a CSV of per-object measurements (spacr.tabular
   columns: label, area, centroid, intensity per channel, etc.) and a short
   README naming the model version, settings and spaCR version.
6. Style: the spaCR site's look (Open Sans, the field backdrop, the dark
   GitHub-neutral cards with teal accents, symmetric layout), every string
   translatable like the rest of the site, accessible (keyboard, screen
   reader labels).
7. Limits and privacy statement on the page: maximum file size, how long
   uploads are kept (ideally not at all), and that results are for research.

--------------------------------------------------------------------------------
ACCEPTANCE
--------------------------------------------------------------------------------

- For each model class: a test image from Hugging Face produces masks that
  match the desktop spaCR result on the same image (same label count, mask
  IoU >= 0.99), and the ZIP contains all six items.
- Works on a phone and a desktop browser; a 10 MB TIFF completes on the
  chosen GPU path within a stated time.
- Links from the main spaCR site and the README Models section.
