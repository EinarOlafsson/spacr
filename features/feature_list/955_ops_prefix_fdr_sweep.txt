WHAT
spacr.ops_prefix.fdr_sweep(reads, cells, library, settings, selection_sites=None)
and the ops phase prefix_fdr_sweep (run_ops(settings, phases=['prefix_fdr_sweep'])).
Each method's reads (site, cell, read, optional quality) are matched by one
matcher against the whitelist + decoys (prefix_decoy_library) and against the
shuffled whitelists (shuffled_library, one per shuffle seed). Grid: max read
distance x min top-barcode reads x cell rule (maxcount, purity50, purity100) x,
for methods whose reads carry a quality, no cut or the quality quantiles of that
method's reads in cells. Per FDR target (and the lowest FDR every method
reaches, rounded up to 1e-4 %) each method's configuration is the one with the
most genotyped cells at pooled decoy FDR <= target (ties: lower FDR, then the
stricter configuration). Every chosen row reports genotyped %, decoy FDR, decoy
counts, site-bootstrap CIs and the barcode-shuffle call rate (mean over seeds,
spacr.ops_decode.shuffle_call_rate, with its interval and per seed); methods get
the paired difference in genotyped % at the same target with a bootstrap CI.
With selection_sites the configurations are chosen on those sites and reported
on the rest (held-out comparison).
Bootstrap draw order: one generator (ops_fdr_sweep_seed), blocks of
ops_fdr_sweep_bootstrap resamples; block 0 serves every share/FDR interval and
the first compared target's differences, each later compared target takes the
next block (this reproduces both former scripts).

SETTINGS (all alpha, ALPHA_FEATURES[955])
ops_fdr_sweep_targets (0.5, 1, 2, 5), ops_fdr_sweep_max_distance (0, 1),
ops_fdr_sweep_min_reads (1, 2, 3), ops_fdr_sweep_rules (maxcount, purity50,
purity100), ops_fdr_sweep_quality_quantiles (0.1..0.9), ops_fdr_sweep_bootstrap
(2000), ops_fdr_sweep_seed (0), ops_fdr_sweep_shuffle_seeds (0, 1, 2),
ops_fdr_sweep_inputs (the phase's inputs: methods -> read files, cells table,
sites, selection_sites; empty = this run's spaCR reads over cells with reads).
Uses ops_prefix_decoy_k (must be >= 1), ops_prefix_decoy_seed, ops_prefix_metric.

OUTPUTS (<dst_root>/results/ops_prefix/)
fdr_sweep_result.json, fdr_sweep_table.csv (one row per target and method),
fdr_sweep_pooled.csv (every configuration on the selection sites),
fdr_sweep_grid.csv (every configuration per site).
