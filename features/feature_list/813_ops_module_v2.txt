WHAT TO BUILD
--------------------------------------------------------------------------------

The OPS submodule of the mask module produces:

1. orig/
   The original files move into orig/ with their folder structure
   unchanged, as in other spaCR modules.

2. Every cell, once, efficiently
   - Core-ownership stitching: each field owns its core.
   - Linked cells are owned where the SBS centroid is deepest (A1b).
   - Margin copies are tagged and excluded.
   - Stitched-patch rescue covers cells cut in every field.
   - Well-boundary cells are flagged.
   - Evidence: /nas_mnt/data/sync/papers/BMCspacr/reanalysis/ops_overlap/REPORT.md
     (+1.9% unique whole cells, 99.7% whole, no extra GPU). Settings spec in
     section 9 of that report.
   - Full-mosaic segmentation stays optional and alpha.

3. Guide detection
   - False discovery rate (FDR) at most 2x Brieflow's, estimated with decoys,
     calibrated, on the upper 95% CI; preferably below Brieflow.
   - Detection at least 70%, preferably at least 75%.
   - Each decode strategy is its own Boolean setting, with defaults chosen
     from the strategy study.

4. merged/
   - merged/phenotype/<plate>/<well>/<field>.npz: compressed; phenotype
     channels first, then masks, for the field's expanded view (the core
     extended just enough to contain every object it owns). Overlap pixels
     may repeat across files; each object belongs to exactly one field, and
     only owned objects are analysed.
   - merged/sbs/<plate>/<well>/<field>.npz: optional, setting
     ops_merged_save_sbs (default on). All SBS cycles x channels at native
     SBS resolution, cropped to the field, plus the SBS-to-phenotype affine
     transform. A helper upsamples onto the phenotype grid on demand; nothing
     upsampled is stored.
   - One file per field, about 1,281 per well folder.
   - Measure and every module that reads merged/ support this layout: they
     load phenotype by default and join SBS on request.
   - A layout manifest/version file lets readers detect the layout.

5. measurements/
   - measurements.db (SQLite) holds the cell index, genotype, metadata and
     png_list, so the standard spaCR tools work. Items 810 and 811 cover the
     SQLite parts.
   - The wide feature tables (cell, nucleus, cytoplasm) are per-well Parquet,
     read through DuckDB by a spaCR reader that exposes them as the usual
     tables.
   - Sized for about 100 M rows; earlier spaCR databases held 1-2 M.

6. data/ crops (optional, as in generate masks)
   - spaCR categories, then plate/well, then field.
   - No folder holds more than ops_max_files_per_folder (default 10,000)
     files.
   - Raw crops, no per-crop stretch (item 772); sharded store per item 809.

SPOTIFLOW SPOT DETECTOR (maintainer, 2026-11-06)
--------------------------------------------------------------------------------

- Setting ops_spot_detector, with three choices:
  - log: the current default, LoG filter plus local maxima;
  - spotiflow;
  - union: both detectors' calls merged, deduplicated within 1-2 px.
- Companion settings:
  - ops_spotiflow_model: a pretrained model name, or a path to a fine-tuned
    model;
  - ops_spotiflow_threshold: a probability; the default comes from the model.
  - GPU use follows the module's GPU setting.
- Spotiflow is an optional dependency, imported lazily. When it is missing,
  a clear message says how to install it, and nothing else breaks.
- The default stays log until the decode-strategy study (N7, detector union)
  shows whether Spotiflow improves detection at FDR at most 2x Brieflow's.
  The study result decides the default.
- Tests: the setting is declared; the missing-dependency message; union
  deduplication on synthetic spots; a stub detector path.

PHENOTYPE ILLUMINATION (FLAT-FIELD) CORRECTION (maintainer, 2026-11-06)
--------------------------------------------------------------------------------

Evidence: /nas_mnt/data/sync/papers/BMCspacr/reanalysis/funk_phenotype/seg_qc/REPORT.md
- Without correction (spaCR currently only max-projects), the corner-to-
  centre intensity ratio is 0.42-0.53 across DAPI, GFP, A594 and AF750.
  GFP also has a left-right gradient of 0.78.
- Nuclei detection is unaffected (0.08% missed), but intensity features are
  biased about 2x in the corners.

Settings:
- ops_ph_illumination_correction (bool), default True on the OPS phenotype
  path.
- ops_ph_flatfield_fields (int, default 200): fields per plate used for the
  estimate.
- ops_ph_flatfield_smoothing (sigma; heavier for nuclear channels).
- ops_ph_flatfield_apply_to: measure, or segment+measure (default).

How:
- Estimate per plate x channel: a robust per-pixel median over fields,
  smoothed and normalised to mean 1.
- Save to <src>/illumination/<plate>_<channel>.npy and reuse it.
- Apply after max-projection, before segmentation and measurement, as
  ops_ph_flatfield_apply_to says.
- QC output: corner/centre ratios before and after.

Tests: synthetic vignetted fields are corrected; the estimate is
reproducible; the settings are declared.
