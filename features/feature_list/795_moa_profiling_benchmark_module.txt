--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

spaCR has profiling with mAP (item 547) but no leave-one-compound-out
mechanism-of-action evaluation. The reanalysis scored it outside spaCR with
/nas_mnt/data/sync/papers/BMCspacr/reanalysis/bbbc021/cellprofiler_baseline/run_and_score.py, ljosa_methods.py and
supervised_moa.py. Item 753 is the CellProfiler head-to-head; this item is
the reusable scorer it and any profiling run would call.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Without it a profiling result cannot be compared with the published
BBBC021/Ljosa numbers inside spaCR.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Leave-one-compound-out 1-NN MoA accuracy under NSC (not same compound)
   and NSCB (not same compound or batch), on per-treatment profiles from
   spacr.sp_stats.
2. Supervised arms (logistic regression, XGBoost on CPU, see 794) under the
   same splits.
3. Shuffled-label controls, a table via spacr.tabular with a control row and
   a glossary; register in ALPHA_FEATURES under 795.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

On the BBBC021 CellProfiler table it reproduces run_and_score.py's NSC
and NSCB accuracies exactly, and the shuffled control is at chance.

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- No per-plate percentile (Ljosa 1st-99th DMSO) scaling inside spaCR: the
  acceptance built the normalised wells with run_and_score.py's normalise();
  spaCR's own normalisers are aggregate_profiles (zscore, robust_zscore, tvn)
  and the sp_stats profiling run.
- No GUI screen and no figure; the module is settings + command line + API.
