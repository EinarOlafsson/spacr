BUILD
- write_ome_zarr(..., ngff_version="0.5", shards=...): zarr v3, sharding,
  zstd 3, "ome" attributes; 0.4 kept; the pure-Python reader refuses sharded
  arrays and zarr reads them.
- spacr.image_store: PlateWriter (HCS plate -> row -> column -> field, masks
  as labels, named channels, commit ledger spacr_commits.jsonl, temporary name
  then rename), run_fields (workers compute, the parent writes, plan order
  through a reorder window, spawn and forkserver safe, resume skips committed
  fields), read_image / read_labels for npy, npz, tif, png and zarr.
- mask_image_format ('npy' default, 'tiff', 'ome-zarr'): Mask Generation also
  writes images/<plate>.ome.zarr or merged_tiff/; merged/*.npy stays.
- spacr.crop_store: cut_crops (bounding box + crop_margin_px, own mask,
  crop_zero_outside), CropPoolWriter (crops/plate=<P>/well=<W>.zarr, one pool
  per class, crops_per_shard per shard written whole), ssCell_Crops table with
  relationship columns, read_crop (context, deterministic resize),
  export_crops (tiff, npy), legacy_png_view (the PNG (Legacy) window, rebuilt),
  pool attributes, commit / read_commit / discard_uncommitted (whole-well
  commit and resume, for 985), spacr.crops.measured_masks_state.
- crop_image_format ('png' default, 'ome-zarr'), crops_per_shard (4096,
  halved under low RAM), crop_margin_px (0), crop_zero_outside (off). Measure
  workers send each field's crops in its write packet; the parent's CropSink
  commits fields in plan order.
- OmeZarrCropSource: the PngCropSource interface (get, get_image, get_many,
  resolve, describe) plus get_raw; ome_zarr_crops_exist.
- Annotate: channel roles for OME-Zarr crops, any number of channels, image
  roles (colour, range, gamma, additive) and outline roles (mask, label
  channel, threshold; width); per-project presets in
  settings/annotate_channel_presets.json; dialog row AnnotateChannelRoles.

PROOF IN TESTS
- Mask Generation fields and masks read back pixel-exact from OME-Zarr and
  TIFF; 'npy' writes nothing new.
- Measure crops: OME-Zarr boxes equal the source cut; 1 and 2 workers give
  identical stores; every PNG (Legacy) crop is rebuilt pixel-exact from the
  store (per-class digests); class counts equal png_list; a shuffled class
  index does not match (20 permutations); reruns are byte-identical.
