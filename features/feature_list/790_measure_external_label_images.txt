--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

Measure reads only spaCR's own merged/*.npy stacks. To measure CellProfiler
label TIFFs on BBBC021 the driver built HxWx5 arrays by hand, wrote
.spacr_plane_layout.json itself and copied spaCR's internal file naming
(<plate with _ escaped as %5F>_<well>_<site>_<time>.npy). Scripts:
/nas_mnt/data/sync/papers/BMCspacr/reanalysis/bbbc021/swap/swap_halfA.py and make_analysis_from_masks.py.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Swap tests (spaCR features on another tool's masks, and the reverse) are
the fairest way to separate segmentation from measurement in a benchmark,
and labs often already have masks from another tool.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. An "import label images" path in Measure: per-object label TIFF/PNG/NPY
   folders (cell, nucleus, pathogen) matched to the raw channels by a
   filename pattern (regex_infer), with label dtype and size checks.
2. Write the merged stacks and the plane layout through spaCR's own writer,
   never by hand, and record the mask source in the run provenance.
3. Settings with types, tooltips and categories; tr() for every string.
4. Register everything in ALPHA_FEATURES under 790.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

The BBBC021 swap half A runs from the Measure settings alone, with no
driver-built arrays, and gives the same per-cell features as the driver
(identical parquet up to row order).

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- One image file per channel per field: a multi-channel TIFF, or a pattern
  without chanID, is refused rather than split.
- Organelle label slots are not importable here; the external-mask importer
  (spacr.external_masks.prepare_external_masks) still covers them.
- Cellpose *_seg.npy bundles are refused by the converter; export the masks
  (TIFF/PNG or a plain label .npy) first.
- One plate folder per run: src must name a single plate.
- The full 55-plate BBBC021 half A rerun is left to the paper lane; the check
  above uses 4 fields. The per-cell parquet export stays the driver's (item
  769 is the spaCR export).
- No public API function: the import is reached through the Measure
  settings; the helpers are private.
- Runtime messages are English and not wrapped in tr(), like the rest of
  spacr.external_masks; the settings labels and tooltips are translated
  through the catalogs.
