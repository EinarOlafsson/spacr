GENE-CLASS (MULTI-LABEL) TRAINING WITH GROUPED SPLITS, DECOY HEADS AND SHUFFLED CONTROLS
========================================================================================

Lifecycle: future
Status: PARTIAL 2026-11-09 (alpha, under ALPHA_FEATURES[889]) — spacr.gene_classes builds the gene classes from versioned annotation files (KinHub, CORUM, KEGG with the BRITE filter, GO-slim, Funk feature directions; md5 in sources.json), merges or drops near-duplicates, splits genes into folds by multi-label iterative stratification (grouped_multilabel_folds, every gene in one fold), gates a table on phenotype-positive members, trains the per-class logistic-regression baseline on a gene feature table with decoy heads and a shuffled-class control, and writes the evaluation report (per_class.csv, summary.json, discovery.csv / discovery_a.csv / discovery_b.csv against the gene-wise decoy null). run_gene_classes runs it from settings (module 'gene_classes'). The shipped spaCR CNN (CustomCellClassifier) is pinned to the benchmark's fixed arm.
