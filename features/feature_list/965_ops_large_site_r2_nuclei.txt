PROBLEM
On the large-site path (spacr.ops_large_sites.segment_cell_painting_site,
preset cell_painting_phalloidin) nuclei were paired one to one with the cell
model's cells. A cell outline holding two nuclei kept one of them and a
nucleus without a cell was dropped: 11-13 % of PERISCOPE's nuclei, 84 % of
them a second, real nucleus in a cell the cell model merged. Seeding the
cells from the nuclei (R1) removes the loss but gives small fragments their
own cells; R2 merges those fragments first.

BUILD
- New setting seg_merge_small_nuclei_frac (float >= 0; 0 = off), in
  LARGE_SITE_DEFAULTS at 0.25, with a tooltip in LARGE_SITE_TOOLTIPS.
- spacr.ops_large_sites.merge_small_nuclei(nuclei, frac=0.25) -> (labels,
  info): threshold = frac x the site's median nucleus area (before merging);
  a nucleus below it that shares a 4-connected border with another nucleus
  is merged into the neighbour with the longest shared border (ties: larger
  neighbour, then lower label); chains of small pieces are followed to a
  kept nucleus, a 2-cycle of small pieces ends on the larger one; a small
  piece touching nothing is kept (never deletes); labels renumbered 1..n in
  the order of their old labels. info: threshold_px, median_area_px,
  n_small, n_merged.
- segment_cell_painting_site runs it after the nucleus mask step and before
  the seeding (or the pairing with the cell model's cells when seeding is
  off); its counts gain merged_small_nuclei and median_nucleus_area_px when
  the merge runs.
- seg_cells_from_nucleus_seeds default True (was False) in
  LARGE_SITE_DEFAULTS; only the large-site path reads it.
- run_large_site_segmentation: sites.csv gains merged_small_nuclei and
  median_nucleus_area_px (only when the merge runs, so an off run writes the
  table it wrote before); the run logs and returns merge_line
  "R2: merged n small nuclear pieces (x % of nuclei)".
- SETTINGS_SCHEMA_VERSION 943; DEFAULT_CHANGES[943] =
  {'seg_cells_from_nucleus_seeds': False, 'seg_merge_small_nuclei_frac': 0.0}.
- Funk's phenotype path (spacr.ops_engine._ph_segment_field) reads neither
  setting and is unchanged (maintainer decision).
