--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

measure_crop reads settings['timelapse'] (spacr/measure.py, measure_crop)
before get_measure_crop_settings fills the defaults, so a Python caller gets
a KeyError unless it fills them first. After that pre-fill the default mask
dims count as explicit and conflict with merged/.spacr_plane_layout.json
(PlaneLayoutConflict; item 614 fixed the GUI path), so the caller must
restate the manifest's dims.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

The documented API call fails on the first try, and the work-around turns
defaults into explicit choices.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Fill defaults before any read in measure_crop.
2. Treat values equal to the defaults from get_measure_crop_settings as not
   explicit when reconciling with the plane layout.
3. A test calling measure_crop({'src': ...}) on a merged folder with a
   non-default layout.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

measure_crop({'src': folder}) runs on the BBBC021 merged folder with no
pre-fill and no restated mask dims.
