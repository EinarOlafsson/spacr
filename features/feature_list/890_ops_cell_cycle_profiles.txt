RESULT
From the flat-field corrected nucleus_dapi_integrated_intensity and the
mitotic call of analysis_plateA/cells/raw_<well>.parquet, cell_cycle_phases
gives the phase and dna_log2_rel of improved/cells/tvn_<well>.parquet bit
for bit in all six wells (5,532,572 cells). From those cell tables,
phase_profiles gives profiles/guides_phase.parquet (20,437 guides x 311
columns) and genes_phase.parquet (5,111 genes) bit for bit, NaN pattern
included.

DIFFERENCE FROM THE REFERENCE RUN
The reference fits TVN on interphase cells and applies it to all cells.
The aggregate phase fits TVN on the cells it pools, so a spaCR run gives
the same phase tables only from the same per-cell TVN components; with
ops_pool_interphase the M block is empty.
