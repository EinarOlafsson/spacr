- timelapse_division_prediction_min_positive_rows defaults to 0 (the spec
  says 20): a default guard would stop fits that run today, against the
  spec's own no-regression rule. The reference preset sets 20.
- Arm labels for the default arms are unchanged ("model", not "full"), so
  default outputs stay identical.
