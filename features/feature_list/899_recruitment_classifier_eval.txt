(border-touching = artefact, else rim_enrichment >= the null p99 threshold
3.345 = recruitment, else no recruitment; 80 / 375 / 45). A settings-file
run (gbp_plate77_ml_eval_settings.csv in the scratch folder) of
generate_ml_scores against the reference script on the same copy of the
annotation database: the leave-one-well-out model, the majority control and
the shuffled-label control (mean of 20, seeds 0-19) give the same accuracy
and per-class precision, recall and n as the reference script, to 1.1e-16
(floating-point summation order): accuracy 0.874 / 0.750 / 0.647. spaCR adds
balanced accuracy 0.641, macro F1 0.637 and AUROC 0.818 for the model
(controls 0.333 / 0.286 / 0.500 and 0.327 / 0.321 / 0.492). The model and
majority rows are pinned in tests/data/recruitment_eval_899.

CNN ROUTE (2026-11-12)
- Classify's train module gets train_eval_split (none, leave_one_well_out,
  leave_one_plate_out, random), train_eval_controls (majority, shuffled),
  train_eval_shuffle_seed (0) and train_eval_shuffle_repeats (1), under
  ALPHA_FEATURES[899]. The name is train_eval_split, not train_split:
  train_split is already the gene-class trainer's fold setting.
- A split turns cross-validation on with one fold per well or plate
  (cv_group_column) or the stratified cross_validation_folds folds; the
  out-of-fold predictions give <model folder>/ml_eval/metrics.csv with the
  columns of evaluate_classifier (pooled and per fold), a majority-class
  control, and a shuffled-label control that reruns the whole
  cross-validation with each fold's training labels permuted (seeds
  train_eval_shuffle_seed, +1, ...; each repeat in shuffled_seed_<seed>/),
  averaged.
- Tests use a fixed model in place of the network (folds, permutation and
  table); no CNN was trained on real crops.
