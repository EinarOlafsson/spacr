Lifecycle: future
Status: DONE 2026-11-09 (alpha) — spacr.published_reference reads a published per-guide or per-gene table (CSV/TSV/Excel/Parquet via spacr.tabular; a wide sgRNA_<k> table such as vesuvius_genes.xlsx becomes one row per guide with cells = interphase + mitotic), matches guides on an 11-base prefix (upper case, U as T) and genes by symbol, case and listed aliases, handles shared reference guides (published_duplicates collapse/keep/drop) and unmatched keys (published_unmatched drop/zero), and reports Spearman and Pearson with bootstrap 95% intervals and a shuffled-gene-label control row, with a glossary. joined.csv, agreement.csv, glossary.csv, summary.json and one scatter per pair (save_figure, _register_figure_data) go to published_dst. --------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

On 2026-10-31 spaCR's per-guide cell counts for Funk plate A were correlated
by hand with the published per-gene table vesuvius_genes.xlsx: Spearman 0.916
per guide. Output:
/nas_mnt/data/sync/papers/BMCspacr/reanalysis/funk_plateA/per_guide_counts_spacr_plateA_vs_funk.csv.
spaCR has no function that does this.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

A reanalysis is only credible when it is compared with the published result,
with a control that shows what agreement chance alone gives.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Read a published per-guide or per-gene table (CSV/XLSX) and map its guide
   or gene key to spaCR's (11-base prefix, gene symbol).
2. Correlate cell counts and any matched phenotype column (Spearman and
   Pearson, bootstrap CI), with a shuffled-label control row and a glossary.
3. Write the joined table and a scatter figure via spacr.plot.save_figure.
4. Register in ALPHA_FEATURES under 751.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

Re-running on plate A reproduces Spearman 0.916 per guide; the shuffled
control row is near 0.
