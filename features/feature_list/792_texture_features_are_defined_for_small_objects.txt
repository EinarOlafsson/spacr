TEXTURE FEATURES ARE DEFINED FOR SMALL OBJECTS

Lifecycle: future
Status: DONE 2026-11-07 — spacr.measure._calculate_homogeneity and the vectorised _torch_homogeneity read each homogeneity_distance_<d> at offset min(d, bounding-box width - 1) (spacr.measure._homogeneity_offset), so an object narrower than d gets a finite value at its widest horizontal offset instead of NaN; a one-pixel-wide object reads 1. Objects wide enough for d are bit-identical to before. The rule is in the feature dictionary entry. No setting, so nothing in ALPHA_FEATURES (exempted in tests/qt/test_alpha_features_gate.py). Tests tests/test_texture_small_objects_792.py. The BBBC021 rerun that checks no well mean is non-finite needs the maintainer's data.

--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

nucleus_channel_*_homogeneity_distance_32 is NaN for nuclei smaller than
the offset, which left 6 BBBC021 wells with non-finite mean profiles.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Non-finite features break well means and every distance computed on
them; dropping the rows biases against small nuclei (mitotic, apoptotic).

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Cap each GLCM distance by the object's size (or skip offsets that do
   not fit and record how many were used), so the feature is always finite.
2. Document the rule in the feature dictionary (spacr/feature_dict.py).
3. Register any new setting in ALPHA_FEATURES under 792.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

On BBBC021 no well mean is non-finite, and the homogeneity values of
nuclei large enough for every offset are unchanged.

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- No column recording the capped offset: it follows from the object's
  bounding-box width, which is already written, and a new column would join
  every feature set.
- Small objects' values change from NaN to a number read at a shorter offset;
  they are not comparable to a large object's value at the full offset.
