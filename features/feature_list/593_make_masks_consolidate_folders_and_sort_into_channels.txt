--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

Built. Non-GUI logic in two modules, Qt thin on top:

* spacr/folder_consolidation.py -- the port of rename_by_folders.py.
  consolidate_folder(source, output=None, extensions=None, skip_dirs=(),
  log=None) copies (never moves) every file into <parent>/<name>_renamed
  (unused name), each named after its folder path joined by "_", collisions
  numbered _2, _3, long names shortened with a hash, Windows-safe names,
  symlinks skipped and recorded, rename_manifest.csv. The Tk picker is gone;
  the CLI stays: python -m spacr.folder_consolidation SOURCE [OUTPUT].
  Added for Make Masks: extensions= (images only) and skip_dirs= (masks,
  orig, sorted_channels -- matched with or without a _2 suffix), and
  nested_file_count() for the question.
* spacr/channel_sorting.py -- parse_names/check_sets (channel from the
  selection or chanID; set = the other named groups), infer_regex (Auto
  regex), detect_sets (Detect sets: Hungarian pairing on filename token
  distance + a small order term, pairs of different image size forbidden,
  mask-vs-image size reported), name_sets/yokogawa_name (Yokogawa naming via
  spacr.convert.target_name), build_plan (nothing moves), apply_plan (moves
  + channel_sorting_manifest.csv) and merge_sorted (stack/, masks/<role>_
  mask_stack/, merged/ through spaCR's own _get_regex('cellvoyager'),
  _extract_filename_metadata, _escaped_field_stem and
  _load_and_concatenate_arrays -- no new npy layout).
* spacr/qt/widgets/channel_sort_dialog.py -- ChannelSortDialog (thumbnail
  list off-thread, ExtendedSelection, Select all, "Channel N" buttons, Add
  channel, Clear channel, per-channel mask-role combo, Apply), RegexWindow
  (guidance with three examples, live test table, summary of unmatched /
  incomplete / duplicated sets, Auto regex, Detect sets) and
  ExampleSetsDialog (three sets, all channels, masks tinted red, Yes/No).
* spacr/qt/screens/make_masks.py -- "Consolidate folders…" and "Sort into
  channels…" buttons; open_paths (single folder) and the folder picker call
  _offer_consolidation, which asks with _confirm and runs the copy in a
  _FolderJobWorker (lines go to the Make Masks console) and then opens the
  new folder. The sort's plan is applied in the same worker type and C01/
  opens afterwards.

Output of a sort, beside the images: <folder>/sorted_channels/ holding
C01/, C02/ ... (Yokogawa-named images, their masks in C0N/masks/ under the
new stem, .curation.json ledgers moved with them), stack/, masks/<role>_
mask_stack/, merged/ (+ .spacr_plane_layout.json) and
channel_sorting_manifest.csv.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Masks drawn in Make Masks on a mixed folder could not reach Measure without
hand renaming: the pipeline needs one multi-channel field per position with
its mask planes. Nested acquisition folders could not be opened at all
(Make Masks lists folders non-recursively).

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

* A multi-folder drop is not consolidated; only a single dropped or picked
  folder is offered. A queue of several folders already works as a queue.
* Images that are not a single 2-D plane (RGB PNGs, z-stacks) are refused by
  the plan rather than projected: Make Masks masks are 2-D and silently
  max-projecting a colour image would put a wrong plane into merged/.
* Sets that are incomplete (a channel missing) block Apply instead of being
  left behind: the user fixes the regex or the selection, or uses Detect
  sets, whose unpaired images simply stay in the folder.
* Detected sets are named one well per set (plate1 A01.., F001, 384 wells to
  a plate), as asked; regex sets without a wellID group fill A01 with fields
  F001..F999.
