--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

Voyager3 (item 973) has no button of its own; it runs inside OPS.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

The knowledge map Voyager3 produces cannot be explored, and the LLM and non-LLM versions cannot be run or compared from the app.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. A Voyager3 button to the left of the AI button.
2. It opens a Voyager3 tab beside OPS where the user picks an OPS run, chooses the LLM or the non-LLM version, and runs it.
3. The tab shows the knowledge map interactively: search, zoom, click a node or edge for an information tile (as in the regression results), filter.
4. One Voyager3 implementation shared with the OPS step and the OPS live tab (item 1018).

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

From the button, both versions run on the example OPS run and the map can be browsed and clicked; screenshots of the real window; tests cover the button, both runs and the click tile.
