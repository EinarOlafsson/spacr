LEVELS
- sbs: decoded sequencing nuclei per guide (the genotype table or ops_barcodes),
  every reference guide kept, absent guides 0 (validate_plate.py's join).
- phenotype: n_cells of the aggregate's guide and gene tables, inner-joined
  with the reference (qc_profiles.py's join).
One generator per level, guides first then genes, as both pilot scripts drew.

DIFFERENCES FROM THE PILOT FUNNEL
dropped_failed_fields counts the cells of the fields item 860's check drops
(ops_drop_failed_fields); the pilot dropped every field whose refinement failed
(refined == 0). decoy_assigned is linked cells whose call is no guide of the
design.
