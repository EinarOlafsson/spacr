--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

There is no per-cell export joining cell, nucleus and cytoplasm. The
driver joined cytoplasm 1:1, took each cell's largest nucleus and added
Metadata_n_nuclei (3-8% of cells have more than one nucleus, 4-8% none).
Item 377 names the same denominator cases for infection.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Every profiling tool expects one row per cell; each user rebuilding the
join makes different choices.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. An export with one row per cell: cell, cytoplasm and a chosen nucleus
   (largest, or aggregated), Metadata_n_nuclei, NaN nucleus features for
   cells without one; Parquet and CSV through spacr.tabular.
2. Feature QC (item 791) runs on the exported table.
3. Register any new setting in ALPHA_FEATURES under 769.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

The BBBC021 driver's parquet export is reproduced by spaCR alone, row for
row.

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- No button on a screen: the export runs from Measure (per_cell_export) and
  from the Python API.
- Pathogen and organelle tables are not joined; the item names cell,
  nucleus and cytoplasm, and a cell can hold many pathogens.
- The driver's own key columns (plate, well, site) are named
  Metadata_Plate, Metadata_Well and Metadata_Site here, as pycytominer
  expects; the BBBC021 scoring scripts read the driver's names.
