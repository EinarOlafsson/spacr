--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

spaCR writes one PNG per cell into one directory. On Funk well A1 (1.59 M
cells, all crops stored), measured on the NAS:

- writes: about 49 files/s (0.9 MB/s), the same with 24 or 48 streams, so it
  is the NAS small-file limit;
- directory listing: 151-604 s;
- renames: about 270 ms per file in a 650 k-entry directory;
- random reads for training: 2.4-5 PNG/s (0.04-0.09 MB/s), so one epoch over a
  plate takes days.
