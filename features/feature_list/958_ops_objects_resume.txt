PROBLEM
_objects in spacr/ops_engine.py composes, segments and sews a well window
by window with no checkpoint, so a stopped objects phase recomposed and
resegmented every window.

BUILD
- ops_objects_resume (bool, default True, alpha): each segmented window's
  labels, overlap gain and covered area are written to
  <ops_objects_windows_dir or dirname(measurements.db)/objects_windows>/<well>/
  w<top>_<left>.npz, then a done marker w<top>_<left>.done.json, each as a
  .part file renamed into place.
- The marker carries a sha256 key of the window (top, left, height, width),
  the canvas and tile shape, the compose blend, the Cellpose model (name,
  file size and mtime for a file, its model_metadata pin), the eval keywords
  (diameter), the cellpose and spaCR versions, and each covering tile's
  rounded position, file path, plane, size and mtime. The device is not in
  the key.
- A rerun reuses a window whose marker key matches and whose labels load
  with the window's shape; any other window is composed and segmented again
  and its files are overwritten. Empty windows are never written.
- Sewing and numbering are unchanged and run in window order, so a resumed
  well's ops_objects and every downstream table equal an uninterrupted run's.
- After the well's objects are stored the window files are deleted (and the
  well folder, and objects_windows when empty) unless
  ops_objects_keep_windows (bool, default False, alpha) is on.
- ops_objects_windows_dir (str or None, default None, alpha): where the
  per-well folders go.
- The run journal gets a stage ops_objects_windows_<well> with the folder and
  the counts of windows, empty, reused, computed, kept and deleted; the
  objects report gets windows_resumed with the same counts only when a window
  was reused, so an uninterrupted run's report keys are unchanged.
- No schema bump and no DEFAULT_CHANGES row: an uninterrupted run's outputs
  are byte-identical to before.

ACCEPTANCE
tests/test_ops_objects_resume_958.py (7 cases, synthetic five-field well):
default run equal to a run with checkpoints off and leaving no files; stop
at a seeded window and resume to md5-equal ops_objects and ops_barcodes; a
changed diameter reusing no window and equal to a fresh run; keep=True
leaving every file and a rerun reusing all; a touched tile file sending back
exactly its windows; a truncated labels file recomputed; checkpoints off
writing nothing; folder defaults.
