Lifecycle: new
Status: IMPLEMENTED 2026-11-13 (default on, not alpha); step 6 reproduction proof below — spacr.ops_compose.compose_window takes blend='feather' (default) or 'average'. Feather weights each tile's pixel by its distance in pixels to the nearest edge of that tile, plus one (min(row, column, height - 1 - row, width - 1 - column) + 1, 0-based tile pixels, the rounded production placement), and the composite is sum(w x tile) / sum(w), summed in float64 and returned as the requested dtype (float32); 'average' is the earlier plain mean, byte for byte. Coverage (the tile count) is unchanged for either blend. The setting ops_compose_blend ('feather') reaches both compose_window calls of spacr.ops_engine (_objects, the segmented mosaic, and _phenotype, the anchor windows the phenotype fields are aligned to) through _compose_blend, which refuses any other name; each well's objects report records compose_blend. Because the default changed, saved settings now carry spacr_settings_version (spacr.settings.SETTINGS_SCHEMA_VERSION = 931): run journals (settings.json, settings.csv), spacr.utils.save_settings and spacr.cli.write_settings_file (Export settings) write it, and spacr-run, spacr repro, the batch queue and Import settings read it. A file with an older stamp or none gets, for every key of its pipeline that it does not set, the default the key had then (spacr.settings.DEFAULT_CHANGES, {931: {'ops_compose_blend': 'average'}}), with a logged notice; a key the file sets always wins. spacr/ops_compose.py, spacr/ops_engine.py, spacr/ops_settings.py, spacr/settings.py, spacr/cli.py, spacr/cli_repro.py, spacr/batch.py, spacr/run_journal.py, spacr/utils.py, spacr/qt/screens/app_screen.py, tests/test_the_nuclear_map_is_composed_window_by_window.py, tests/test_settings_schema_version_931.py.
