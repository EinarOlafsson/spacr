--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

With no pathogen object Measure still writes *_pathogen_* distance
features, all +inf (the distance transform of an empty mask). The
reanalysis dropped them in its export. Feature QC (item 791) now reports
them as all_missing.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

+inf columns break every downstream mean, scaling and distance.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. Skip the pathogen distance features when no pathogen mask exists, or
   write NaN with a documented meaning.
2. A test measuring a field without pathogen_mask_dim.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

A BBBC021 measurements.db has no +inf column.

--------------------------------------------------------------------------------
DELIBERATELY NOT DONE
--------------------------------------------------------------------------------

- No new setting, so nothing is registered under ALPHA_FEATURES: the change
  only removes columns that were all +inf.
- object_distances keeps +inf for a segmented partner type that has no object
  in the field (its documented "no partner" value); only never-segmented
  roles are skipped.
- The BBBC021 measurements.db rerun is left to the paper lane.
