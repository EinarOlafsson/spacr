ORIGINAL READER/DISCOVERY GAPS (NPY ENTRY NOW IMPLEMENTED ABOVE)

MakeMasksScreen.open_paths delegates to drop_classification.classify_drop,
whose channel_sorting.IMAGE_EXTS excludes numeric NPY and ND2/CZI/LIF.
_open_queue independently checks mask_engine.IMAGE_EXTS, which excludes the
same four formats. mask_engine.read_image handles SCN/TEM specially and
otherwise uses imageio.imread; it does not dispatch the existing vendor
readers in spacr.convert. Merely adding suffixes cannot provide support.

Ordinary NPY files are explicitly classified as arrays rather than images.
The safe existing io._load_array_any reader uses allow_pickle=False;
resume.read_npy_header can inspect shape and dtype without loading pixels.
Cellpose *_seg.npy bundles have a distinct existing load_seg_bundle route;
retain that contract rather than treating arbitrary object arrays as images.

Import already exposes convert.IMAGE_EXTENSIONS, reader_requirement,
reader_available, scan/_describe and _read_source for TIFF/OME-TIFF, ordinary
raster images, ND2, CZI, LIF and SCN. Import also supports validated numeric
two-dimensional YX NPY images; ambiguous higher-rank arrays require explicit
axis selection and are not silently converted. Other shared readers cover
numeric arrays and TEM. Current drop discovery
also omits engine-supported DM3/DM4/MRC/REC; explicit MAP volume opening is
not represented consistently in ordinary queues. The image picker advertises
NPY but can open a different supported sibling image instead of the requested
file because it opens the folder before verifying the requested queue entry.

Single-frame GIF, WebP and other installed Pillow OPEN formats now have a real
Import conversion route, including palette-to-RGB/RGBA conversion; multiframe
rasters are explicitly refused pending frame/axis selection. Make Masks still
lacks matching discovery/picker/queue support for those general raster formats.
Easy mode must not claim a direct Make Masks route, nor imply that renaming
genuine GIF/WebP bytes converts them into supported TIFFs. The capability
follow-up must retain safe conversion of an unchanged original and conditional
installed-reader coverage, including unavailable-reader diagnostics.

2. Open supported numeric NPY safely with pickle disabled and explicit shape,

4. Inspect bounded headers and samples first. Run necessary image reads in

5. Explain unavailable optional readers and provide their real installation
   route. Advertise direct Make Masks opening only where its complete route
   works; retain useful Import guidance when conversion is required.
6. Opening must preserve original files, names and metadata. Keep existing
   masks, source identities, save/export behavior and 2D/3D/TEM routes intact.
   A requested unsupported file must not silently open a different sibling.
