CURRENT MAINTAINER STARTUP POLICY — 2026-10-28
Normal launches after closing spaCR must always start at Navigator Home, or classic Home if Navigator is disabled, irrespective of old session-restore preferences or stale restart records. Only an explicit Restart or Force restart may restore the module/location and settings that were open; consume that restart request once and never automatically resume computations. Preserve explicit CLI module launches, crash-draft recovery, and autosave. Remove contradictory normal-launch session preference/help. Workstation root owns startup integration/tests/publication, retained shutdown and preferences peers own disjoint implementation, and index peer owns required normal localization/docs artifacts. This supersedes historical every-start restoration requirements below.

WHAT TO BUILD
  Session restore on every start: reopen the last module, settings and folder after any exit or crash, not only after updates.

DONE WHEN
