PROBLEM
spacr-run ops <file> calls run_ops(settings) with no phase list, so it
always ran stitch, phenotype, objects and decode. A settings file could not
reproduce a run that went on to segment and measure the phenotype fields,
merge them with the calls and aggregate them.

BUILD
- ops_phases (str, list or None; default None): the phases a run without
  its own phase list runs, in order. run_ops resolves them with
  _run_phases: the caller's phases win; an empty setting keeps the four
  default phases (the default run is byte-identical); an unknown phase is
  refused by name before any folder is read or written.
