--------------------------------------------------------------------------------
WHAT THE STATE IS
--------------------------------------------------------------------------------

There is no VRAM budget; the driver caps each segment process with
torch.cuda.set_per_process_memory_fraction. Item 282 is the host memory
budget only.

--------------------------------------------------------------------------------
WHY IT MATTERS
--------------------------------------------------------------------------------

Shared GPUs (one workstation, several jobs) need a hard per-job cap.

--------------------------------------------------------------------------------
WHAT TO DO
--------------------------------------------------------------------------------

1. A vram_budget setting (GB or fraction) applied per process and split
   across workers, with batch size reduced to fit.
2. Retry a batch that runs out of memory at half size before failing.
3. Register it in ALPHA_FEATURES under 768.

--------------------------------------------------------------------------------
HOW TO KNOW IT WORKED
--------------------------------------------------------------------------------

A BBBC021 plate segments inside a 5 GB budget, verified with nvidia-smi
per process.
