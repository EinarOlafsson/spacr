RULE PINNED FROM THE NOTEBOOKS
- Test unit: guide-level profile rows (guide_normalized_feature_select_median_merged) of a gene vs ALL nontargeting rows, per
  feature, scipy.stats.mannwhitneyu(NT, gene) default (two-sided); U is the NT sample's (mann_whitney_table).
- Gene score: count of features with p STRICTLY below 0.001, per compartment and in all; compartment = feature name contains
  mito / cona / wga / dapi / phalloidin in any case (a feature may count in two); the file's sig_gene_count row is dropped.
- Null: genes of the dataset with DepMap 21Q4 A549 log2(TPM+1) == 0 (3,068); expressed = the rest minus nontargeting (17,324).
- Threshold per score (null_threshold): from 200 (compartment) / 500 (whole profile) down, the first c with more than
  int(n_null / (100 / FDR%)) null genes above c sets threshold c+1. Whole-cell hit: expressed and Sum > threshold;
  compartment-specific: expressed, Sum <= its threshold, any compartment > its threshold.
- CORUM r (Figure 4C): genes = hit list; PCA keeping the number of components closest to 90 % variance; Pearson r between gene
  rows; complexes with > 0.333 of subunits scored; unique within-complex pairs pooled; median. (The spec's per-complex
  median is also written, corum_complexes.csv.)
- STRING display (Figure 4D): STRING links among scored genes binned by r (-1,-0.66,-0.33,0,0.33,0.66,1], combined score per bin.
  AUPRC (new, no reference value): pairs ranked by cosine, positives = links >= threshold x 1000.
