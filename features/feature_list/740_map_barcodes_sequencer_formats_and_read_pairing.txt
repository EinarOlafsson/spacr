The maintainer explicitly requests this as a separate item. In the sequencing
branch, ask which sequencing machine produced the reads, accommodate different
sequencing file formats in Map Barcodes, and offer paired, unpaired or both
(mixed inputs). Carry the selected compatible options from Navigator Protocols
into Map Barcodes.

Before coding, inventory actual current readers/formats and propose supported
sequencers, format detection/conversion, machine-specific settings, read/index
roles, paired-file matching and mixed-input validation. Retain an unknown/other
route; infer a machine only when evidence is reliable. Do not advertise formats
that current readers cannot handle. Preserve existing barcode-mapping behavior,
quality/identity checks, data provenance and output contracts. Explain failures
and missing conversion requirements clearly rather than silently coercing data.

Design and implementation must be coordinated with N739's complete path catalog.
The original request is preserved verbatim in N739. No implementation is authorized
by this recording-only session; the next session first presents its plan.
