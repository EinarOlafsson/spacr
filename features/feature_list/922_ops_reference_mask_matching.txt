OPS CROSS-PIPELINE CELL MATCHING BY MASK OVERLAP (F1 AT IoU 0.5, MEDIAN IoU, PER-CELL CALL CONCORDANCE)
=====================================================================================================

Lifecycle: future
Status: DONE 2026-11-11 (alpha, under ALPHA_FEATURES[922]) — the compare_calls phase gains ops_compare_match 'mask_overlap' (spacr.ops_decode.run_compare_masks; runs alone). Per field and object, spaCR's label masks (default <dst_root>/<well>/phenotype_masks/site-<n>.npz, or any template) are matched to the reference pipeline's label masks (ops_compare_reference_masks template with {plate}/{well}/{site}|{tile}/{object}) by a one-pass sparse contingency (label_contingency); each spaCR object gets the reference object of largest overlap (ties: higher IoU, then lower label; best_overlaps) and F1 uses a Hungarian one-to-one matching at IoU >= ops_compare_iou (one_to_one, match_masks). Objects touching the image border are counted apart (ops_compare_edge_policy). Reference per-cell calls (ops_compare_reference_calls + ops_compare_call_columns, PERISCOPE map by default; reference_cell_calls, parse_site_key) are carried through the matches and compared with spaCR's (ops_cells_<plate>.parquet or ops_compare_spacr_calls; 'reference' = self-match control). Feldman reads -> per-cell call rule: cell_calls_from_reads (top barcode by read count, tie = no call). spacr/ops_decode.py, spacr/ops_engine.py, spacr/ops_settings.py, spacr/settings.py, tests/test_ops_mask_matching_922.py.
