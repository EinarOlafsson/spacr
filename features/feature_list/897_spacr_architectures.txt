RESULT
Acceptance scripts and logs: scratch-docs/lane-j-1109/v897/ (accept_897.py,
accept_*.json). In envs/spacr, on the reference's normalised ResNet-18
embeddings of BBBC021 (255,310 cells), OMP_NUM_THREADS=2 as the reference
queue ran:
- The normalisation from the raw per-plate embeddings (plate control
  centring and scaling, control PCA whitening to 256 dimensions) gives the
  reference's cached input bit for bit (float16, 255,310 x 256); with every
  BLAS thread instead of two it differs by one float16 step (max 0.0156).
- mean_knn, mean_lr, mean_lr_shuffled, n1, abmil and settf (the main arm;
  n1, abmil and settf are trained transformer arms, 12 folds of 800 steps
  each): treatment_probs.csv bit-identical to the reference runs, and
  accuracy (settf 0.794, 81/102), bootstrap interval, macro AUROC, macro AP,
  majority class, parameter count and median penetrant fraction identical
  to runs_cpu/summary_table.csv.
- mixbag (ablation) and settf_shuffled (control): bit-identical too, so
  every NSCB ResNet-18 arm and control the reference ran matches.
- The 25 unit tests of spacr_arch.py are ported (CPU, smaller widths where
  the reference used 224 px on full-size models); the parameter counts of
  the default sizes match the reference's smoke log (2.43 M, 5.57 M, 21.76 M).
- mean_lr matches only with two BLAS threads, as the reference queue
  (OMP_NUM_THREADS=2); with one thread AUROC moves by 4e-4.
- Not matched: the synthetic arms of summary_table.csv, because the
  reference did not seed torch for them (spaCR seeds it, so its synthetic
  runs are reproducible from now on).
