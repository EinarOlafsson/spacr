QUALITY CLASSES
perfect   >= ops_quality_min_reads exact reads of one barcode, no read of
          any other barcode
great     not perfect; the top barcode has more reads than any other
          (exact reads with a minority competitor, a single exact read,
          or corrected reads only)
ambiguous matched reads, two barcodes tie for the most reads
none      no read matched a callable barcode
ops_prefix_quality_method='recipe_simple' (added 2026-11-11, lane Q) uses
instead the "simple" cell quality PERISCOPE's Perfect / Great classes came
from: simple_categorize of the Broad pooled Cell Painting profiling recipe
(github.com/broadinstitute/pooled-cell-painting-profiling-recipe, ported from
commit 49e62a30c6; same rules as 1d5e071, 2020-08-20). It is not in
pycytominer (1.7.1 has no cell-quality method). spacr.ops_prefix.
recipe_simple_quality groups a cell's reads by gene and barcode (mean score,
count; score = 1 - distance / key length, as CallBarcodes scores):
perfect   one barcode, mean score 1 (every read exact)
great     one barcode, mean score below 1
imperfect several barcodes; one has both the single highest mean score and
          the single highest count
bad       several barcodes otherwise
none      no read matched a callable barcode
ops_quality_min_reads is not used under it. quality_classes.json records the
method, its classes and the source commit.

DEVIATIONS FROM THE SPEC
- Crosstalk is its own setting, ops_prefix_crosstalk, rather than new values
  of ops_crosstalk: the tile decode's ops_crosstalk keeps its default
  'argmax_median', while the spec wants 'none' first for P1.
- ops_prefix_masks (new) names the cell labels reads are assigned by, since
  the cropped layout has no spaCR segmentation yet (items 921/922).
- The decode phase reads only the cropped-site layout (item 919). The tile
  path (Feldman via item 925) is not wired.
- Reads with an N are matched by Hamming distance under either metric.

VALIDATION (Home, CPU, spacr env, 2026-11-11)
- Library, N = 10, from the deposited Barcodes.csv: 80,862 guides, 78,521
  prefixes, 2,324 shared prefixes (2,323 shared by different genes, 1 by
  one gene; 4,665 guides involved), 76,197 callable prefixes, minimum
  Hamming distance 1 (109,954 pairs at distance 1). An independent pandas
  count from Barcodes.csv gives the same numbers and the same prefix set.
  N = 11 and 12 have no shared prefixes (minimum distance 1 and 2).
- Pilot, one site (CP186A Well1 site 45), settings-file run with defaults
  (ops_read_threshold 315 from the Funk plate, crosstalk 'none', Hamming 1)
  and CellProfiler's own Cells masks: 668 reads; exact 34 %, corrected
  13 %, ambiguous 38 %, collision 3 %, out of library 11 %; the shuffled
  whitelist matches 30 % of the same reads against 48 % for the real one.
  549 cells with a read (2.0 % of CellProfiler's 11,135 segmented cells
  with an exact read); 3 perfect and 284 great. CellProfiler retained 2,026
  cells (18 %; 1,066 Perfect, 960 Great). Of their retained cells that
  spaCR also called (213), 169 (79 %) have the same gene. Same cells
  (their masks), same site, same library; the spot threshold was NOT tuned
  (no tuning on test data), so this is not a fair yield comparison: spaCR
  found far fewer reads than CellProfiler's foci at this threshold.
- A rerun from the saved settings gives identical reads, cell and summary
  tables.
