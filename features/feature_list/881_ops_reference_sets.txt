WHAT THE STATE IS
The OPS cluster benchmark (855) read the three Brieflow benchmark tables for
cluster enrichment only. Gene-gene retrieval needs every reference as a set
of gene pairs, with a fixed split into a half used to choose and a half used
to report, and a split by date for asking what was found before it was
known.

WHAT TO DO
- One module that reads every reference by name from ops_reference_dir (a
  folder or a list of folders) and returns its unordered pairs.
- The SELECT / REPORT halves exactly as the reference code draws them.
- The 2022 references and the 'new after 2022' sets, diffed on stable ids
  (STRING protein ids, Entrez ids), both genes present in the old release.
- Record file, md5, release and pair count of each reference of a run.

RESULT
Against the reference code and files (scratch script
paper-items-1109/lane-d/accept_881.py):
- every reference and every half (CORUM, KEGG, STRING_brieflow,
  STRING>=0.7, STRING>=0.4, BioGRID, the seven time-split references, and
  the SELECT / REPORT halves of the first six) gives exactly the pair set
  of ic_lib._ref_pairs;
- prepare_time_split_references rebuilt from the archives gives the
  versions.json counts exactly (STRING v11.5 897,565 / 252,982 pairs,
  22,349 new v12 >= 0.7; BioGRID 746,082 old, 989,498 new, 242,263 added;
  CORUM 3.0 2,916 complexes, 39,593 pairs, 6,840 new) and the same pair set
  in all seven parquet tables (the two BioGRID tables differ only in row
  order, which comes from set iteration);
- prepare_current_references gives string_v12_ge400.parquet and
  biogrid_physical.parquet frame-identical to the prepared tables.
