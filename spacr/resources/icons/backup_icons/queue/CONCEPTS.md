# queue -- 8 candidate concepts

White artwork on transparent background, 1024x1024 RGBA,
house style of `plaque.png` / `measure.png`.
Candidates for review only; the installed icon is whichever
one was copied to `spacr/resources/icons/`.

1. **queue_01** - One settings card feeding a column of identical plates.
2. **queue_02** - A stack of identical plates, each stamped with the same gear.
3. **queue_03** - A waiting line: plates queued behind a 'now running' marker.
4. **queue_04** - One recipe, many runs: a settings sheet cloned down the stack.
5. **queue_05** - Plates on a belt, all carrying the same mark.
6. **queue_06** - A numbered running order down one column of plates.
7. **queue_07** - Hopper: identical plates dropping through one set of settings.
8. **queue_08** - Same settings, ticked off plate after plate.

Contact sheets: `_sheet_dark.png` (white ink on #14161a)
and `_sheet_light.png` (the same alpha masks tinted dark on
#f5f6f8, which is how a light theme re-inks them).

`python _generators/group_queue_batch_invasion_replication.py`
