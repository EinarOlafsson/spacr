# run -- candidate concepts

1. **run_01** - play triangle built from cells (the pipeline is made of objects)
2. **run_02** - petri dish with an inscribed play triangle
3. **run_03** - power / start button ring around a play triangle
4. **run_04** - stopwatch with a play triangle on the face: start a timed run
5. **run_05** - three-stage pipeline (dish -> image tile -> plot) ending in go
6. **run_06** - fast-forward chevrons advancing over a row of samples
7. **run_07** - microscope objective over a slide, with a start triangle
8. **run_08** - funnel: a stack of raw images in, one measured object out
9. **run_09** - stepper track: stages completed and stages still to run
10. **run_10** - terminal window with a prompt and cursor: execute the pipeline

_All 1024x1024 RGBA, white on transparent, house style (flat, thin strokes + solid fills), matching `plaque.png` / `measure.png`._

_`_sheet_dark.png` shows the PNGs as they are. `_sheet_light.png` re-inks the same alpha masks in dark grey, because pure-white artwork is invisible on a light background -- that is the point of the second sheet._
