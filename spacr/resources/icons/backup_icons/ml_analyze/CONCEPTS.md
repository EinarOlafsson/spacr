# ml_analyze - candidate concepts

White-on-transparent flat vector, 1024x1024 RGBA, house style of
`plaque.png` / `measure.png`.  Ten conceptually distinct metaphors.

1. Decision tree whose nodes are cells - the classifier splitting a population.
2. Neural network: a cell feeding three fully connected layers.
3. Cell distilled into a feature vector of bars - featurisation.
4. Ranked feature-importance bar chart beside the cell the features came from.
5. Confusion matrix: cells sorted into a 2x2 grid, diagonal correct.
6. Two feature clusters separated by a dashed decision boundary.
7. Convolution window sliding over an image patch - CNN on raw pixels.
8. Classifier funnel sorting cells into two labelled bins.
9. Random forest: an ensemble of three trees voting on one cell.
10. ROC curve above the chance diagonal - model performance.

_Sheets: `_sheet_dark.png` (#14161a), `_sheet_light.png` (#f5f6f8, artwork re-tinted so it is visible). Each cell also shows a 48 px thumbnail bottom-right._
