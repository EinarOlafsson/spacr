# sequencing -- candidate concepts

1. **sequencing_01** - barcode bars above a DNA double helix
2. **sequencing_02** - flow cell: lanes with sequencing clusters
3. **sequencing_03** - nanopore: a strand threading a membrane pore
4. **sequencing_04** - Sanger chromatogram: base peaks on a baseline
5. **sequencing_05** - read pile-up aligned against a reference
6. **sequencing_06** - the four bases as A/T/G/C code tiles
7. **sequencing_07** - a barcode tag attached to a cell (barcode-to-cell mapping)
8. **sequencing_08** - magnifier reading a barcode
9. **sequencing_09** - a FASTQ record: @header, sequence, +, quality
10. **sequencing_10** - electrophoresis gel: lanes of bands

_All 1024x1024 RGBA, white on transparent, house style (flat, thin strokes + solid fills), matching `plaque.png` / `measure.png`._

_`_sheet_dark.png` shows the PNGs as they are. `_sheet_light.png` re-inks the same alpha masks in dark grey, because pure-white artwork is invisible on a light background -- that is the point of the second sheet._
