# batch -- 8 candidate concepts

White artwork on transparent background, 1024x1024 RGBA,
house style of `plaque.png` / `measure.png`.
Candidates for review only; the installed icon is whichever
one was copied to `spacr/resources/icons/`.

1. **batch_01** - A schedule: different module marks against different plates.
2. **batch_02** - A chain of unlike jobs, run one after another.
3. **batch_03** - A worklist of mixed jobs with a run button.
4. **batch_04** - Cards in a hopper, each a different module.
5. **batch_05** - Overnight: a clock over a stack of unlike jobs.
6. **batch_06** - Many modules x many plates, folded into one run.
7. **batch_07** - A numbered running order of unlike steps.
8. **batch_08** - A pipeline of different stages emptying into one output.

Contact sheets: `_sheet_dark.png` (white ink on #14161a)
and `_sheet_light.png` (the same alpha masks tinted dark on
#f5f6f8, which is how a light theme re-inks them).
